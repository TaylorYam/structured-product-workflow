## 1. 和 `nomura-zh-iis` 不同的地方

| 位置 | `nomura-zh-iis`（FCN） | `nomura-zh-dacn-iis` |

| 封面英文名稱 | `… Autocall Fixed Coupon Notes …` | `… Autocall Daily Range Accrual Notes with Memory Knock-Out …` |
| 第三 1. 配息 | `固定配息率：就每配息日而言，X%`（每期，4 位） | `於每觀察期間，…（惟若有自動提前出場事件，該觀察期間之配息金額將於自動提前出場日支付）：配息金額：(i)就第一個配息日而言，…：每單位商品面額×年化配息率/12(ii) 就其他配息日而言，…：每單位商品面額×年化配息率/12 ×實際日數/總日數。年化配息率：X%。`（年利率，2 位） |

## 3. 範本辨識條件

全部成立才算 `nomura-zh-dacn-iis`（去空白後比對）：

1. `nomura-zh-iis` §6 的條件 1、3、4、5（首列、商品種類行、相關機構第 1 點、段落順序）；中文名稱以 `NomuraInternationalFundingPte.Ltd.發行` 開頭、以 `(無擔保)` 結尾。
2. **商品家族（每日計息）**：`第三 收益分配事項` 到 `第四 贖回價金之計算` 之間有 `×實際日數/總日數`。

條件 1、2 成立後，現行版特徵全部成立才是本範本；缺任一項 → 不支援的範本版本（轉人工覆核、不能人工放行）：

- 第三 1. 的配息公式 (i)(ii)（§1，去空白逐字相等）與 `年化配息率：X%` 剛好一處；
- 英文名稱含 `AutocallDailyRangeAccrualNotes` 且以 `issuedbyNomuraInternationalFundingPte.Ltd.(unsecured)` 結尾；中文名稱含 `計價每日計息(`。

和 `nomura-zh-iis` 互斥：`nomura-zh-iis` 的辨識另加條件「第三 收益分配事項沒有 `×實際日數/總日數`」。
