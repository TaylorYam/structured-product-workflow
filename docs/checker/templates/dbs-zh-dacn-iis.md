### 1.1 累積日數的寫法（7 份逐字相同；去空白後比對）

`累積日數：就每個觀察期間而言，(a)如果該觀察期間內未發生自動提前出場事件，則累積日數為該觀察期間內所有連結標的的參考價格皆等於或高於其區間下限價格(且等於或低於其區間上限價格(如適用))的觀察日的總數；或者(b)如果該觀察期間內發生了自動提前出場事件，則累積日數為該觀察期間內截至(包含)自動提前出場事件日為止之期間內，所有連結標的的參考價格皆等於或高於其區間下限價格(且等於或低於其區間上限價格(如適用))的觀察日的總數。`

和說明書 §2.1 第 2 段文字相同（說明書 `(a)`、`(b)` 前後換行，去空白後一樣）。總日數 `總日數：就每個觀察期間而言，為該觀察期間內觀察日的總數。`（比說明書多一個 `為`，同 FCN 投資人須知）。

## 3. 範本辨識條件

全部成立才算 `dbs-zh-dacn-iis`（去空白後比對）：

1. `dbs-zh-iis` §6 的條件 1～5（第一行、名稱開頭、代號與 ISIN、相關機構、段落順序）；
2. **商品家族（區間累計配息）**：`收益分配事項` 到 `贖回價金之計算` 之間的 `累積日數：` 定義有 `參考價格皆等於或高於其區間下限價格`。

條件 1、2 成立後，現行版特徵全部成立才是本範本；缺任一項 → 不支援的範本版本（轉人工覆核、不能人工放行）：

- §1.1 累積日數寫法；
- 價格表表頭有 `區間下限價格` 與 `區間上限價格`；
- 中文名稱含 `區間累計配息記憶型每日觀察自動提前出場`；英文名稱含 `Range Accrual Memory Daily Knock-Out`；
- 商品簡介交易日不早於 2026-06-01（同說明書）。

和 `dbs-zh-iis` 互斥：`dbs-zh-iis` 的辨識另加條件「收益分配事項沒有 `其區間下限價格`」。
