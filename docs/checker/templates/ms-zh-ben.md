# 範本規格：摩根士丹利（MS）BEN 中文產品說明書

> 現行上手／樣態限制見[支援範圍](../support-matrix.md)。本文件的樣本數、探勘結論與日期決策保留當時觀察，不代表目前所有交易或公司上線驗收都已通過。

- 範本代號：`ms-zh-ben-pd`
- 商品種類：參考條件表 Product = `BEN`（workflow ADR 0029、#372、#373、#374）
- 商品家族：MS 的 BEN 有兩種型態，都沒有定期配息、不會提前出場、沒有 KI，只在到期依期末定價日收盤價對執行價結算（< 執行價交股）：
  - **一般 BEN**：中文 `紅利表現結構型商品`、英文 `Bonus Enhanced Notes`。≥ 執行價付面額 ×〔100% + 最大值（紅利, 參與率 × 最差標的漲幅）〕；說明書明寫參與率 100%。
  - **Digital**：中文名稱**沒有產品字樣**（`連結股票或指數股票型基金結構型商品`）、英文 `Equity Linked Notes`。≥ 執行價付面額 ×（100% + 紅利）；說明書明寫參與率 0%。
  - 兩種都可能有 **lookback**（回顧觀察期間，§14(9)）：執行價改由回顧期初價格算（ADR 0029、#374）。lookback 不改名稱。
  - MS 把紅利叫「**紅利配息率**」：到期一次付、不年化。
- 發行機構、受託機構、總代理人：同 [MS FCN 範本](ms-zh-product-description.md)（`ms-zh-pd`）
- 依據：2026-10-30 對 18 份真實樣本（BEN-MS01～BEN-MS18，說明書與投資人須知成對；一般 BEN 16 份含 lookback 5 份、Digital 2 份含 lookback 1 份）的探勘與開發者螢光標記（workflow #376）。**作業人員獨立標記先略過，2026-10-30 使用者決定**：核對範圍以開發者凍結的標記為準，見 [MS BEN 核對規則](../rules/ms-ben-check-rules.md) §7
- 狀態：規格；實作另開（workflow #376）

> 真實樣本、擷取文字與比對輸出只放在被 Git 忽略的 `data/`。本文件只記錄版面、錨點與規則；所有數值範例都是虛構的。樣本代號與真實商品代號的對照只存在本機（`data/tmp/ben_ms/sample_map.txt`）。標「待使用者確認（BEN-376-nn）」的是暫定的保守做法，編號對到本機疑慮記錄，使用者回覆後再更新。

本文件只寫和 `ms-zh-pd` 不同的地方；沒提到的（文件特性、頁首頁尾、章名頓號、封面 1～16 項與警語、刊印日期、第一章 §1～§9、§11 標的表、§12 公司介紹、第二～六章、費用表、審查標準出處、MS 版固定警語、受託機構寫法、開始受理贖回日期）照 `ms-zh-pd`。

### 2.1 §15 到期公式與定義段

| 型態 | (a) 現金交割（≥ 執行價） | (b) 實物交割（< 執行價） |
|---|---|---|
| 一般 BEN | `到期日持有之商品單位數 x 每單位商品面額 x {100% + 最大值 [紅利配息率, 參與率 x (籃子中表現最差的連結標的期末定價日之收盤價/籃子中表現最差的連結標的期初價格 -100%)]}；否則，` | `若於期末定價日時籃子中表現最差的連結標的之收盤價低於其執行價，發行機構將於到期日，以支付「最終實物贖回權益」之方式贖回每單位商品：` |
| 一般 BEN lookback | 同上，`期初價格` 改 `回顧期初價格`；條件句比 `回顧執行價` | `…低於其回顧執行價，…` |
| Digital | `每單位面額 x (100% +紅利配息率)；否則，`；條件句 `若於期末定價日時該連結標的之收盤價高於或等於其執行價` | `若於期末定價日時該連結標的之收盤價低於其執行價，…` |
| Digital lookback | 同上，比 `回顧執行價` | 同上，比 `回顧執行價` |

定義段（`其中：` 之後）：

| 定義 | 非 lookback | lookback |
|---|---|---|
| 執行價 | `執行價：就任何連結標的而言，為相關連結標的之期初價格的X%` | 沒有；改為下面兩條 |
| 回顧期初價格 | — | `回顧期初價格：就任何連結標的而言，即為以下兩項中的較低者：（i）該連結標的期初價格及（ii）該連結標的於回顧觀察期間內任何共同預定交易日之最低收盤價。` |
| 回顧執行價 | — | `回顧執行價：就任何連結標的而言，即為該連結標的回顧期初價格乘以X%。` |
| 籃子中表現最差的連結標的（只有一般 BEN） | `…在期末定價日時收盤價除以其期初價格的數值，比一籃子中其他連結標的有關的數值為低…` | **同左，仍寫期初價格**（到期公式卻用回顧期初價格）：當固定句核對、不判錯；到期判斷的差異不在本範本（待使用者確認（BEN-376-01），詳見本機疑慮記錄） |
| 轉換匯率、最終實物贖回權益 | 說明文字 | 同左 |

Digital §15(1) 開頭仍寫 `籃子中表現最差的連結標的之收盤價而定`（單一標的卻用一籃子寫法），(a)(b) 改寫 `該連結標的`：當範本固定句，不判錯（待使用者確認（BEN-376-04），詳見本機疑慮記錄）。

## 3. 核心欄位定位規則

和 `ms-zh-pd` §3 相同的欄位不重列（商品代號、受託機構商品代號、ISIN、名稱、幣別、機構、面額、發行價格、標的代號、交易日、發行日、到期日、期末定價日、天期、最低金額、刊印日期、開始受理贖回日期、費率）。不同的：

| 標準欄位 | 主來源 | 擷取方式 |
|---|---|---|
| 型態（一般 BEN／Digital） | 名稱＋§10、§15(1)(a) 公式＋§15(3) | 中文名稱、英文名稱、§10(a)、§15(1)(a)、§15(3) 參與率都要指向同一型態；對不上 → 轉人工覆核（§8；Digital 待使用者確認（BEN-376-03），詳見本機疑慮記錄） |
| lookback 與否 | §14(9)＋§15 定義段 | §14(9) 回顧觀察期間、§15 回顧期初價格與回顧執行價定義、§15(1) 比 `回顧執行價`、價格表沒有執行價欄：四者一起有或一起沒有；混雜 → 轉人工覆核 |
| `lookback_end_date`（回顧結束日，新） | §14(9) `至YYYY 年M 月D 日（包含）` | 日期；起點寫法 `自交易日（包含）起` 是固定寫法 |
| `participation_pct` | §15(3) `參與率：X%` | **MS 明寫參與率**（和 HSBC 不同）：一般 `100.00%`、Digital `0%`；只比數值 |
| `coupon_pa_pct`（紅利） | §15(1) 價格表後 `(1) 紅利配息率：X%` | 一次性紅利，**不年化**（參考條件表 `Coupon p.a. (%)` 存的就是它，ADR 0029）；小數位數不固定（整數、1 位、2 位都有），只比數值；讀不到或有多個不同值 → 轉人工覆核 |
| `strike_pct` | 非 lookback：§15 `執行價：…期初價格的X%`；lookback：`回顧執行價：…乘以X%` | 非 lookback 和價格表表頭 % 交叉驗證；lookback 沒有表頭 % |
| `underlying_prices` | §15 價格表 | 期初價格（4 位小數、可能有千分位）；非 lookback 另有執行價欄；lookback 的執行價不讀表，由期初價格 × K% 推（核對規則 §3.2） |
| `ko_pct`、`ko_observation`、`ko_memory`、`first_callable_period` | — | 不適用：沒有提前出場。沒有 KO 由 §10 開頭句、第一章沒有自動提前出場條判斷（核對規則 §3.5） |
| `ki_type` | §15 | 全文沒有 `觸及`、價格表沒有下限價欄、§15(1)(b) 直接比執行價：三者都成立 → 無 KI；任一不成立 → 讀不到 |
| 比價日 `autocall_schedule` | §14(5) 期末定價日 | 只有 `比價日_{天期}` = 期末定價日，其他格 `-`（[MS BEN 下單資料格式](../order-formats/ms-ben-reference.md) §4） |
| `monthly_coupon_pct`、日期表 | — | 不適用（沒有定期配息、沒有日期表） |

MS FCN 交「範本沒有」的 `coupon_pa_pct`，BEN 改成交紅利；`subscription_dates` 仍交「範本沒有」。

## 5. 情境分析（第 16 項）

基本假設（`▪` 條列）：

| 假設 | 寫法（虛構例） |
|---|---|
| 總投資金額 | `▪ 總投資金額 = 1 單位商品面額 = 10,000.00 美元` |
| 年期 | `▪ 年期：6 個月` |
| 紅利 | `▪ 紅利配息率：12.5%` |
| 最低保證贖回率 | `▪ 最低保證贖回率：本商品不適用。本商品不保本。本商品於到期的本金贖回可能等於零。` |
| 參與率 | `▪ 參與率：100.00%` |
| 重印價格表 | 非 lookback：欄同 §15 價格表；lookback：表頭 `回顧期初價格`／`回顧執行價 （回顧期初價格的X%）`，值 = §15 期初價格與期初價格 × K%（說明書發行時以期初價格示意） |

以標題區分情境，不以編號判斷：

| 情境 | 一般 BEN | Digital |
|---|---|---|
| 一 | `較佳情況 A`：收盤價 ≥ 執行價、`100%x(…收盤價/…期初價格-100%)高於紅利配息率`；`=10,000x[100%+100% x (P 美元/I 美元-100%)]` | `較佳情況`：收盤價 > 執行價；`每單位商品面額x (100%+紅利配息率)` |
| 二 | `較佳情況 B`：紅利配息率高於漲幅；`=10,000 美元x(100%+X%)` | `較佳情況`：收盤價 = 執行價、現金結算；`每1 單位面額x(100%+紅利配息率)` |
| 三 | `最差情況`：收盤價 < 執行價、實物交割 | 同左 |
| 四 | 發行機構無法履約（只有文字） | 同左 |

- lookback 版情境的 I 是回顧期初價格、K 是回顧執行價（值 = 期初價格、期初 × K%）。
- 一般 BEN 情境一、二的到期金額 = 面額 × (100% + max(紅利, 參與率 × (P ÷ I − 1)))：漲幅以**期初價格**（lookback：回顧期初價格）算，不是執行價。
- 交股算式：股數 = 面額 × 期末匯率 ÷ K（4 位）；交割股數 = 無條件捨去取整；零股 = 股數 − 交割股數；剩餘金額 = P × 零股 ÷ 期末匯率（2 位）；到期贖回價值 = P × 交割股數 ÷ 期末匯率 + 剩餘金額（2 位）；損益 = 價值 − 面額。
- 報酬率 = 損益 ÷ 面額；年化 = 報酬率 × 12 ÷ 天期。**交股情境 MS 先把報酬率 half-up 到 2 位再年化**（樣本 54 個情境都照這個算法一致）；現金情境報酬率本身是整數或 2 位，兩種算法結果相同。
- 情境二文字寫成 `籃子中表現最差的連接標的`（`連接`，範本原樣）：情境說明句不核對，不會因舊版特徵 `連接` 誤判版本（版本只看名稱與 §1 標題）。

## 7. 容易誤抓的地方

- **Digital 名稱太通用**：`結構型商品`、`Equity Linked Notes` 沒有產品字樣，以後若 MS 別種商品也這樣命名會撞名。Digital 要名稱＋§10／§15 Digital 公式＋§15(3) 參與率 0%＋Product BEN 全部成立才認（待使用者確認（BEN-376-03），詳見本機疑慮記錄）。
- **「紅利配息率」不是定期配息**：判斷有沒有配息不能用「配息」關鍵字。
- **最低保證贖回率「本商品不適用」不是 0%**，也不是參與率；參與率在 §15(3) 另寫。
- **lookback 的價格表沒有執行價欄**：不能把下一欄或重印表的回顧執行價當成 §15 的執行價。
- **lookback 的 §16 重印表表頭寫「回顧期初價格」，值卻是期初價格**（發行時還沒有回顧價格）：比對時對到 §15 期初價格，不是資料庫的 `lookback_price`。
- **舊總表的 lookback 商品進場價可能已被改成回顧期初價格**：說明書的期初價格才是進場價（[MS BEN 下單資料格式](../order-formats/ms-ben-reference.md) §7；待使用者確認（BEN-376-02），詳見本機疑慮記錄）。
- 情境二、§19 的範本筆誤（`連接`、20.1～20.4）不核對。
- 受託機構商品代號空白的樣本有 3 份：同 MS FCN，判不一致。

## 8. 範本辨識

全部條件成立才判定為 `ms-zh-ben-pd`；只符合部分條件，或同時符合多個範本，一律轉人工覆核。

1. `ms-zh-pd` 的版面條件成立（封面標題 `中文產品說明書`、封面 10 發行機構含 `英商摩根士丹利國際股份有限公司`、英文名稱以 `Morgan Stanley & Co. International Plc issuance of` 開頭、第一章 §1 標題 `商品中文名稱`），但第一章條號是 **1～28** 連續。
2. 封面中文名稱以 `英商摩根士丹利發行` 開頭、不含 `固定配息`、`區間累積`、`自動提前`（忽略空白），而且：一般 BEN 含 `紅利表現結構型商品`；Digital 是 `連結{標的寫法}結構型商品`（標的寫法後面直接接 `結構型商品`）。
3. 封面英文名稱含 `Bonus Enhanced Notes`（一般 BEN）或 `Equity Linked Notes`（Digital）（忽略空白），不含 `Fixed Coupon`、`Autocallable`，且和條件 2 是同一型態。
4. 現行版特徵（§1）：§10 開頭 `主要給付項目為到期贖回金額`；§15 標題 `到期贖回計算公式、最低保證贖回率及參與率`；§15(1)(a) 是該型態的公式（§2.1）；§15(2) 固定句；§15(3) 參與率是該型態的值（一般 100、Digital 0）；沒有自動提前出場條。

條件 1～3 成立、4 不成立 → **不支援的範本版本**：轉人工覆核，錯訊寫明「MS BEN 說明書的寫法和現行版不同」（錯訊開頭是「目前樣態不支援自動核對：」，Issue #340），不跑規則、不能人工放行（同不支援樣態；待使用者確認（BEN-376-05），詳見本機疑慮記錄）。Digital 的條件 2、3 只看名稱會太寬，條件 4 和商品種類一致（下段）一起成立才認（待使用者確認（BEN-376-03））。

`ms-zh-pd` 要求 `固定配息` 與 `Fixed Coupon Notes`，天然排除 BEN；探勘時現行程式把 18 份 BEN 說明書都判為範本未知，沒有誤判。MS DACN（英文 `Autocallable Range Accrual Notes`，workflow #366 系列）也被條件 2、3 排除。

**商品種類一致**：辨識結果和參考條件表 Product 不一致（Product 是 `BEN` 但辨識成 `ms-zh-pd`，或 Product 是 FCN／FCN_Express／DACN／空白但辨識成 `ms-zh-ben-pd`）→ 轉人工覆核，錯訊寫出兩邊（共用 `template.product_family`）。

負面測試：MS FCN（新舊版）、MS DACN 說明書不應被判定為本範本；本範本不應被判定為 `ms-zh-pd`；MS BEN 投資人須知不應被判定為說明書；中英文型態對不上（一般 BEN 中文配 `Equity Linked Notes`）轉人工；Digital 名稱但 §15(1)(a) 是一般 BEN 公式（或參與率 100%）轉人工；其他上手的 BEN 不含 `英商摩根士丹利`。

## 9. 日期之間的關係（現行版觀察）

| 關係 | 觀察 | 核對 |
