| 版本 | 樣本 | 特徵 | 處理 |

## 3. 欄位

| 欄位 | 出處 | 規則 |
|---|---|---|
| 出場紅利 | 二、2.(a) `自動提前出場紅利：x%` | 數值 = 說明書出場紅利（= 參考條件表 `Coupon p.a. (%)`）；說明書 2 位、投資人須知 4 位，比數值 |
| 沒有配息 | 二、1.(15)、二、2. 開頭 | 兩句都要有；沒有或不同 → 轉人工覆核 |
| 記憶式 | 二、2.(a) 事件句 | 非記憶式句（多標的或單一標的）→ `N`；其他句型 → 讀不到 |
| KI 型態 | 到期贖回金額段 | 沒有界限事件、(i) 直接比執行價 → 無 KI；否則讀不到 |
| 贖回 % | 二、2.(a) `(100%+自動提前出場紅利)` | 固定寫法 = 說明書第 9 項 (a) |
| 到期公式 | (ii) | 固定寫法（同說明書，比對忽略空白與 `x`／`*` 前後空白） |
| KO 觀察方式、第一個可提前出場期 | — | 投資人須知沒寫（只參照說明書），不核對；說明書另核對 |
| 月配息率、年利率 | — | 不適用 |

其餘欄位（代號、ISIN 兩處、商品種類、刊印日期、警語、風險等級、機構、幣別、標的代號、年期、期初訂價日（交易日）、發行日、期末訂價日、到期日、開始受理贖回日寫法、幣別字、費率、保證機構評等）照 `ca-zh-iis` §3。

## 4. 範本辨識條件

全部成立才算 `ca-zh-sb-iis`：

1. `ca-zh-iis` 的版面條件成立（`中文投資人須知` 開頭、章名一～七、發行機構 `Crédit Agricole CIB Financial Solutions`）。
2. 中文名稱含 `計價連結表現自動提前出場結構型商品(無擔保)(不保本)`（忽略空白）、不含 `固定配息`。
3. 英文名稱含 `Performance Autocall Note`（忽略空白）。
4. 現行版特徵：二、2. 有 `本商品持有期間並無配息金額。`、`自動提前出場紅利：` 行、KO 事件句；沒有 `▪` 條列。

條件 1～3 成立、4 不成立 → **Super Bull 舊版**：轉人工覆核，錯訊寫明「CA Super Bull 舊版投資人須知（範本文字和現行版不同），不支援自動核對」。

`ca-zh-iis` 的辨識要確認名稱含 `固定配息`、英文含 `Fixed Coupon`（現有條件若沒有就補上），避免 Super Bull 投資人須知被認成 FCN。

**商品種類一致**：辨識結果和參考條件表 Product 不一致 → 轉人工覆核（同說明書範本 §8）。

負面測試：CA FCN、FCN_Express 投資人須知不應被判定為本範本，本範本也不應被判定為 `ca-zh-iis`；CA Super Bull 說明書不應被判定為投資人須知。
