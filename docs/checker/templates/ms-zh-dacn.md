### 2.1 第 15 項 (2) 的固定寫法（2 份相同；比對前去空白，`#` 是數字）

依序出現：

1. `每月配息金額(j) = 配息日(j)持有之商品單位數×每單位配息金額(j)`
2. `每單位配息金額(1) = 每單位商品面額× 固定配息率 (#.####%)`
3. `每單位配息金額(j) = 每單位商品面額×{#.####%×n(j)/N(j)}`，後接 `(四捨五入計算至小數點後第 2 位)`
4. `n(j) = 於第 j 個配息觀察期間，指在該配息週期起始日至（i）該配息週期終止日或（ii）自動提前出場事件發生日孰先，籃子中表現最差的連結標的之收盤價等於或大於其執行價的配息觀察日總數。`
5. `N(j) = 於第 j 個配息觀察期間的配息觀察日總數`
6. `j 係為a 至N 的數字，代表第a 至N 個配息觀察期間`（同 FCN 的期別範圍）
7. `配息觀察日：係任一共同預定交易日，即同時為所有連結標的之預定交易日之日。…`

第 3 段的 X 與第 2 段相同；n(j)、N(j) 與配息觀察日的天數不推算（核對規則 §2）。

## 4. 範本內的變化維度

### 4.1 配息門檻（= 執行價）

n(j) 數的是「籃子中表現最差的連結標的之收盤價等於或大於其**執行價**」的天數，價格表沒有另外的配息門檻欄：配息門檻 % = 第 16 項執行價表頭的 %，每檔配息門檻價格 = 執行價（不另核）。2 份都一樣。

### 4.2 保證期數（對應 Non-Call）

| 項目 | MD1、MD2 |
|---|---|
| §2.1 第 2 段 | `每單位配息金額(1)`（g = 1） |
| §2.1 第 6 段 | `j 係為2 至N`（a = g + 1） |
| 第 17 項 | `記憶事件觀察日：每日觀察，為自第1 個配息週期終止日…`（Non-Call = 1） |
| 第 18 項 | 每個情境的 `本商品第1 個月發放固定配息`（情境二～四後接 `，而後發放浮動配息`） |

g、a − 1 與 Non-Call 三者相同。

### 4.3 情境分析（第 18 項）

標題同 FCN 可提前出場型（`情境一:較佳情況 A`、`情境二：較佳情況B`、`情境三：一般情況`、`情境四：較差情況`、`情境五：發行機構無法履約`），假設段（總投資金額、年期、月配息率）與重印價格表同 FCN。

| 情境 | 假設 | 算式 |
|---|---|---|
| 一 | 第 1 個配息週期終止日提前出場 | 只有第 1 期固定配息：`面額×X% = A`、損益 `= 面額+A x1-面額`、年化報酬率 = 年利率（同 FCN） |
| 二 | 第 2 期一半天數符合後提前出場 | 第 1 期固定 `面額×固定配息率（X%） = 面額 美元×X% = A 美元`；第 2 期 `每單位商品面額×X%x（n/M） = 面額 美元×X%×（n/M） = B 美元`（前半段左邊是文字，最後一步才是數字算式）；損益 `= 面額 美元+A 美元x1+B 美元-面額 美元 = 損益 美元`；年化報酬率依天數假設算出 |
| 三 | 第 2～N 期一半天數符合、到期拿回本金 | 同上，第 2～N 期 `×（n/M）`；損益 `= 面額 美元+A 美元x1+Bx(N−1)-面額 美元 = 損益 美元`（B 後面沒有幣別字） |
| 四 | 從未提前出場、到期觸及下限、第 2～N 期天數為 0 | 第 1 期固定；第 2～N 期 `每單位商品面額×浮動配息率（X%）×（0/M） = 面額 美元×X%×（0/M） = 0 美元`；損益 `= A 美元x1+到期贖回價值 美元-面額 美元 = 損益 美元`（B = 0 的區間計息項不寫）；最差標的 `（代碼）收盤價 = P 美元小於其執行價 = K 美元`；股數、零股、到期贖回價值與年化報酬率（同 FCN 不核） |

`n/M` 是假設的天數。`B` 照第 15 項 (2) 四捨五入到 2 位；`B` 與損益用文件寫的 n/M 驗算（假設本身不核），情境二～四的年化報酬率依假設算出、不核（核對規則 §2、§3.7，workflow #578）。2 份樣本的寫法相同。情境四的句型是 `籃子中表現最差之連結標的（代碼）收盤價 = …`（FCN 是 `…連結標的（代碼）的收盤價 = …`），兩種都要讀得到。

## 7. 容易誤抓的地方

- MS FCN D 型也有 `{X%×n(j)/N(j)}`；家族要看 n(j) 定義**比執行價**（FCN 的 n(j) 是到提前出場日為止的天數），不能只看公式。
- §2.1 第 3 段跨行時 `×{` 可能落在下一行開頭（投資人須知就是這樣），比對前先接行去空白。
- 第 18 項情境四同時有 `收盤價 = P 美元小於其執行價 = K 美元` 與交割股數算式 `…/K美元`；執行價只取前者。
- 情境二、三的區間計息算式 `10,000.00 美元×X%×（n/M） = B 美元` 不是「面額 × 月配息率 = 每期配息」，不能被當成固定配息算式比金額。

## 8. 範本辨識

全部條件成立才判定為本範本；只符合部分條件，或同時符合多個範本，一律轉人工覆核。

1. MS 說明書骨架：`ms-zh-pd` §8 條件 1、2、5、6（封面標題、發行機構、第一章 §1 標題與條號 1–29、章名）；中文名稱以 `英商摩根士丹利發行` 開頭、含 `區間累積配息` 與 `結構型商品`；英文名稱以 `Morgan Stanley & Co. International Plc issuance of` 開頭、含 `Range Accrual Notes`（去空白比對）。
2. **商品家族（區間累積配息）**：第 15 項有 `{X%×n(j)/N(j)}`，且 n(j) 定義數的是 `…收盤價等於或大於其執行價的配息觀察日總數`（依計息公式辨識，workflow #366 決定 10）。

條件 1～2 成立後，再看現行版特徵，全部成立才是本範本；缺任一項 → **不支援的範本版本**（`template_unsupported`，錯訊列出缺的特徵）：

- §2.1 第 1～7 段（依序）；
- 第 14 項 (2) 讀得到交易日（只看寫法、不看早晚）。

和 `ms-zh-pd`、`ms-zh-ben-pd` 的關係：同一家上手由專到泛（#436），先試本範本、再試 BEN、FCN。本範本認得出商品家族但版本不支援時停在本範本、報「範本版本不支援」，不退回 FCN；本家族的標記是「全文有 `區間累積配息`」：有標記、但家族條件不成立的文件也停在本範本（範本未知、轉人工覆核）。MS FCN 的名稱條件（`固定配息`／`Fixed Coupon`）與 BEN 的名稱條件（排除 `區間累積`）本來就不收 DACN。

負面測試：MS FCN 樣本（全文沒有 `區間累積配息`，n(j) 是到提前出場日的天數）與 MS BEN 樣本不應被判定為本範本；其他上手的 DACN 樣本封面發行機構不是英商摩根士丹利，不應被判定為本範本；MS DACN 投資人須知（`_IIS`）不應被判定為說明書範本。

## 10. 日期之間的關係

同 `ms-zh-pd` §10 的 D 型（2 份都成立，開始受理贖回日期除外）：第 1 期起始日 = 發行日、起始日接前期終止日的下一個交易日、末期終止日 = 期末定價日、末期配息日 = 到期日。第四章開始受理贖回日期：MD1 = 發行日的次一臺北營業日；MD2 寫成發行日的次一日曆日，但那天是臺北的放假日 → 照 FCN 規則判不一致（核對規則 §6）。
