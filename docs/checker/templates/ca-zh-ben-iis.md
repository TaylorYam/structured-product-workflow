# 範本規格：東方匯理（CA）BEN 中文投資人須知

> 現行上手／樣態限制見[支援範圍](../support-matrix.md)。本文件的樣本數、探勘結論與日期決策保留當時觀察，不代表目前所有交易或公司上線驗收都已通過。

- 範本代號：`ca-zh-ben-iis`
- 對應說明書範本：[`ca-zh-ben-pd`](ca-zh-ben.md)；一檔商品一份說明書＋一份投資人須知（[ADR 0007](../adr/0007-iis-paired-with-term-sheet.md)）
- 依據：2026-10-30 對 5 份真實樣本（與說明書 BEN-CA01～BEN-CA05 同商品）的探勘與開發者螢光標記（workflow #377）。**作業人員獨立標記先略過，2026-10-30 使用者決定**
- 狀態：已實作（workflow #377）。標「待使用者確認（BEN-377-nn）」的是暫定的保守做法，編號對到本機疑慮記錄，全部列在 [CA BEN 核對規則](../rules/ca-ben-check-rules.md) §9.2

> 真實樣本與擷取文字只放在被 Git 忽略的 `data/`。本文件的數值範例都是虛構的。

本文件只寫和 [CA FCN 投資人須知](ca-zh-iis.md)（`ca-zh-iis`）不同的地方；文件特性（4 頁、頁底 `第N頁，共M頁`、CJK 相容字只換 U+F900～U+FAFF）、章名、警語、相關機構、二、1. 商品簡介標籤、標的表、贖回價金、發行不成立、費用表照 `ca-zh-iis`。和 [CA Super Bull 投資人須知](ca-zh-super-bull-iis.md) 相同的（沒有配息兩處）只寫出處。

## 1. 範本版本

| 版本 | 樣本 | 特徵 | 處理 |
|---|---|---|---|
| 現行版（Bonus） | BEN-CA02～BEN-CA05 | 二、1.(15) `配息日：本商品持有期間並無配息金額。`；二、2. 開頭無配息句、Bonus 公式、`參與率：X%。紅利率：X%。詳細請參見…` 行 | 本文件的規格 |
| Digital | BEN-CA01 | 二、1. 沒有 `配息日` 項（之後的編號少 1）；二、2. 公式 `每單位面額 x 紅利水準。`、`紅利水準：X%。詳細請參見…` | 不支援樣態，轉人工（待使用者確認（BEN-377-03），詳見本機疑慮記錄） |

4 份 Bonus 投資人須知的段落寫法相同（說明書的早期版、KO 價欄版殘留字句只在說明書）。版本依投資人須知本身的內容判斷；同一檔商品的說明書是不支援的範本版本時，投資人須知照說明書一起轉人工（同 CA Super Bull 投資人須知 §1；待使用者確認（BEN-377-01），詳見本機疑慮記錄）。

## 2. 和 FCN 投資人須知不同的段落

| 位置 | BEN 寫法（虛構範例） | 對應 |
|---|---|---|
| 第 1 頁名稱 | `Crédit Agricole CIB Financial Solutions 3 個月美元計價紅利結構型商品(無擔保) (不保本)`、`Crédit Agricole CIB Financial Solutions USD 3-Month Bonus Note (Unsecured)(Non-principal protected)` | 中英文名稱（樣本 2 份寫錯，§4） |
| 二、1.(15) | `配息日：本商品持有期間並無配息金額。` | 沒有配息 |
| 二、1.(19) | `開始受理贖回日及後續受理贖回日：…`（Digital 是 (18)） | 照 CA FCN，依標籤定位 |
| 二、2. 開頭 | `本商品主要給付項目為「到期贖回金額」，持有期間並無配息金額。` | 沒有配息、沒有 KO |
| 二、2. 到期 | `到期日給付視最差表現之的連結標的期末訂價而定，…`（樣本多「之」，照抄）；`（1） 若最差表現之連結標的期末訂價小於執行價，…及以美元支付剩餘金額（如有）;`、`（2） 若最差表現之連結標的期末訂價大於或等於執行價，則投資人可領回：`；沒有界限事件 | 無 KI、剩餘金額幣別字 |
| 二、2. 公式 | `每單位面額 x[100%+最大值(紅利率，參與率x(最差表現之連結標的期末訂價/最差表現之連結標的期初訂價)-100%))]。`（同說明書，括號不對稱照抄） | 到期公式 |
| 二、2. 參數 | `參與率：100.00%。紅利率：20.00%。詳細請參見中文產品說明書第一章第9 項之說明。`（一行） | 參與率、紅利 |

FCN 的 `配息率x%，換算年利率為y%`、`n/N` 句、自動提前出場事件句與觀察日項都沒有。

## 3. 欄位

| 欄位 | 出處 | 規則 |
|---|---|---|
| 紅利 | 二、2. `紅利率：X%。` | 數值 = 說明書第 9 項紅利率（= 參考條件表 `Coupon p.a. (%)`），比數值 |
| 參與率 | 二、2. `參與率：X%。` | 數值 = 說明書第 9 項參與率（= 參考條件表「參與率(%)」） |
| 沒有配息 | 二、1.(15)、二、2. 開頭 | 兩句都要有；沒有或不同 → 轉人工覆核 |
| KO | 二、2. 開頭 | 只有 `到期贖回金額`、全文沒有 `提前出場`；否則讀不到 |
| KI 型態 | 二、2. 到期 | 沒有界限事件、(1) 直接比執行價 → 無 KI；否則讀不到 |
| 到期公式 | 二、2. 公式 | 固定寫法 = 說明書第 9 項（忽略空白；括號照樣本，不另核對括號，BEN-377-06） |
| 月配息率、年利率、記憶式、KO 觀察 | — | 不適用 |

其餘欄位（代號、ISIN 兩處、商品種類、刊印日期、警語、風險等級、機構、幣別、標的代號、年期、期初訂價日（交易日）、發行日、期末訂價日、到期日、開始受理贖回日寫法、幣別字、費率、保證機構評等）照 `ca-zh-iis` §3。

## 4. 範本辨識條件

全部成立才算 `ca-zh-ben-iis`：

1. `ca-zh-iis` 的版面條件成立（`中文投資人須知` 開頭、章名一～七、發行機構 `Crédit Agricole CIB Financial Solutions`）。
2. 中文名稱含 `紅利結構型商品(無擔保)(不保本)`（忽略空白）、不含 `自動提前出場`、`連結表現`。
3. 英文名稱含 `Bonus` 與 `Note`，或含 `Digital Coupon Note`（忽略空白）。
4. 現行版特徵：二、2. 開頭無配息句、Bonus 公式、`參與率：…紅利率：…` 行；二、1.(15) 配息日句；全文沒有 `提前出場`。

條件 2、3 刻意寫寬：樣本有 1 份中文名稱多 `固定配息`（`…計價固定配息紅利結構型商品…`）、1 份英文名稱多 `Autocall`（`… Bonus Autocall Note …`），說明書都正確。名稱寫錯的投資人須知仍要辨識成 CA BEN，再由名稱規則（= 說明書、= 名稱樣板）判不一致、作業人員確認後人工放行（待使用者確認（BEN-377-04），詳見本機疑慮記錄）。`ca-zh-iis` 要 `計價固定配息自動提前出場結構型商品`，多 `固定配息` 的那份不會被認成 FCN。

- 條件 1～3 成立、是 Digital（英文 `Digital Coupon Note` 或 Digital 公式）→ 轉人工覆核（同說明書範本 §8；BEN-377-03）。
- 條件 1～3 成立、4 不成立 → **CA BEN 不支援的範本版本**：轉人工覆核，錯訊寫明「CA BEN 投資人須知寫法和現行版不同」（錯訊開頭是「目前樣態不支援自動核對：」，Issue #340；BEN-377-02）。

**商品種類一致**：辨識結果和參考條件表 Product 不一致 → 轉人工覆核（同說明書範本 §8）。

負面測試：CA FCN、FCN_Express、Super Bull 投資人須知不應被判定為本範本，本範本也不應被判定為它們；名稱多 `固定配息` 或 `Autocall` 的 CA BEN 投資人須知要判成本範本、名稱判不一致；CA BEN 說明書不應被判定為投資人須知。
