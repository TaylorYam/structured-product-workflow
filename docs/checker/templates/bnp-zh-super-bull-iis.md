## 3. 欄位

| 欄位 | 出處 | 規則 |
|---|---|---|
| 出場紅利 | 收益分配事項 `{100% + X%}` 的 X | = 說明書 §16 出場紅利（= 參考條件表 `Coupon p.a. (%)`） |
| KO 觀察方式 | 商品簡介 `● 自動提前贖回評價日：每N 個月一次` 或 `每月一次` | 讀到這兩種寫法之一 → `P`；寫法不在表內 → 讀不到 |
| 評價日間隔 N | 同上 | 說明書日期表的每個間隔（發行日 → 第 1 個評價日、相鄰評價日之間，月數依說明書範本 §4.1）都要 = N；`每月一次` 為 1；有任一不等 → 轉人工覆核（#309 決策） |
| 記憶式 | 自動提前贖回事件句 | 非記憶式句 → `N`；同 `bnp-zh-iis` §4.2 |
| KI 型態 | 到期贖回金額段 | 沒有觸及生效事件、到期條款是上表兩款 → 無 KI；否則讀不到 |
| 沒有配息 | `● 配息：不適用` | 只有這個寫法；沒有或不同 → 轉人工覆核 |
| 第一個可提前出場期 | — | 不寫（同 `bnp-zh-iis` P 型；說明書另核對 Non-Call） |
| 月配息率 | — | 不適用 |

## 4. 範本辨識條件

全部成立才算 `bnp-zh-sb-iis`：

1. `bnp-zh-iis` 的條件 1、3、4 成立（標題、英文名稱有 `issued by BNP Paribas Issuance B.V.`、相關機構 1 發行機構）。
2. `刊印日期：日期` 之後緊接以 `法國巴黎銀行` 開頭、以 `(下稱「商品」)` 結束的中文名稱，且**不含** `固定配息`。
3. 英文名稱含 `Super Bull Early Redeemable Note`。
4. 依序出現 `本商品之投資風險警語：`、`壹、相關機構`、`貳、商品事項`、`商品簡介`、`收益分配事項及到期贖回金額之計算`、`發行不成立之處理`、`叁、投資風險`、`肆、投資人應負擔的各項費用`、`伍、相關機構之權利、義務及責任`、`陸、協助投資人權益保護之方式`。
5. 收益分配事項有 `● 配息：不適用`。

條件 1～3 成立、段名是 FCN 的 `收益分配事項、自動提前贖回金額及到期贖回金額之計算`、紅利寫 `{100.00% + X% }` → **Super Bull 舊版**：轉人工覆核，錯訊寫明「BNP Super Bull 舊版投資人須知（2026-06 以前的範本），不支援自動核對」。

**FCN 範本要補的條件**：`bnp-zh-iis` 的辨識目前不看名稱有沒有 `固定配息`；Super Bull 舊版投資人須知的段名和 FCN 相同，會被誤認成 FCN 投資人須知。實作時 `bnp-zh-iis` 加一條：中文名稱含 `固定配息`、英文名稱含 `Fixed Coupon`。

**商品種類一致**：辨識結果和參考條件表 Product 不一致 → 轉人工覆核（同說明書範本 §8）。

負面測試：BNP FCN 投資人須知不應被判定為本範本，本範本也不應被判定為 `bnp-zh-iis`；Super Bull 說明書不應被判定為投資人須知；其他上手的投資人須知不含 `issued by BNP Paribas Issuance B.V.`。
