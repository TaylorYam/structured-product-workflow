# 核對規則：MS DACN 中文產品說明書與投資人須知

- 文件側：[MS DACN 範本規格](../templates/ms-zh-dacn.md)（`ms-zh-dacn-pd`）、[MS DACN 投資人須知範本規格](../templates/ms-zh-dacn-iis.md)（`ms-zh-dacn-iis`）
- 下單側：參考條件表，見[參考條件表格式](../order-formats/reference-sheet.md)與 [MS DACN 下單資料格式](../order-formats/ms-dacn-reference.md)
- 商品：DACN（workflow ADR 0030、#366、#367）；第二波開放順序 Barclays → BNP → UBS → MS（路線圖 #551），本文件是 MS（workflow #550）
- 狀態：已實作（workflow #550）；情境二～四的區間計息驗算（§3.7）是規格（workflow #578，路線圖 #575，實作另開 PR；實作前照 #550 只核固定期配息與 X）。核對範圍以開發者凍結的螢光標記為準；**作業人員獨立標記不做（路線圖 #551 指示，同 DACN／BEN 第一波）**（§7）
- 本文件只寫和 [MS 核對規則](ms-check-rules.md)（FCN）不同或 DACN 特有的部分。沒提到的（審查標準、MS 版本固定警語與次數、受託機構、發行機構、信用評等、商品種類、幣別、費率、最低金額、發行價格、受託機構商品代號、開始受理贖回日期、名稱一致、標的代號、價格推算、KO／記憶式／KI 的內部一致、D 型日期表與比價日、期數與 `j 係為a 至N`、情境標題、假設與重印表、較差情境執行價）照 MS FCN D 型。共用的 DACN 規則（配息門檻、商品種類一致、沒有樣本的型態轉人工、保證期數 = Non-Call）和第一波 DACN、[Barclays DACN](barc-dacn-check-rules.md)、[BNP DACN](bnp-dacn-check-rules.md)、[UBS DACN](ubs-dacn-check-rules.md) 相同

## 1. 範圍

- 只支援現行版範本（範本規格 §1）；辨識得出是 MS DACN、但現行版特徵不成立 → 不支援的範本版本，轉人工覆核、不能人工放行（作業人員可改走「人工核對完成」，workflow ADR 0032）。版本只看寫法、不看交易日（同第一波，workflow #409；Issue #550 驗收條件的「2026-06 以前的舊版」照這個原則以寫法判斷）。
- 依第 15 項的 `{X%×n(j)/N(j)}` 與 n(j) 定義（比 `執行價`）辨識商品家族（workflow #366 決定 10）；名稱另當條件（`區間累積配息`／`Range Accrual Notes`，範本規格 §8）。同一家上手由專到泛：DACN → BEN → FCN（`issuers.py`，#436）。辨識結果和參考條件表 Product 不一致時轉人工覆核。
- 支援樣態內、但 DACN 沒有樣本的型態（非美元、單一標的、5 檔以上標的、KO 非記憶式、無 KI、KI 每日、保證期數或 Non-Call ≠ 1）→ 轉人工覆核，錯訊寫「待樣本驗證」（§3.1）。KI 每期觀察（MKI）照 workflow #386／#403 轉人工：MS 的不支援樣態清單已有 KI 每期觀察（[支援矩陣](../support-matrix.md)），參考條件表、說明書或投資人須知任一邊是 MKI 時整批先停在不支援樣態（`batch.variant`，停止條件核對、不能人工放行），不會走到本範本的核對規則；型態檢查的錯訊「每期觀察 KI 維持人工處理（#386）」只在清單拿掉 MKI 後才會出現。KO 每期觀察沒有 DACN 樣本：第 15 項沒有 `{X%×n(j)/N(j)}` → 商品家族條件不成立、範本無法辨識；有的話 → 型態檢查（§3.1）轉人工。兩條路都轉人工（範本規格 §4.5）。
- MS 上手支援樣態表照 FCN。
- 兩份都通過或人工放行才打 `TS`／`IIS` 的 `V` 並回填（ADR 0007）。

## 2. 不核對的項目

- 照 MS FCN §2。
- **區間計息的計算**：n(j)、N(j)、配息觀察日、各期配息金額（workflow #366 不在範圍內；ADR 0030 不追蹤每日計息）。第 15 項的 n(j)、N(j)、配息觀察日定義只當固定寫法（辨識，範本規格 §2.1）；`每單位配息金額(j)` 的 X 只當配息率出處（§3.3）。
- 第 10 項 `每月配息金額(若有)`、投資人須知商品簡介 11) `每月配息(若有)`（同 FCN 不核對第 10 項、商品簡介 11)）。
- 情境分析：**有區間計息算式 `×（n/M）` 的情境（樣本是情境二～四）的年化報酬率**不核對（依天數假設算出；FCN 獲利情境的年化報酬率 = 年利率，DACN 不成立，見 §3.7、§9）。假設的天數 n、M 與配息次數本身不核對，只拿來驗算每期配息與損益加總（§3.7）；展開到一半、左邊是文字的中間步驟（例：`每單位商品面額×X%x（n/M）`）不當算式比對。較差情境的股數、零股、假設收盤價、到期贖回價值同 FCN 不核對。

## 3. 核對規則

### 3.1 樣態與分流

| 檢查 | 規則 |
|---|---|
| 開放 | `[auto_check_products]` 的 `DACN` 加 `MS`；沒開放的上手照不支援樣態轉人工 |
| 範本版本 | 寫法和現行版不同 → 不支援的範本版本（`template.detect`，原因 `template_unsupported`），錯訊列出缺的特徵；不看交易日 |
| 商品種類一致 | 辨識到的範本商品家族 ≠ Product → 轉人工覆核（共用 `template.product_family`）；Product 空白視為 FCN |
| 沒有樣本的型態 | 說明書讀出的型態不是「美元計價、2～4 檔標的、KO 每日＋記憶式、KI 到期觀察、保證 1 期、Non-Call 1」（KO 每期觀察也在這裡）→ 轉人工覆核（`doc.template_variant`），錯訊寫出哪一項「待樣本驗證」；KI 每期觀察（MKI）由 MS 的不支援樣態清單先擋（`batch.variant`，§1），走不到這裡；清單拿掉 MKI 後才在這裡轉人工，錯訊寫「每期觀察 KI 維持人工處理（#386）」 |

### 3.2 參考條件表欄位（共用 `rules/reference.py`、`backfill.py`）

| 標準欄位 | 規則 | DACN 差異 |
|---|---|---|
| 商品代號、ISIN、幣別、面額、各日期、天期、K／KI／KO %、KO 型態、記憶式、KI 型態、標的、各標的價格、比價日 | 共用 `field.*`、`backfill.*` | 同 MS FCN D 型 |
| 年利率 | MS 說明書沒有年利率（同 FCN）：月配息率 = 年利率 ÷ 12、情境一年化報酬率 = 年利率（§3.3、§3.7） | 情境二～四的年化報酬率不比（§2） |
| 配息門檻 % | 第 16 項執行價表頭的 %（n(j) 比執行價，範本規格 §4.1）→ 共用 `field.coupon_barrier_pct`（表上有 `配息門檻(%)` 欄且有數字 → 和欄比；有欄但空白或 `-`、或沒有這欄 → 和 `K(%)` 比並註明；說明書讀不到 → 轉人工覆核） | 新 |

### 3.3 配息率

| 檢查 | 規則 |
|---|---|
| 月配息率 | 同 FCN：第 15 項 (2) `每單位配息金額(1) = … 固定配息率 (X%)` 的 X = 年利率 ÷ 12 half-up 到 4 位（`derive.monthly_coupon`；2 份成立） |
| 區間計息公式的 X | `每單位配息金額(j) = 每單位商品面額×{X%×n(j)/N(j)}` 的 X = 固定配息率（同 FCN D 型的 `{X%×n(j)/N(j)}`，每個出處一筆） |
| 第 18 項 | 假設 `月配息率=X%` 與每個情境算式的 `×X%`（含 `×X%×（n/M）`、`浮動配息率（X%）`）= 第 15 項（共用 `scenario.params`，同 FCN） |
| n(j)／N(j) | 不推算（§2） |

### 3.4 配息門檻

| 檢查 | 規則 |
|---|---|
| 配息門檻 % | §3.2：說明書值取第 16 項執行價表頭 %，證據附 n(j) 定義（說明為什麼是執行價） |
| 配息門檻價格 | = 每檔執行價，不另核（執行價照 FCN 推算核對） |

### 3.5 保證期數與 Non-Call

| 檢查 | 規則 |
|---|---|
| 保證期數 = Non-Call | 第 15 項 (2) `每單位配息金額(1)`（只寫第 1 期 → g = 1）= 第 17 項推得的 Non-Call（DACN 共用 `doc.guaranteed_periods`）；其他寫法沒有樣本 → 讀不到、轉人工覆核 |
| j 範圍 | `j 係為a 至N` 的 a = Non-Call + 1、N = 天期（同 FCN `doc.coupon_periods`；DACN 的 a 也 = g + 1） |
| 第 18 項情境 | 每個情境的 `本商品第g 個月發放固定配息` 推得的 g = 第 15 項的 g（每個情境一筆，`doc.scenario_guaranteed_periods`；同 UBS DACN 十四的交叉驗證）；寫法不同或找不到 → 讀不到、轉人工覆核 |
| 投資人須知 | 收益分配事項 `每單位配息金額(1)` 推得的 g = 說明書的 g（`iis.guaranteed_periods`，DACN 共用） |

### 3.6 名稱與審查標準

照 MS FCN（`issuer.ms`）。**商品名稱樣板 `issuer.ms.product_names.DACN`**（參考條件表 Product 是 DACN 時用；範本規格 §4.4）：

- 中文：`英商摩根士丹利發行{tenor}個月期{ccy_zh}計價連結{underlying_zh}區間累積配息{memory_zh}結構型商品(無保證機構)(無擔保)(不保本)(下稱「本商品」)`
- 英文：`Morgan Stanley & Co. International Plc issuance of {tenor} Months {ccy} Autocallable Range Accrual Notes linked to {underlying_en} (non-guaranteed)(unsecured)(non-principal protected)`
- `{memory_zh}`、`{underlying_*}` 與比對方式同 `issuer.ms.product_name`（英文沒有記憶式字樣；單一標的照 FCN 的 `single_*` 寫法，但單一標的沒有樣本，型態另轉人工 §3.1）。2 份樣本都符合。
- 投資人須知的名稱和說明書比（同 MS FCN 投資人須知）。

### 3.7 說明書內部交叉驗證與情境分析

照 MS FCN §3.5、§3.7。DACN 差異：

| 檢查 | DACN |
|---|---|
| 情境標題、假設、重印價格表 | 同 FCN |
| 沒有 `×（n/M）` 的情境（樣本是情境一：第 1 期提前出場） | 同 FCN：每期配息 = 面額 × 月配息率、損益 = 每期配息 × 假設期數、年化報酬率 = 年利率 |
| 有 `×（n/M）` 的情境（情境二～四） | 用文件自己寫的 n、M 驗算，假設值本身不核（workflow #578）：<br>① 固定配息那一期 `面額×X% = A` 照 FCN（A = 面額 × 月配息率，half-up 2 位）。<br>② 區間計息每期配息：只比最後一步的純數字算式 `面額 美元×X%×（n/M） = B 美元`；B = 面額 × X% × n ÷ M 四捨五入到 2 位（第 15 項 (2) 的 `四捨五入計算至小數點後第 2 位`），也要等於用月配息率（參考條件表年利率推得，同 ①）算的值；算式的面額 = 第一章面額；M 是 0 或讀不出最後一步 → 轉人工覆核。X 另由 `scenario.params` 核（§3.3）。<br>③ 損益加總：最後一步 `= 項+項+…-面額 = 損益`，每一項是 `金額（幣別）x 次數`，沒寫次數是 1 次。獲利情境第一項 = 面額（到期或提前出場拿回的本金）、較差情境最後一個加項是到期贖回價值（金額同 FCN 不核）；最後減的面額 = 第一章面額；損益 = 各項金額 × 次數加總 − 面額（各項已進位，直接相加，同 FCN 總配息 = 已進位的每期配息 × 期數；共用 `dacn.coupon_total`）。配息項：第一項配息 = A、次數 = 保證期數 g；其餘是區間計息項，金額 = 同情境區間計息算式的 B，次數合計 = 配息次數 − g（獲利情境的配息次數取假設段 `假設在第k 個配息觀察期間` 的 k、`假設在第a 至第N 個配息觀察期間` 的 N；較差情境 = 天期，同 FCN）；B = 0 的區間計息項可以不寫。同一情境出現兩個以上不同的 B，或損益裡的區間計息項對不到任何一個 B → 轉人工覆核（不猜是哪一個）。<br>④ 年化報酬率不核（§2）。 |
| 較差情境執行價 | 同 FCN（共用 `scenario.strike`）；DACN 句型 `籃子中表現最差之連結標的（代碼）收盤價 = P 美元小於其執行價 = K 美元` 也要讀得到（範本規格 §4.3） |

情境標題或算式找不到時轉人工覆核，不跳過後宣稱通過。

### 3.8 投資人須知

照[投資人須知核對規則](iis-check-rules.md) §3 的 MS 欄；不同的地方：

| 檢查點 | DACN |
|---|---|
| 名稱 | = 說明書（同 FCN） |
| 月配息率 | 收益分配事項固定配息率與 `{X%×n(j)/N(j)}` 的 X = 說明書（同 FCN D 型） |
| 保證期數 | `每單位配息金額(1)` 推得的 g = 說明書 g（`iis.guaranteed_periods`）；其他寫法沒有樣本 → 讀不到、轉人工覆核 |

## 4. 判定原則

同 MS FCN §4：必核欄位抓不到、抓到多個不同值、或寫法不在範本規格內，一律轉人工覆核。配息門檻、保證期數都由明確的固定寫法推得（Issue #297 的原則），不由關鍵字有無推測。

## 6. 試跑預期（實作 PR 的驗收）

以私人雲端倉庫的 2 份樣本、舊總表整理的參考條件表（加 `配息門檻(%)` 欄 = `K(%)`、不加、改錯三種）在本機跑完整核對：

- 其他規則除舊版參考條件表沒有評等欄的信用評等（同 FCN）外全部通過；情境二～四的固定期配息、區間計息每期配息與損益加總依 §3.7 驗算全部通過（workflow #578；本機試算 2 份樣本的最後一步算式與損益加總都和文件一致；落在進位點的幾處都不是無條件捨去，和第 15 項 (2) 寫的四捨五入一致）。
- 配息門檻沒有欄時和 K% 比、有欄時和欄比都通過；改錯時判不一致。
- MS FCN、BEN 與其他上手既有測試、本機真實樣本結果不變（MS FCN 全文沒有 `區間累積配息`）。
