# 核對規則：CA Super Bull 中文產品說明書與投資人須知

- 文件側：[CA Super Bull 範本規格](../templates/ca-zh-super-bull.md)（`ca-zh-sb-pd`）、[CA Super Bull 投資人須知範本規格](../templates/ca-zh-super-bull-iis.md)（`ca-zh-sb-iis`）
- 下單側：參考條件表，見[參考條件表格式](../order-formats/reference-sheet.md)與 [CA Super Bull 下單資料格式](../order-formats/ca-super-bull-reference.md)
- 商品：Super Bull（workflow ADR 0028、#309）；開放順序 BNP → CA → HSBC，本文件是 CA（workflow #312）
- 狀態：規格（workflow #312），尚未實作。核對範圍以開發者凍結的螢光建議清單為準，作業人員獨立標記略過（2026-10-28 使用者決定，§7）
- 本文件只寫和 [CA 核對規則](ca-check-rules.md)（FCN）不同或 Super Bull 特有的部分；Super Bull 共用的分流（§3.1）照 [BNP Super Bull 核對規則](bnp-super-bull-check-rules.md) §3.1。沒提到的（審查標準、固定警語、受託機構名稱與特例、發行機構名稱、保證機構評等、幣別代碼、費率、最低金額、受理申購日、刊印日期、價格推算、分割轉人工、連結標的公司介紹、名稱與 ISIN 交叉驗證、開始受理贖回日寫法）照 CA FCN

## 1. 範圍

- 只支援現行版範本（範本規格 §1：SB-CA01～SB-CA19、SB-CA29～SB-CA41）；舊版（■ 版、缺無配息句、x100% 版、三欄表）辨識出是 Super Bull 就轉人工覆核、不能人工放行。版本依範本內容判斷，不看交易日（2026-10-28 使用者決定）。
- 說明書與投資人須知都依商品家族辨識（`ca-zh-pd`／`ca-zh-sb-pd`、`ca-zh-iis`／`ca-zh-sb-iis`）；辨識結果和參考條件表 Product 不一致時轉人工覆核。
- 幣別：境外人民幣（CNH）轉人工覆核；其他幣別、單一標的與一籃子都開放（2026-10-28 使用者決定）。
- 兩份都通過或人工放行才打 `TS`／`IIS` 的 `V` 並回填（ADR 0007）。

## 2. 不核對的項目

- 照 CA FCN §2（保證機構與總代理人名稱、發行不成立門檻、期初定價和說明書的比對、`UL_n_Memo`、第三章 6.(4) 第三處受託機構名稱、連結標的中文名稱與交易所、警語 2～12 全文、第 17～25 項、第五～七章等）。
- 第 9 項 (2) 的定義段（期初訂價、期末訂價、收盤價、最差表現、單位數、剩餘金額、期末匯率）：只有文字。
- 13.(7)～(10)（觀察日參照、預定交易日、營業日、營業日慣例）；自動提前出場日的日期本身（只檢查晚於同列觀察日，#312 驗收條件）。
- 觀察日到出場日、期末訂價日到到期日的天數（只作參考）。
- 起單建檔的 `Observation Frequency (m)`（不在參考條件表）。
- 情境的條件句（`假設不曾發生任何自動提前出場事件…`）、情境三文末 `*在必要時，依期末匯率轉換為計價貨幣。`、`※ 請注意…`、`投資人請注意:` 段。
- 境外人民幣的第八章（替代貨幣條件）與章節交叉引用（境外人民幣轉人工，不核對）。

## 3. 核對規則

### 3.1 樣態與分流

| 檢查 | 規則 |
|---|---|
| 開放 | `[auto_check_products]` 的 `"Super Bull"` 加 `CA`（#312）；沒開放的上手照不支援樣態轉人工 |
| 樣態 | 參考條件表 KO(Freq) = `P`、KO(memo) = `N`、KI(Freq) = `-`；任一不符 → 照不支援樣態轉人工（共用，同 BNP Super Bull §3.1） |
| 範本版本 | 舊版 → 轉人工覆核（同不支援樣態），錯訊寫明舊版 |
| 商品種類一致 | 範本辨識的商品家族 ≠ Product → 轉人工覆核，錯訊寫出 Product 與辨識到的範本（共用 `template.product_family`） |
| CA 限定 | 承作幣別 CNH → 轉人工覆核；觀察日表各列 KO% 或紅利不同 → 轉人工覆核（樣本都相同，#309 決策） |

BNP Super Bull 的「KO% ≠ K%、單一標的、非美元 → 轉人工」**不套用到 CA**：CA 現行版有這些樣本。

### 3.2 參考條件表欄位（共用 `rules/reference.py`、`backfill.py`）

語意同 CA FCN §3.1；CA Super Bull parser 只負責交出標準欄位。

| 標準欄位 | 規則 | Super Bull 差異 |
|---|---|---|
| 商品代號、ISIN、幣別、面額、各日期、天期、K%、KO%、標的、各標的價格、期初定價 | 共用 `field.*`、`backfill.*` | 同 CA FCN（交易日取期初訂價日；K%、KO% 取價格表表頭）；VWAP 照 #122 |
| `coupon_pa_pct` | 共用 `field.coupon_pa_pct` | 交出觀察日表的出場紅利；和 `Coupon p.a. (%)` 數值相等，**不年化** |
| `ki_type`、`ki_pct` | 共用 | 無 KI：KI(Freq) `-`、KI(%) `-` |
| Non-Call | 共用 `field.*`＋`field.non_call_product` | 第 1 個觀察日的月數；Super Bull 至少 1（`PRODUCT_RULES`） |
| 比價日 | 共用 `backfill.compare_dates` | 照 [CA Super Bull 下單資料格式](../order-formats/ca-super-bull-reference.md) §4：`比價日_m` = 觀察日、`比價日_{天期}` = 期末訂價日 |

### 3.3 出場紅利（CA Super Bull 專屬）

| 檢查 | 規則 |
|---|---|
| 主來源 | 觀察日表每列 `自動提前出場紅利`：每列相同（不同 → 轉人工覆核，§3.1）；讀不到 → 轉人工覆核 |
| 其他出處 | 16.(3) 基本假設 `自動提前出場紅利：x%`、情境一 `(100% + x%)`、投資人須知 二、2.(a) `自動提前出場紅利：x%`：每處數值 = 主來源，每處一筆結果 |
| KO 贖回金額 | 第 9 項 (a) `x(100%+自動提前出場紅利)`、投資人須知 二、2.(a) `× (100%+自動提前出場紅利)`：固定寫法；不同（例：`x100%`）→ 不一致 |

### 3.4 觀察日表與比價日（CA Super Bull 專屬，取代共用 §6.1 與 CA FCN P 型檢查）

Super Bull 沒有配息表，觀察日表只列觀察日；共用日期表檢查（[共用核對規則](shared-check-rules.md) §6.1）與 CA FCN 的「觀察日表列數 = 天期 − Non-Call + 1」「出場日在配息日表」不適用；parser 交出 `schedule_table` 為不適用，改核對下表。

| 檢查 | 規則 |
|---|---|
| 表的結構 | 表頭四欄 `自動提前出場觀察日`、`自動提前出場價`、`自動提前出場日`、`自動提前出場紅利`；至少 1 列；每列觀察日、出場日是日期，出場價、紅利是 % |
| KO% | 每列出場價 = 價格表表頭 KO%（數值相等）；不同 → 轉人工覆核（§3.1） |
| 月數 | 每個觀察日的月數 m（範本規格 §4.1）：和「發行日 + m 個月」差距 ≤ 7 個日曆天（樣本 ±3 天）；1 ≤ m < 天期；各列 m 遞增且不重複 |
| 順序 | 同列觀察日 < 出場日；觀察日逐列遞增；末列觀察日 < 期末訂價日 |
| Non-Call | = 第 1 列的 m |
| 比價日 | 由 m 與期末訂價日推得（§3.2），parser 直接交出提前出場排程 |

### 3.5 說明書內部交叉驗證

| 檢查 | 規則 |
|---|---|
| 沒有配息 | 第 9 項 (1) `本商品持有期間並無配息金額。`、13.(6) `配息日：本商品持有期間並無配息金額。`、15.(4) `最低保證配息率：不適用。本商品持有期間並無配息金額。`：三處都要有；沒有或不同 → 不一致（樣態佐證；現行版都有） |
| 非記憶式 | 第 9 項 (a) 事件句：多標的 `所有連結標的於預定自動提前出場觀察日之收盤價高於或等於自動提前出場價`、單一標的 `連結標的於預定…` → N（同 CA FCN `doc.ko_memory`，Issue #344）；投資人須知同句 |
| 無 KI | 全文沒有 `界限事件`、價格表沒有下限價欄、(b)(i) 直接比執行價：三者都成立才判無 KI；任一不成立 → 讀不到 |
| 到期公式 | (b)(ii) `x [100%+100%* (最差表現連結標的期末訂價/最差表現連結標的執行價-100%)]`（單一標的 `連結標的…`）、15.(5) `參與率：不適用。`：固定寫法（忽略空白），不同 → 不一致 |
| 價格 | 共用 `derive.prices`：執行價 = 期初訂價 × K%、自動提前出場價 = 期初訂價 × KO%（4 位）；價格表列數 = 第 10 項標的數；沒有下限價欄 |
| 名稱、ISIN、幣別、期數 | 同 CA FCN §3.5（`doc.name_consistency`、`doc.isin_consistency`、`doc.currency_consistency`；期數 = 名稱 `N 個月`／`N-Month` = 13.(1) = 基本假設天期） |
| FCN 專屬規則 | 配息表、月配息率、最低保證配息率月數、`doc.redemption_pct`（固定 100%）、第一期整期配息句不適用 |

### 3.6 審查標準

照 CA FCN（`issuer.ca`：固定警語 CA 版本 3 次、風險等級寫法、發行機構名稱、商品種類 `股權連結結構型商品`、受託機構名稱與特例、費率、發行價格 100%）。風險等級的期望值同 FCN：參考條件表「風險等級」（流程自算，Super Bull 用同一個公式）。

只有**商品名稱樣板**不同（依 Product 選樣板，見[審查標準](review-standard.md) §2.15；設定 `[issuer.ca.product_names."Super Bull"]`，同 BNP）：

- 中文：`Crédit Agricole CIB Financial Solutions {tenor} 個月{ccy_zh}計價連結表現自動提前出場結構型商品(無擔保) (不保本)`
- 英文：`Crédit Agricole CIB Financial Solutions {ccy} {tenor}-Month Performance Autocall Note (Unsecured)(Non-principal protected)`
- 只有天期、幣別兩個佔位符；比對方式（截到 `(ISIN：` 之前、忽略空白、括號統一）同 CA FCN。

### 3.7 情境分析（16.(3)；#309 決策：照 FCN 重算核對）

共用 `scenario.reprint`（情境價格表逐格與表頭 % = 第 9 項價格表）照用。共用 `scenario.params` 只交天期、每單位面額、初始投資金額；情境年化報酬率不等於年利率，不交給共用規則，改由下表核對。

| 檢查 | 規則 |
|---|---|
| 情境種類 | 剛好三個：較佳情況、一般情況、較差情況（以標題判斷） |
| 基本假設 | `自動提前出場紅利：x%` = 出場紅利（§3.3） |
| 情境一 | 假設句 `假設於第1 個自動提前出場觀察日`；`= N × (100% + x%)` 的 N = 面額、x = 出場紅利；`= A` 的 A = 面額 × (100% + x%)（容許 ±0.01）；總報酬率 = x%（文件位數）；年化 = x × 12 ÷ 第 1 個觀察日的月數，half-up 到文件位數 |
| 情境二 | 假設收盤價 P ≥ 執行價 K（K = 價格表最差那一檔的執行價）；算式代入的面額、P、K 與 `(100% + r%)` 的 r = P ÷ K − 1；金額 = 面額 × P ÷ K，half-up 到 2 位（容許 ±0.01）；報酬率 = 金額 ÷ 面額 − 1（文件位數）；年化 = 報酬率 × 12 ÷ 天期，half-up 到文件位數 |
| 情境三 | 假設收盤價 P < 執行價 K；股數 = 面額 ÷ K **無條件去位到 3 位**；整數股數 = 股數取整；畸零股數 = 股數 − 整數股數；剩餘金額 = 畸零股數 × P，half-up 到 2 位（容許 ±0.01）；報酬率算式重寫的整數股數、P、剩餘金額、面額 = 前面各值；總報酬率 = (整數股數 × P + 剩餘金額) ÷ 面額 − 1（2 位，容許 ±0.01）；年化 = **未四捨五入的**總報酬率 × 12 ÷ 天期（2 位，容許 ±0.01） |
| 幣別字 | 情境金額與 `以X支付剩餘金額` = 承作幣別（同 CA FCN §3.1 `currency_others`） |

金額與報酬率容許 ±0.01 進位差（#312 驗收條件；探勘時 2 份需要）。情境標題、假設句或算式找不到 → 轉人工覆核，不跳過後宣稱通過。現行版文件真的寫錯（不是進位差）→ 判不一致，作業人員確認後人工放行。

和 BNP Super Bull 的差別：CA 情境三的年化報酬率要核對（開發者凍結清單有這項，§7；探勘時現行版全部可重算）；BNP 情境三、四的年化不核對。

## 4. 判定原則

同 CA FCN §4：必核欄位抓不到、抓到多個不同值、或寫法不在範本規格內，一律轉人工覆核；無 KI、非記憶式、沒有配息都要由明確的句子判定（Issue #297）。
