# 核對規則：Natixis DACN 中文產品說明書與投資人須知

- 文件側：[Natixis DACN 範本規格](../templates/natixis-zh-dacn.md)（`natixis-zh-dacn-pd`）、[Natixis DACN 投資人須知範本規格](../templates/natixis-zh-dacn-iis.md)（`natixis-zh-dacn-iis`）
- 下單側：參考條件表，見[參考條件表格式](../order-formats/reference-sheet.md)與 [Natixis DACN 下單資料格式](../order-formats/natixis-dacn-reference.md)
- 商品：DACN（workflow ADR 0030、#366、#367）；開放順序 Nomura → SG → DBS → Natixis，本文件是 Natixis（workflow #371）
- 狀態：規格；實作另開 PR（workflow #371）。核對範圍以開發者凍結的螢光標記為準；**作業人員獨立標記先略過，2026-10-30 使用者決定**（§7）
- 標「待使用者確認」的是暫定的保守做法（轉人工覆核、不放行、不臆測），詳見本機疑慮記錄（DACN-371-01～08）；使用者回覆後再更新本文件與實作
- 本文件只寫和 [Natixis 核對規則](natixis-check-rules.md)（FCN）不同或 DACN 特有的部分。沒提到的（審查標準、固定警語與次數、受託機構名稱與其他出處、發行機構名稱、信用評等、商品種類、幣別、費率、最低申購與贖回、受理申購日、刊印日期、審查通過日期、價格推算、表頭 %、KO／KI／記憶式的內部一致、KO 每日到最終評價日含不含（Issue #351）、日期表與比價日、連結標的公司介紹、開始受理贖回日寫法、受託機構商品代號）照 Natixis FCN。共用的 DACN 規則（配息門檻、商品種類一致、沒有樣本的型態轉人工）和 [Nomura DACN 核對規則](nomura-dacn-check-rules.md) 相同

## 1. 範圍

- 只支援現行版範本（範本規格 §1）；辨識得出是 Natixis DACN、但現行版特徵對不上或交易日早於 2026-06-01 → 不支援的範本版本，轉人工覆核、不能人工放行（待使用者確認，詳見本機疑慮記錄）。
- 依第 13 項的 `「變動配息金額」` 公式與 n 定義（`所有連結標的收盤價皆高於或等於配息界限價格之配息觀察日天數`）辨識商品家族，不靠標題（workflow #366 決定 10）；Natixis FCN 與 DACN 範本互斥（範本規格 §8）。辨識結果和參考條件表 Product 不一致時轉人工覆核。
- 沒有樣本的型態（KO 每期觀察、非記憶式、單一標的、KI 每期觀察、美元與日圓以外的幣別、保證期數不是 1）→ 轉人工覆核，錯訊寫「待樣本驗證」（§3.1；KI 每期觀察的 DACN 另見 workflow Issue #386；待使用者確認，詳見本機疑慮記錄）。
- 兩份都通過或人工放行才打 `TS`／`IIS` 的 `V` 並回填（ADR 0007）。

## 2. 不核對的項目

- 照 Natixis FCN §2。
- **區間計息的計算**：n、N、各期配息金額、配息日（workflow #366 不在範圍內；ADR 0030 不追蹤每日計息）。n、N 只核對定義的固定寫法（辨識，範本規格 §2.1）。第 12 項 (13) `D. 配息觀察日為中斷日` 怎麼影響 n、N 不解讀。
- 記憶式「曾經」從哪一天起算：第 14 項句型和 Natixis FCN 相同（`皆曾經高於或等於`），照 FCN 判記憶式、KO 觀察起日照第 12 項 (8)，不另外解讀（待使用者確認，詳見本機疑慮記錄）。
- 第 13 項 (b) 的 `配息界線價格`（和 (a) 的 `配息界限價格` 不同字）：當成現行版固定寫法，不報錯；更正成 `配息界限價格` 也收（待使用者確認，詳見本機疑慮記錄）。
- 第 16 項情境：假設 g. `預定交易日(N)`、各情境 `x (n/N)` 的假設天數、配息金額、累積配息、股數、剩餘現金；情境一以外的平均年化報酬率（假設計息一半天數，不是年利率）。
- 投資人須知配息公式與 n、N 定義和說明書寫法不同的字句（各自當固定寫法，不互相比對；投資人須知範本規格 §1.1）。

## 3. 核對規則

### 3.1 樣態與分流

| 檢查 | 規則 |
|---|---|
| 開放 | `[auto_check_products]` 的 `DACN` 加 `NATIXIS`（實作 PR）；沒開放的上手照不支援樣態轉人工 |
| 範本版本 | 寫法和現行版不同、或交易日早於 2026-06-01 → 不支援的範本版本（`template.detect`，原因 `template_unsupported`），錯訊列出缺的特徵 |
| 商品種類一致 | 辨識到的範本商品家族 ≠ Product → 轉人工覆核（共用 `template.product_family`）；Product 空白視為 FCN |
| 沒有樣本的型態 | 說明書讀出的型態不是「KO 每日觀察＋記憶式、多標的、KI 無／到期／每日觀察、美元或日圓、保證期數 1」→ 轉人工覆核（`doc.template_variant`），錯訊寫出哪一項「待樣本驗證」 |

### 3.2 參考條件表欄位（共用 `rules/reference.py`、`backfill.py`）

| 標準欄位 | 規則 | DACN 差異 |
|---|---|---|
| 商品代號、ISIN、幣別、面額、各日期、天期、K／KO／KI %、KO／KI 型態、記憶式、標的、各標的價格、期初定價、比價日 | 共用 `field.*`、`backfill.*` | 同 Natixis FCN |
| `coupon_pa_pct` | 共用 `field.coupon_pa_pct` | 同 FCN（第 13 項 `即年利率y%`） |
| `coupon_barrier_pct` | 共用 `field.coupon_barrier_pct`（§3.4） | 第一次用在 Natixis |
| Non-Call | 共用 `field.first_callable_period`＋`field.non_call_product` | 同 FCN D 型；另核 = 保證期數（§3.5） |

### 3.3 年利率與月配息率

| 檢查 | 規則 |
|---|---|
| 年利率、月配息率 | 照 Natixis FCN §3.3（年利率 = `Coupon p.a. (%)`；月配息率 = 年利率 ÷ 12 四捨五入到 4 位，`derive.monthly_coupon`；7 份成立） |
| 情境假設 f. | 年利率（共用 `scenario.params`，同 FCN） |
| 情境配息算式 | 每個情境每列 `面額 x X%`（保證期）與 `面額 x X% x (n/N)`（計息期）的 X = 第 13 項月配息率（共用 `scenario.params`，出處代號 `scenario_monthly_coupon`）；面額 = 第一章第 5 項面額（同 FCN 配息算式的面額） |
| 情境一年化 | `平均年化報酬率為Y%，即[…] x n=Y%` 的兩個 Y = 年利率（共用 `scenario.params`，同 FCN Issue #228）；其他情境不核對（§2） |

### 3.4 配息門檻（共用規則，所有上手的 DACN 共用）

同 [Nomura DACN 核對規則](nomura-dacn-check-rules.md) §3.4（共用 `field.coupon_barrier_pct`）：表上有「配息門檻(%)」欄且有數字 → 和說明書配息門檻比；有欄但空白或 `-` → 轉人工覆核；沒有這欄 → 和 `K(%)` 比並註明；說明書讀不到 → 轉人工覆核。Natixis 說明書配息門檻 = 第 9 項價格表 `配息界限價格(每日觀察)/執行價格` 欄頭 %（範本規格 §4.1；說明書沒有定義句，待使用者確認，詳見本機疑慮記錄）。

投資人須知有 `「配息界限價格」係指…之期初進場價格之X%` 定義句：X = 同商品說明書配息門檻（`iis.coupon_barrier_term_sheet`）；說明書讀不到時轉人工覆核。

### 3.5 保證期數

| 檢查 | 規則 |
|---|---|
| 主來源 | 第 12 項日期表 `配息金額` 欄：從第 1 期起連續 `固定配息金額` 的列數 g；之後全部 `變動配息金額`。夾雜、讀不到或列數 ≠ 日期表列數 → 轉人工覆核（`doc.guaranteed_periods`） |
| = Non-Call | 保證期數 g = 第 12 項 `從第k個配息觀察期間結束日(含)` 的 k；不同 → 不一致（`doc.guaranteed_periods`） |

### 3.6 說明書內部交叉驗證

照 Natixis FCN §3.5（名稱三處、幣別、期數、KO 型態、KO 每日到最終評價日含不含、Non-Call、KI 三處一致、日期表、情境價格表、受託機構商品代號）。不同的地方：

| 檢查 | DACN |
|---|---|
| 第 9 項表頭 % | 執行價格欄頭（`配息界限價格(每日觀察)/執行價格 (期初進場價格之X%)`）= 第 15 項執行價格定義（同 FCN `doc.table_header_pct`）；這一欄同時是配息門檻（§3.4） |
| KI 欄 | 價格表有無 `界限價格 (期初進場價格之Z%)` 欄（不含 `配息界限價格` 那一欄）與 KI 寫法一致（同 FCN `doc.ki_consistency`） |

### 3.7 審查標準

照 Natixis FCN（`issuer.natixis`）。只有**商品名稱樣板**不同：設定 `[issuer.natixis.product_names.DACN]`（參考條件表 Product 是 DACN 時用，同 Nomura、SG DACN 的做法）：

- 中文：`法國外貿銀行{tenor}個月{ccy_zh}計價區間計息(自動提前到期)連結一籃子標的結構型商品(不保本、無擔保及無保證機構)`
- 英文：`Natixis – {tenor}-Month {ccy} – Autocallable Daily Range Accrual Note Linked to Basket of Equities (Non-Principal Protected, Unsecured and Non-Guaranteed)`
- 只有天期、幣別兩個佔位符；比對方式（忽略空白、括號統一、`(Non Principal` 視同 `(Non-Principal`）同 FCN 樣板；投資人須知同一樣板。

### 3.8 情境分析（第一章第 16 項 (3)）

| 檢查 | 規則 |
|---|---|
| 假設 a.、c.～f. | 照 FCN（面額、天期、配息觀察期間數、KO 觀察寫法、年利率） |
| 重印價格表 | 照 FCN（共用 `scenario.reprint`） |
| 情境種類 | 照 FCN：情境一～四（無 KI 一～三）以 `情境N(` 切段；找不到或順序不對 → 轉人工覆核 |
| 配息列數 | 照 FCN：情境一 = Non-Call、其他 = 天期（`doc.coupon_periods`） |
| 保證期與計息期 | 每個情境第 1～g 列是保證期算式（沒有 `x (n/N)`）、之後是計息期算式（有 `x (n/N)`）；情境一只有前 Non-Call 列（`doc.scenario_terms`）。順序或列數不對 → 不一致 |
| 月配息率、面額、情境一年化 | §3.3 |
| 自動提前到期與到期贖回 %、情境一提前到期期別、實物交割算式執行價格、金額幣別 | 照 FCN |
| 其他 | 不核對（§2） |

### 3.9 投資人須知

照[投資人須知核對規則](../rules/iis-check-rules.md) §3 的 Natixis 欄與 [Natixis 核對規則](natixis-check-rules.md)（KO 定義寫法、KO 每日到最終評價日含不含、受託機構商品代號）；不同的地方：

| 檢查點 | DACN |
|---|---|
| B6 名稱 | = 說明書封面名稱（DACN 樣板） |
| 年利率、月配息率 | 照 FCN（`月配息率：x% (即年利率y%)`；共用 `field.coupon_pa_pct`、`iis.monthly_coupon`） |
| 配息界限價格 | `「配息界限價格」係指…之X%` 的 X = 說明書配息門檻（§3.4，`iis.coupon_barrier_term_sheet`） |
| 配息公式與 n、N 定義 | 固定寫法（辨識時依序比對，投資人須知範本規格 §1.1） |
| 發行價格 | 列項符號 `•` 或 `●` 都收（照 FCN 核對 100%） |

## 4. 判定原則

同 Natixis FCN §4：必核欄位抓不到、抓到多個不同值、或寫法不在範本規格內，一律轉人工覆核。配息門檻、保證期數都由明確的寫法推得（Issue #297 的原則：價格表欄頭、日期表 `固定配息金額`），不由關鍵字有無推測。

## 5. 探勘比對結果（2026-10-30）

探勘腳本（本機 `data/tmp/dacn_natixis/scripts/`：`explore_fcn_parser.py`、`dims.py`、`compare.py`）對 7 份說明書與投資人須知逐項比對舊總表（Product = DACN、TDCC 前三碼 328）與說明書內部一致性：

| 範圍 | 結果 |
|---|---|
| 現行 Natixis FCN parser 讀 DACN | 說明書除封面標題（頁尾英文名稱換行不同，沒被排除）、第 9 項與情境價格表（`配息界限價格(每日觀察)/執行價格` 欄含 `界限價格`，被當成 KI 欄）以外全部讀得到；投資人須知只差英文名稱與 1 份 `●發行價格`。7 份說明書與投資人須知都被判為範本不符（沒有被 FCN 範本誤判，但只因英文名稱不同，所以 FCN 範本要加互斥條件） |
| 參考條件表 | 代號、ISIN、幣別、面額、各日期、天期、K／KO／KI %、KO／KI 型態、記憶式、Non-Call、比價日、年利率全部一致 |
| 型態 | 7 份同一範本版本；KO 每日（從第 1 期結束日、到最終評價日不含）＋記憶式、Non-Call 1、保證 1 期；KI 到期 1 份、每日 5 份、無 1 份；美元 6 份、日圓 1 份；3～4 檔標的 |
| 固定寫法 | 說明書第 13 項 (2) 七段 7 份逐字相同（日圓多捨去句）；投資人須知八段 7 份逐字相同 |
| 年利率與月配息率 | 月配息率 = 年利率 ÷ 12 四捨五入到 4 位（7 份）；情境假設 f.、情境一年化 = 年利率（7 份）；情境配息算式的 X = 月配息率 6 份，日圓那份不同（DACN-371-04，核對時判不一致） |
| 配息門檻 | 第 9 項、情境價格表欄頭 % = 執行價格 % = 投資人須知配息界限價格 % = 舊總表 `K(%)`（7 份） |
| 保證期數 | 日期表第 1 期 `固定`、其餘 `變動`；= Non-Call；各情境第 1 列保證期算式、其餘計息期算式（7 份） |

## 6. 試跑預期（實作 PR 的驗收）

以私人雲端倉庫的 7 份樣本、舊總表整理的參考條件表（加 `配息門檻(%)` 欄 = `K(%)` 與不加兩種）在本機跑完整核對：

- 全部辨識成 `natixis-zh-dacn-pd`／`natixis-zh-dacn-iis`；沒有一份被 Natixis FCN 範本認走。
- 美元 6 份說明書與投資人須知全部通過並回填（ISIN、發行日、比價日）；配息門檻沒有欄時和 K% 比、有欄時和欄比都通過；改錯配息門檻時判不一致。
- 日圓那份：情境配息算式的月配息率和第 13 項不同 → 判不一致（DACN-371-04），其他項目通過。
- Natixis FCN 與其他上手既有測試、本機真實樣本結果不變（FCN 辨識多一個條件，FCN 樣本都沒有 `變動配息金額`）。
