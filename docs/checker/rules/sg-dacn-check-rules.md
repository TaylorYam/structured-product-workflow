# 核對規則：SG DACN 中文產品說明書與投資人須知

- 文件側：[SG DACN 範本規格](../templates/sg-zh-dacn.md)（`sg-zh-dacn-pd`）、[SG DACN 投資人須知範本規格](../templates/sg-zh-dacn-iis.md)（`sg-zh-dacn-iis`）
- 下單側：參考條件表，見[參考條件表格式](../order-formats/reference-sheet.md)與 [SG DACN 下單資料格式](../order-formats/sg-dacn-reference.md)
- 商品：DACN（workflow ADR 0030、#366、#367）；開放順序 Nomura → SG → DBS → Natixis，本文件是 SG（workflow #369）
- 狀態：規格；實作另開 PR（workflow #369）。核對範圍以開發者凍結的螢光標記為準；**作業人員獨立標記先略過，2026-10-30 使用者決定**（§7）
- 標「待使用者確認」的是暫定的保守做法（轉人工覆核、不放行、不臆測），詳見本機疑慮記錄（DACN-369-01～08）；使用者回覆後再更新本文件與實作
- 本文件只寫和 [SG 核對規則](sg-check-rules.md)（FCN）不同或 DACN 特有的部分。沒提到的（審查標準、固定警語、受託機構名稱與負責人、發行機構／保證機構／總代理人名稱、信用評等、幣別、費率、最低金額倍數、受理申購日、刊印日期、價格推算、KO／KI／記憶式／標的數的內部一致、日期表、連結標的公司介紹、開始受理贖回日寫法）照 SG FCN。共用的 DACN 規則（配息門檻、商品種類一致、沒有樣本的型態轉人工）和 [Nomura DACN 核對規則](nomura-dacn-check-rules.md) 相同

## 1. 範圍

- 只支援現行版範本（範本規格 §1）；辨識得出是 SG DACN、但現行版固定寫法對不上或訂價日早於 2026-06-01 → 不支援的範本版本，轉人工覆核、不能人工放行（待使用者確認，詳見本機疑慮記錄）。
- 依第 8 項的區間累積配息公式（n(i)／N(i)）辨識商品家族，不靠標題（workflow #366 決定 10）；SG FCN 與 DACN 範本互斥（範本規格 §8）。辨識結果和參考條件表 Product 不一致時轉人工覆核。
- 沒有樣本的型態（KO 每期觀察、非記憶式、無自動提前出場、單一標的、KI 每日／每期觀察、非美元、保證期數不是 1 或 2）→ 轉人工覆核，錯訊寫「待樣本驗證」（§3.1；待使用者確認，詳見本機疑慮記錄）。
- 兩份都通過或人工放行才打 `TS`／`IIS` 的 `V` 並回填（ADR 0007）。

## 2. 不核對的項目

- 照 SG FCN §2。
- **區間累積配息的計算**：n(i)、N(i)、各期配息金額、配息日（workflow #366 不在範圍內；ADR 0030 不追蹤每日計息）。n(i)、N(i) 只核對定義的固定寫法（辨識，範本規格 §2.1）與期別範圍（§3.5）。中斷日如何影響每日計數不解讀（待使用者確認，詳見本機疑慮記錄）。
- 第 15 項情境：每個情境的 `配息週期`／`n(i)`／`N(i)` 假設表；各情境的配息金額、計息期中間百分比、累積總配息金額、贖回金額、總報酬率；情境三～五的平均年化報酬率；情境四、五的應實際交付數、現金交割、持有單位與現金結算總報酬率（計息期中間百分比進位不一致，範本規格 §4.3；待使用者確認，詳見本機疑慮記錄）。情境的幣別仍照 FCN 核對（Issue #170）。
- 投資人須知 n(i) 定義、記憶事件、到期贖回開頭和說明書寫法不同的字句（各自當固定寫法，不互相比對；範本規格見投資人須知 §1.1）。

## 3. 核對規則

### 3.1 樣態與分流

| 檢查 | 規則 |
|---|---|
| 開放 | `[auto_check_products]` 的 `DACN` 加 `SG`（實作 PR）；沒開放的上手照不支援樣態轉人工 |
| 範本版本 | 寫法和現行版不同、或訂價日早於 2026-06-01 → 不支援的範本版本（`template.detect`，原因 `template_unsupported`），錯訊列出缺的特徵 |
| 商品種類一致 | 辨識到的範本商品家族 ≠ Product → 轉人工覆核（共用 `template.product_family`）；Product 空白視為 FCN |
| 沒有樣本的型態 | 說明書讀出的型態不是「KO 每日觀察＋記憶式、多標的、KI 無或到期觀察、美元、保證期數 1 或 2」→ 轉人工覆核（`doc.template_variant`），錯訊寫出哪一項「待樣本驗證」 |

### 3.2 參考條件表欄位（共用 `rules/reference.py`、`backfill.py`）

| 標準欄位 | 規則 | DACN 差異 |
|---|---|---|
| 商品代號、ISIN、幣別、面額、各日期、天期、K／KO／KI %、KO／KI 型態、記憶式、標的、各標的價格、最低金額、比價日 | 共用 `field.*`、`backfill.*` | 同 SG FCN |
| `coupon_pa_pct` | 共用 `field.coupon_pa_pct` | 主來源改成第 8 項 `（相當於年配息率Y%）` |
| `coupon_barrier_pct` | 共用 `field.coupon_barrier_pct`（§3.4） | 第一次用在 SG |
| Non-Call | 共用 `field.first_callable_period`＋`field.non_call_product` | 同 FCN D 型；另核 = 保證期數（§3.5） |

### 3.3 年利率與配息率

| 檢查 | 規則 |
|---|---|
| 年利率 | 第 8 項 `（相當於年配息率Y%）` 剛好一處 = 參考條件表 `Coupon p.a. (%)`（共用 `field.coupon_pa_pct`）；讀不到或多處 → 轉人工覆核 |
| 配息率 | 第 8 項 `配息率 = X%` = 參考條件表年利率 ÷ 12，四捨五入（half-up）到 4 位（`derive.monthly_coupon`，同 SG FCN；10 份成立） |
| 第 15 項假設、各情境算式 | 假設 `配息率 = X %`、每個情境保證期配息算式與計息期配息算式（`…xX%x(n/N)`）的 X = 第 8 項配息率（共用 `scenario.params`） |
| 情境一、二 | `平均年化報酬率：Y%` = 年利率（共用 `scenario.params`，依說明書位數比；10 份成立） |

### 3.4 配息門檻（共用規則，所有上手的 DACN 共用）

同 [Nomura DACN 核對規則](nomura-dacn-check-rules.md) §3.4（共用 `field.coupon_barrier_pct`）：表上有「配息門檻(%)」欄且有數字 → 和說明書配息門檻比；有欄但空白或 `-` → 轉人工覆核；沒有這欄 → 和 `K(%)` 比並註明；說明書讀不到 → 轉人工覆核。SG 說明書配息門檻由第 8 項 n(i) 定義推得（`其執行價` → = `strike_pct`，範本規格 §4.1）。投資人須知不核對配息門檻。

### 3.5 保證期數與計息範圍

| 檢查 | 規則 |
|---|---|
| 主來源 | 第 8 項配息公式第一行 `第1個`／`第1~g個` → 保證期數 g |
| = Non-Call | 保證期數 = 日期表推得的第一個可提前出場期（`first_callable_period`）；不同 → 不一致（`doc.guaranteed_periods`） |
| 計息範圍 | 配息公式第二行 `第a~b個`、n(i) 與 N(i) 的 `(i=a-b)`：三處的 a 都 = g + 1、b 都 = 天期；不同 → 不一致（`doc.accrual_range`） |

### 3.6 說明書內部交叉驗證

照 SG FCN §3.5（受託機構商品代號、ISIN、名稱、幣別、期數、KO 觀察方式、記憶式、自動提前出場字樣、KI、最差表現 k 數、D 型日期表、自動提前出場日、贖回金額 100%、實體交付公式），只有一處不同：

| 檢查 | DACN |
|---|---|
| D 型 Non-Call（`schedule.autocall_dates`） | 第 Non-Call+1 期起始日 = 第 8 項記憶事件觀察期間起日、自動提前出場日為事件後第 3 個營業日照 FCN；FCN 的按比例條款 `第k-n個配息週期` 範本沒有，改由 §3.5 計息範圍核對 |

### 3.7 審查標準

照 SG FCN（`issuer.sg`）。只有**商品名稱樣板**不同：設定 `[issuer.sg.product_names.DACN]`（參考條件表 Product 是 DACN 時用，同 Nomura DACN、Super Bull 的做法）：

- 中文：`SG ISSUER {ccy_zh}計價{tenor}個月區間累積配息{autocall_zh}股權連結結構型商品（不保本及無擔保）`
- 英文：`SG ISSUER {ccy} {tenor}-month {memory_en}{autocall_en}Range Accrual Equity Linked Notes (Non Principal Guaranteed and Unsecured)`
- `autocall_*`、`memory_*`、幣別代碼、括號與空白的比對方式同 SG FCN 樣板；投資人須知同一樣板。

### 3.8 情境分析（第 15 項 (3)）

| 檢查 | 規則 |
|---|---|
| 假設 | `總投資金額 = U單位面額 = N`：N = U × 面額；`天期：n個月` = 天期；`配息率 = X %` = 第 8 項（共用 `scenario.params`） |
| 重印價格表 | 照 FCN（共用 `scenario.reprint`） |
| 情境種類 | 剛好五個，依序 `情境一：較佳情況(A)`、`情境二：較佳情況(B)`、`情境三：一般情況`、`情境四：較差情況`、`情境五：最差情況`；不同 → 轉人工覆核（`doc.scenario_terms`） |
| 期別 | 每個情境的保證期配息算式期別 = 第 1～g 期（g = 1 寫 `第1個`）；情境二計息期算式 = 第 g+1 期、情境三～五 = 第 g+1～天期（`doc.scenario_terms`）；算式找不到 → 轉人工覆核 |
| 配息率、情境一二年化 | §3.3 |
| 情境四、五數額算式執行價 | `數額計算 = 每單位面額 / … = 面額 / 執行價` 的執行價 = 假設的 `(k=n)` 那一檔的執行價（共用 `scenario.strike`，同 FCN） |
| 其他算式 | 不核對（§2） |

### 3.9 投資人須知

照[投資人須知核對規則](iis-check-rules.md) §3 的 SG 欄；不同的地方：

| 檢查點 | DACN |
|---|---|
| B6 名稱 | = 說明書封面名稱（DACN 樣板） |
| B16 年利率、配息率 | `（相當於年配息率Y%）` 的 Y = 參考條件表 `Coupon p.a. (%)`（共用 `field.coupon_pa_pct`）、= 說明書第 8 項（`iis.coupon_pa_term_sheet`）；`配息率 = X%` 的 X 同 SG FCN（共用 `iis.monthly_coupon`） |
| 保證期數與計息範圍 | 配息公式第一行的 g、第二行與 n(i)、N(i) 的範圍 = 說明書（`iis.guaranteed_periods`） |
| 配息公式與 n(i)、N(i) 定義 | 固定寫法（辨識時逐字比對，投資人須知範本規格 §1.1） |
| KO、記憶式、D 型觀察起日、KI、有無自動提前出場、受理贖回文字 | 照 SG FCN（`iis.has_autocall`、`iis.ko_observation_start` 等） |

## 4. 判定原則

同 SG FCN §4：必核欄位抓不到、抓到多個不同值、或寫法不在範本規格內，一律轉人工覆核。配息門檻、保證期數都由明確的固定寫法推得（Issue #297 的原則），不由關鍵字有無推測。

## 5. 探勘比對結果（2026-10-30）

探勘腳本（本機 `data/tmp/dacn_sg/scripts/`：`explore_fcn_parser.py`、`dims.py`、`compare.py`）對 10 份說明書與投資人須知逐項比對舊總表（Product = DACN、TDCC 前三碼 037）與說明書內部一致性：

| 範圍 | 結果 |
|---|---|
| 現行 SG FCN parser 讀 DACN | 說明書除年利率、配息率（寫法不同）與按比例條款（範本沒有）以外全部讀得到；投資人須知只差英文名稱與年利率。10 份說明書與投資人須知都被判為範本不符（沒有被 FCN 範本誤判，但只因英文名稱不同，所以 FCN 範本要加互斥條件） |
| 參考條件表 | 代號、ISIN、幣別、面額、各日期、天期、K／KO／KI %、KO／KI 型態、記憶式、Non-Call、比價日、年利率、各標的代號與四個價格全部一致 |
| 型態 | 10 份同一範本版本、新版面；全部美元、KO 每日＋記憶式、3～4 檔標的；保證 1 期 9 份、2 期 1 份（Non-Call 同）；KI 無 8 份、到期觀察 2 份 |
| 固定寫法 | 說明書配息公式、n(i)、KO 期 n(i) 句、N(i)、配息週期定義 10 份逐字相同；投資人須知另一種寫法也 10 份逐字相同 |
| 年利率與配息率 | 第 8 項年配息率 = 舊總表；配息率 = 年配息率 ÷ 12 四捨五入到 4 位；第 15 項假設、各情境算式配息率、情境一二年化都一致（10 份） |
| 保證期數與範圍 | 配息公式兩行、n(i)、N(i) 範圍、日期表 Non-Call、情境期別全部一致（10 份） |
| 情境 | 五個情境標題 10 份相同；計息期中間百分比進位不一致（DACN-369-05）→ 金額類不核對 |

## 6. 試跑預期（實作 PR 的驗收）

以私人雲端倉庫的 10 份樣本、舊總表整理的參考條件表（加 `配息門檻(%)` 欄 = `K(%)` 與不加兩種）在本機跑完整核對：

- 全部辨識成 `sg-zh-dacn-pd`／`sg-zh-dacn-iis`；沒有一份被 SG FCN 範本認走。
- 說明書與投資人須知全部通過並回填（ISIN、發行日、比價日）；VWAP 的 2 份價格照 #122；配息門檻沒有欄時和 K% 比、有欄時和欄比都通過；改錯配息門檻時判不一致。
- 保證 2 期的那份：保證期數 2 = Non-Call 2，照常通過。
- 投資人須知警語七「受託投資」：樣本交易日都在 #247 特例的截止日以前，照特例通過（DACN-369-08）。
- SG FCN 與其他上手既有測試、本機真實樣本結果不變（FCN 辨識多一個條件，FCN 樣本都沒有 n(i)／N(i)）。

| I08～I11 | 面額與發行價格、價格表、年期與日期、受理申購與贖回 | 照 FCN |
| I12 | 收益分配事項配息公式 | 範本辨識（固定寫法）；保證期數與計息範圍 = 說明書（§3.9） |
| I13 | 收益分配事項配息率與年配息率 | 年配息率 = `Coupon p.a. (%)`、= 說明書；配息率 = 年利率 ÷ 12（§3.9） |
| I14 | n(i)、N(i) 定義 | 固定寫法（投資人須知自己的寫法；不和說明書比文字） |
| I15、I16 | KO 事件與記憶事件、觀察起日；到期贖回各款 | 照 FCN |
| I17 | 肆 費用 | 照 FCN |

標記外、刻意不核對的段落見 §2。每條新規則實作時要有合成反例，特別是「正式條款正確、但其他出處錯」：第 8 項年配息率正確、配息率不是年利率 ÷ 12；第 15 項假設或某個情境算式的配息率錯；情境一或二年化錯；n(i) 定義改成別的價格（→ 不支援的範本版本）；配息公式第一行改成保證 2 期但日期表 Non-Call 1（不一致）；n(i) 或 N(i) 範圍和配息公式不同；情境少一個或標題不同；情境期別錯；參考條件表配息門檻 ≠ K%；配息門檻欄存在但空白；表上沒有配息門檻欄；Product 是 FCN 但文件是 DACN（及反過來）；FCN 說明書英文名稱誤寫成 DACN（兩邊都不符）；DACN 說明書英文名稱誤寫成 FCN（不被 FCN 認走）；訂價日早於 2026-06-01；投資人須知年配息率或保證期數和說明書不同。
