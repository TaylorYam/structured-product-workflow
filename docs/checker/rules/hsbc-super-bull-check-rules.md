# 核對規則：HSBC Super Bull 中文產品說明書與投資人須知

- 文件側：[HSBC Super Bull 範本規格](../templates/hsbc-zh-super-bull.md)（`hsbc-zh-sb-pd`）、[HSBC Super Bull 投資人須知範本規格](../templates/hsbc-zh-super-bull-iis.md)（`hsbc-zh-sb-iis`）
- 下單側：參考條件表，見[參考條件表格式](../order-formats/reference-sheet.md)與 [HSBC Super Bull 下單資料格式](../order-formats/hsbc-super-bull-reference.md)
- 商品：Super Bull（workflow ADR 0028、#309）；開放順序 BNP → CA → HSBC，本文件是 HSBC（workflow #314）
- 狀態：規格（workflow #314），尚未實作。核對範圍以開發者凍結的螢光建議清單為準，作業人員獨立標記略過（2026-10-28 使用者決定，§7）
- 本文件只寫和 [HSBC 核對規則](hsbc-check-rules.md)（FCN）不同或 Super Bull 特有的部分；Super Bull 共用的分流（§3.1）照 [BNP Super Bull 核對規則](bnp-super-bull-check-rules.md) §3.1，和 BNP、CA 相同的 Super Bull 規則（月數、順序、出場紅利、沒有配息、情境骨架）不重寫，只寫 HSBC 的出處與差異。沒提到的（審查標準、固定警語、受託機構名稱與負責人、發行機構名稱、信用評等、幣別、費率、最低金額、受理申購日、刊印日期、價格推算、連結標的公司介紹、開始受理贖回日寫法）照 HSBC FCN

## 1. 範圍

- 只支援現行版範本（範本規格 §1：SB-HS01～SB-HS05 的寫法）；辨識得出是 HSBC Super Bull、但寫法和現行版不同的說明書或投資人須知轉人工覆核、不能人工放行。版本依範本內容判斷，不看交易日（2026-10-28 使用者決定）。
- 說明書與投資人須知都依商品家族辨識（`hsbc-zh-pd`／`hsbc-zh-sb-pd`、`hsbc-zh-iis`／`hsbc-zh-sb-iis`）；辨識結果和參考條件表 Product 不一致時轉人工覆核。
- 沒有樣本的型態：單一標的、非美元計價、KO% ≠ K%、多個決定日 → 轉人工覆核；4 檔以上標的、VWAP → 開放、待樣本驗證（2026-10-28 使用者決定，同 BNP Super Bull）。
- 兩份都通過或人工放行才打 `TS`／`IIS` 的 `V` 並回填（ADR 0007）。

## 2. 不核對的項目

- 照 HSBC FCN §2（保證機構、`UL_n_Memo`、連結標的中文名稱與交易所、警語全文以外的段落、第五章等）。
- §11(1) 頻率句 `自動提前贖回事件頻率: …`（6 個月期只決定一次卻寫「每半年一次」；比價日以提前贖回表為準，#314 已確認）。
- §11(2) 的定義段（最差表現、期末股價、收盤價、連結標的股數、零股、期末匯率）：只有文字。
- §15(4) 評價日定義、§15(7)～(10)（含 (8) 自動提前贖回決定日參照）；付款日的日期本身（只檢查順序，§3.4）。
- 決定日到付款日、最後評價日到到期日的天數（只作參考）。
- 起單建檔的 `Observation Frequency (m)`（不在參考條件表）。
- 情境的示意股價與條件句（`期末股價為美元 P，高於…`、`以下情境分析之零股數僅供示意…`）、§18 重印表的幣別與交易所欄（SB-HS01 交易所欄放中文名稱）、本金虧損之機率段。
- 投資人須知 第三 贖回價金之計算（只參照說明書）。

## 3. 核對規則

### 3.1 樣態與分流

| 檢查 | 規則 |
|---|---|
| 開放 | `[auto_check_products]` 的 `"Super Bull"` 加 `HSBC`（#314）；沒開放的上手照不支援樣態轉人工 |
| 樣態 | 參考條件表 KO(Freq) = `P`、KO(memo) = `N`、KI(Freq) = `-`；任一不符 → 照不支援樣態轉人工（共用，同 BNP Super Bull §3.1） |
| 範本版本 | 寫法和現行版不同 → 轉人工覆核（同不支援樣態），錯訊寫明 |
| 商品種類一致 | 範本辨識的商品家族 ≠ Product → 轉人工覆核，錯訊寫出 Product 與辨識到的範本（共用 `template.product_family`） |
| HSBC 限定 | 只有 1 檔標的、承作幣別不是 USD、KO% ≠ K%、提前贖回表 2 列以上 → 轉人工覆核，錯訊寫明「待樣本驗證」（沒有樣本；範本規格 §4.1、§4.2） |

### 3.2 參考條件表欄位（共用 `rules/reference.py`、`backfill.py`）

語意同 HSBC FCN；HSBC Super Bull parser 只負責交出標準欄位。

| 標準欄位 | 規則 | Super Bull 差異 |
|---|---|---|
| 商品代號、ISIN、幣別、面額、各日期、天期、K%、KO%、各標的價格、期初定價 | 共用 `field.*`、`backfill.*` | 同 HSBC FCN；K% 取 §11(2) 定義句、KO% 取提前贖回表；VWAP 照 #122 |
| 標的 | 共用 `field.underlyings` | **以彭博代號配對、不看順序**（#314 已確認，下單資料格式 §5）；數量要相同。HSBC FCN 照舊依順序 |
| `coupon_pa_pct` | 共用 `field.coupon_pa_pct` | 交出 `自動提前贖回配息為X%`；和 `Coupon p.a. (%)` 數值相等，**不年化** |
| `ki_type`、`ki_pct` | 共用 | 無 KI：KI(Freq) `-`、KI(%) `-` |
| Non-Call | 共用 `field.*`＋`field.non_call_product` | 第 1 個決定日的月數；Super Bull 至少 1（`PRODUCT_RULES`） |
| 比價日 | 共用 `backfill.compare_dates` | 照 [HSBC Super Bull 下單資料格式](../order-formats/hsbc-super-bull-reference.md) §4：`比價日_m` = 決定日、`比價日_{天期}` = 最後評價日 |

### 3.3 出場紅利（自動提前贖回配息）

| 檢查 | 規則 |
|---|---|
| 主來源 | §11(1) `自動提前贖回配息為X%`；讀不到或有多個不同值 → 轉人工覆核 |
| 其他出處 | 提前贖回表每列 `贖回價` = 100% + X%；§18 假設 `自動提前贖回配息為X%`（或 `：X%`）；情境一 `(100% + X%)`：每處數值 = 主來源，每處一筆結果。**只比數值**，不管小數位數（SB-HS01 贖回價寫 2 位、SB-HS05 情境一紅利寫 3 位都算對，#314 已確認） |
| 假設句多出的字 | §18 假設那一行除了一個 % 數值外有其他數字（SB-HS05 `自動提前贖回配息：A%為X%`，A 是另一個數字）→ 不一致，作業人員確認後人工放行（#314 已確認） |
| KO 贖回金額 | §11(1) `支付贖回金額 = 每單位面額 × (100% + 自動提前贖回配息)`：固定寫法（忽略空白）；不同 → 不一致 |

### 3.4 提前贖回表與比價日（取代共用 §6.1 與 HSBC FCN P 型檢查）

Super Bull 沒有配息表，提前贖回表只列決定日；共用日期表檢查（[共用核對規則](shared-check-rules.md) §6.1）與 HSBC FCN 的「提前出場付款日 = 配息表付息日」不適用；parser 交出 `schedule_table` 為不適用，改核對下表（同 BNP、CA Super Bull 的 `schedule.observation_months`、`schedule.observation_order`）。

| 檢查 | 規則 |
|---|---|
| 表的結構 | 表頭四欄 `自動提前贖回價`、`自動提前贖回決定日`、`自動提前贖回付款日`、`贖回價`；至少 1 列；每列決定日、付款日是 `YYYY/M/D` 日期，自動提前贖回價、贖回價是 % |
| 列數 | 1 列；2 列以上 → 轉人工覆核（待樣本驗證，§3.1） |
| KO% | 每列自動提前贖回價 = 參考條件表 KO%；各列不同 → 轉人工覆核 |
| 月數 | 每個決定日的月數 m（範本規格 §4.1）：和「發行日 + m 個月」差距 ≤ 7 個日曆天（樣本都是當天）；1 ≤ m < 天期；各列 m 遞增且不重複 |
| 順序 | 同列決定日 < 付款日 < 到期日；決定日逐列遞增；末列決定日 < 最後評價日 |
| Non-Call | = 第 1 列的 m |
| 比價日 | 由 m 與最後評價日推得（§3.2），parser 直接交出提前出場排程 |

### 3.5 說明書內部交叉驗證

| 檢查 | 規則 |
|---|---|
| 沒有配息 | §16 `本商品不適用`、§17(1) 最低保證配息率 `本商品不適用`：兩處都要有；沒有或不同 → 不一致 |
| 非記憶式 | §11(1) 事件句 `若於任一自動提前贖回決定日，所有連結標的之收盤價皆大於或等於其自動提前贖回價，則自動提前贖回事件視同發生。`（忽略空白）→ N；其他句型 → 讀不到（沿用 `doc.ko_memory`） |
| 無 KI | 全文沒有 `觸及不保本`、§12(1) 沒有觸及不保本價格欄、§11(2) (1) 直接比執行價：三者都成立才判無 KI；任一不成立 → 讀不到 |
| 到期公式 | §11(2) (1) `若最差表現之連結標的期末股價小於執行價，以實物給付最差表現連結標的之股份數…及以現金支付零股部分。`、(2) `…大於或等於執行價：以現金給付 每單位面額x (最差表現連結標的期末股價/最差表現連結標的執行價)`、§17(2) 參與率 `本商品不適用`：固定寫法（忽略空白），不同 → 不一致 |
| 百分比 | §12(1) 表頭 `自動提前贖回價(即期初股價的X%)` = KO%、`執行價(即期初股價的X%)` = §11(2) 定義句 K%（**依欄名對**，KO 欄在執行價欄前面） |
| 價格 | 共用 `derive.prices`：自動提前贖回價 = 期初股價 × KO%、執行價 = 期初股價 × K%（half-up 4 位）；價格表列數 = 標的數；沒有觸及不保本價格欄 |
| 名稱、ISIN、幣別、期數 | 同 HSBC FCN（`doc.name_consistency`：§1 名稱 = 封面，中英文都比；期數 = 名稱 `N 個月` = §15(1) = §18 假設天期） |
| FCN 專屬規則 | 配息表、配息期數、月配息率、記憶式名稱對應、`doc.redemption_pct`、P 型提前出場表對付息日不適用 |

### 3.6 審查標準

照 HSBC FCN（`issuer.hsbc`：固定警語 HSBC 版本 3 次、投資人須知 2 次、風險等級、發行機構名稱、受託機構名稱與負責人、費率、發行價格 100%）。風險等級的期望值同 FCN：參考條件表「風險等級」（流程自算，Super Bull 用同一個公式）。

只有**商品名稱樣板**不同（依 Product 選樣板，見[審查標準](review-standard.md) §2.2；設定 `[issuer.hsbc.product_names."Super Bull"]`，同 BNP、CA）：

- 中文：`香港上海滙豐銀行{天期}個月{幣別中文}計價自動提前贖回股權連結（無保證機構無擔保）（不保本）結構型商品（以下簡稱「本商品」）`（投資人須知沒有「（以下簡稱「本商品」）」，同 FCN）
- 英文：`SuperBull Notes (Non Guaranteed, Unsecured)`；名稱前面多的字（例：`Maxi `）**不核對**（#314 已確認：SB-HS01 有 `Maxi`、其他 3 檔標的的沒有，看不出規則）。設定方式實作時定（例：英文只比結尾）。
- 只有天期、幣別兩個佔位符；比對方式（英文忽略所有空白、中文括號全半形不計）同 HSBC FCN。

### 3.7 情境分析（§18；#309 決策：照 FCN 重算核對）

共用 `scenario.reprint`（§18 重印表逐格與表頭 % = §12(1)，依代號對；沒有中文名稱欄，交易所欄內容不比）照用。共用 `scenario.params` 交天期、每單位面額、期初投資金額；情境年化報酬率不等於年利率，不交給共用規則，改由下表核對。

| 檢查 | 規則 |
|---|---|
| 情境種類 | 剛好三個：情境分析一（第 1 個決定日提前贖回）、二（到期 ≥ 執行價）、三（到期 < 執行價），以標題判斷 |
| 基本假設 | 天期 = §15(1)；面額、期初投資金額 = 面額 × 發行價格；期末匯率寫 `1 {幣別} = {幣別} 1.00`；`自動提前贖回配息` = 出場紅利（§3.3） |
| 情境一 | 標題 `於第 1 個自動提前贖回決定日`；`= N × (100% + x%)` 的 N = 面額、x = 出場紅利；`= A` 的 A = 面額 × (100% + x%)（容許 ±0.01）；損益 = A − 面額；年化 = x × 12 ÷ 第 1 個決定日的月數 |
| 情境二 | 算式 `= N × (P/K)` 的 N = 面額、K = 括號內最差表現標的（以 §12(1) 中文名稱對到列）的執行價、P ≥ K；金額 = N × P ÷ K，half-up 到 2 位（容許 ±0.01）；損益 = 金額 − 面額；年化 = 損益 ÷ 面額 × 12 ÷ 天期 |
| 情境三 | P < K（K 同情境二）；股數 = 面額 × 期末匯率 ÷ K（4 位，容許 ±0.0001）；交割股數 = 股數無條件捨去取整；零股數 = 股數 − 交割股數（4 位）；剩餘金額 = P × 零股數 ÷ 期末匯率，half-up 到 2 位；到期贖回價值 = P × 交割股數 ÷ 期末匯率 + 剩餘金額（2 位）；損益 = 價值 − 面額；年化 = 損益 ÷ 面額 × 12 ÷ 天期。金額容許 ±0.01 |
| 年化的寫法 | 文件寫「四捨五入至百分位後第二位」但整數不補 0（虛構例 `24%`、`120%`、`18.5%`）：重算值 half-up 到 2 位後和文件值**比數值**（容許 ±0.01，#314 已確認） |
| 幣別字 | 情境金額與 `以X支付` 的 X = 承作幣別（同 HSBC FCN §3.5 金額旁的幣別） |

情境標題、假設句或算式找不到 → 轉人工覆核，不跳過後宣稱通過。現行版文件真的寫錯（不是進位差）→ 判不一致，作業人員確認後人工放行（#314 已確認）。

## 4. 判定原則

同 HSBC FCN §4：必核欄位抓不到、抓到多個不同值、或寫法不在範本規格內，一律轉人工覆核；無 KI、非記憶式、沒有配息都要由明確的句子判定（Issue #297）。

## 5. 探勘比對結果（2026-10-28）

探勘腳本（本機 `data/tmp/superball_hsbc/explore.py`）對 5 份說明書與投資人須知逐項比對參考條件表（156 項）與說明書內部一致性（247 項），差異全部有解釋：

| 範圍 | 結果 |
|---|---|
| 參考條件表 | 差異只有 3 份的標的順序（以代碼對齊後一致，§3.2）；代號、ISIN、各日期、天期、K%、KO%、出場紅利 = `Coupon p.a. (%)`、Non-Call、比價日（決定日放 `比價日_{月數}`、最後評價日放 `比價日_{天期}`）、各標的價格全部一致 |
| 內部一致性 | 價格推算、兩張價格表、表頭 %、提前贖回表 KO% 與贖回價、名稱、ISIN、無配息、事件句、到期公式、情境一～三（金額、年化、股數）全部成立；年化寫成整數或 1 位小數、贖回價寫 2 位小數只是寫法差異（比數值通過） |
| 頻率句 | SB-HS01～SB-HS04 寫「每半年一次」但決定日在第 3 個月：不核對（§2） |
| 文件本身的問題 | SB-HS05 §18 假設有殘留數字：判不一致、人工放行（§3.3）；SB-HS01 §1 英文名稱寫成 `Maxi Bonus Enhanced Notes`（封面是 `Maxi SuperBull Notes`）：`doc.name_consistency` 判不一致、人工放行 |
| 範本辨識（現行程式） | 說明書被 `hsbc-zh-pd` 擋下（商品家族未知）；**投資人須知被 `hsbc-zh-iis` 判定成功**，會用 FCN 規則核對 → 實作時補商品家族條件（投資人須知範本規格 §4） |
