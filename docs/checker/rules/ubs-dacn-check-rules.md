# 核對規則：UBS DACN 中文產品說明書與投資人須知

- 文件側：[UBS DACN 範本規格](../templates/ubs-zh-dacn.md)（`ubs-zh-dacn-pd`）、[UBS DACN 投資人須知範本規格](../templates/ubs-zh-dacn-iis.md)（`ubs-zh-dacn-iis`）
- 下單側：參考條件表，見[參考條件表格式](../order-formats/reference-sheet.md)與 [UBS DACN 下單資料格式](../order-formats/ubs-dacn-reference.md)
- 商品：DACN（workflow ADR 0030、#366、#367）；第二波開放順序 Barclays → BNP → UBS → MS（路線圖 #551），本文件是 UBS（workflow #549）
- 狀態：規格（實作另開 PR）。核對範圍以開發者凍結的螢光標記為準；**作業人員獨立標記不做（路線圖 #551 指示，同 DACN／BEN 第一波）**（§7）
- 本文件只寫和 [UBS 核對規則](ubs-check-rules.md)（FCN）不同或 DACN 特有的部分。沒提到的（審查標準、UBS 版本固定警語與次數、受託機構、發行機構與倫敦分行、信用評等、商品種類、幣別、費率、最低金額與累加申購、提前贖回 1 倍面額、受理申購日、刊印日期、審查通過日期、受託機構商品代號、價格推算與分割轉人工、KO／記憶式的內部一致、D 型日期表與比價日、名稱一致、連結標的說明）照 UBS FCN。共用的 DACN 規則（配息門檻、商品種類一致、沒有樣本的型態轉人工、保證期數 = Non-Call）和第一波 DACN、[Barclays DACN](barc-dacn-check-rules.md)、[BNP DACN](bnp-dacn-check-rules.md) 相同

## 1. 範圍

- 只支援現行版範本（範本規格 §1）；辨識得出是 UBS DACN、但現行版特徵不成立 → 不支援的範本版本，轉人工覆核、不能人工放行（作業人員可改走「人工核對完成」，workflow ADR 0032）。版本只看寫法、不看交易日（同第一波，workflow #409）。
- 依八的 `變動配息率：x%X（nt/Nt）` 與 nt 定義（比 `區間下限價`）辨識商品家族（workflow #366 決定 10）；名稱另當條件（`區間累計配息`／`Range Accrual`，範本規格 §8）。同一家上手由專到泛：DACN → FCN（`issuers.py`，#436）。辨識結果和參考條件表 Product 不一致時轉人工覆核。
- 支援樣態內、但 DACN 沒有樣本的型態（非美元、單一標的、KO 每期觀察、有 KI、保證期數或 Non-Call ≠ 1）→ 轉人工覆核，錯訊寫「待樣本驗證」（§3.1）。KO 記憶式與非記憶式都有樣本（UD3 非記憶式），兩種都照常核對。KI 每期觀察（MKI）照 workflow #386／#403 轉人工，錯訊寫「每期觀察 KI 維持人工處理（#386）」。
- UBS 上手支援樣態表照 FCN（期初定價 VWAP、Non-Call = 天期不支援）。
- 兩份都通過或人工放行才打 `TS`／`IIS` 的 `V` 並回填（ADR 0007）。

## 2. 不核對的項目

- 照 UBS FCN §2。
- **區間計息的計算**：nt、Nt、交易所營業日、各期配息金額（workflow #366 不在範圍內；ADR 0030 不追蹤每日計息）。八的 `變動配息率`、nt、Nt 定義只當固定寫法（辨識，範本規格 §2.1）與配息率出處（§3.3）；十二 `交易所營業日：` 定義不核對。
- 八 `➢ 每月潛在配息：` 小標、價格表下 `上述區間下限價、轉換價、提前出場價將四捨五入…` 一句。
- 情境分析：十五設定參數 `假設每個觀察期間皆為M個交易所營業日` 的 M、情境算式的 `Xn/M`、第 2 期起的配息金額、累積配息、結算收益與**所有情境的平均年化報酬率**（依計息天數假設算出；UBS FCN 拿回本金情境的平均年化報酬率 = 年利率，DACN 不成立，見 §3.7、§9）。
- 投資人須知 `受託不成立之處理` 1.～3.、收益分配事項的配息後淨值例句。

## 3. 核對規則

### 3.1 樣態與分流

| 檢查 | 規則 |
|---|---|
| 開放 | `[auto_check_products]` 的 `DACN` 加 `UBS`；沒開放的上手照不支援樣態轉人工 |
| 範本版本 | 寫法和現行版不同 → 不支援的範本版本（`template.detect`，原因 `template_unsupported`），錯訊列出缺的特徵；不看交易日 |
| 商品種類一致 | 辨識到的範本商品家族 ≠ Product → 轉人工覆核（共用 `template.product_family`）；Product 空白視為 FCN |
| 沒有樣本的型態 | 說明書讀出的型態不是「美元計價、多標的、KO 每日（記憶式或非記憶式）、無 KI、配息表保證 1 期、Non-Call 1」→ 轉人工覆核（`doc.template_variant`），錯訊寫出哪一項「待樣本驗證」；KI 每期觀察照 #386 也在這裡轉人工，錯訊寫「每期觀察 KI 維持人工處理（#386）」 |

### 3.2 參考條件表欄位（共用 `rules/reference.py`、`backfill.py`）

| 標準欄位 | 規則 | DACN 差異 |
|---|---|---|
| 商品代號、ISIN、幣別、面額、各日期、天期、K／KO %、KO 型態、記憶式、標的、各標的價格、比價日 | 共用 `field.*`、`backfill.*` | 同 UBS FCN |
| `ki_type`、KI % | 共用 `field.*` | 3 份都沒有 KI（表上 `-`）；價格表的 `區間下限價` 欄不是 KI 的下限價欄（範本規格 §5.1） |
| `coupon_pa_pct` | 共用 `field.coupon_pa_pct`（八 `年化配息率為y%`） | 同 FCN |
| `coupon_barrier_pct` | 共用 `field.coupon_barrier_pct`（§3.4） | 第一次用在 UBS |
| Non-Call | 共用 `field.first_callable_period`＋`field.non_call_product` | 同 FCN D 型；另核 = 配息表保證期數（§3.5） |

### 3.3 配息率

| 檢查 | 規則 |
|---|---|
| 年利率 | 同 FCN：八 `固定配息率：x%。（年化配息率為y%）` 的 y = 參考條件表 |
| 月配息率 | 同 FCN：x = y ÷ 12 half-up 到 4 位（`derive.monthly_coupon`；3 份成立） |
| 變動配息率 | 八 `變動配息率：x%X（nt/Nt）（年化配息率為y%X（nt/Nt））` 的 x、y = 固定配息率那一句（`doc.coupon_mentions`，同 FCN D 型；DACN 的年化後面也有 `X（nt/Nt）`） |
| 其他出處 | 十五設定參數重複的固定、變動配息率與年化 = 八；情境算式 `X固定配息率X1=…XX%X1`、`X變動配息率=…XX%Xn/M` 的 X = 八的 x（共用 `scenario.params`，同 FCN 一筆帶出每一處） |
| `nt/Nt` | 不推算（§2） |

### 3.4 配息門檻（共用規則＋價格表內部核對）

| 檢查 | 規則 |
|---|---|
| 配息門檻 % | 八價格表表頭 `區間下限價(即期初價格的X%)` 的 X → 共用 `field.coupon_barrier_pct`（表上有 `配息門檻(%)` 欄且有數字 → 和欄比；有欄但空白或 `-`、或沒有這欄 → 和 `K(%)` 比並註明；說明書讀不到 → 轉人工覆核） |
| 配息門檻價格 | 八價格表每列區間下限價 = 該檔期初價格 × X%，half-up 到 4 位後相等（`doc.coupon_barrier`，同 Barclays、BNP、DBS DACN 的共用算法 `dacn.barrier_price`）；列數 = 標的數 |
| 情境價格表 | 十五情境價格表**含區間下限價欄**，共用 `scenario.reprint` 和八逐格比（期初、區間下限價、轉換價、提前出場價）與表頭 % |

### 3.5 保證期數與 Non-Call

| 檢查 | 規則 |
|---|---|
| 配息表保證期數 = Non-Call | 八配息表公式 `固定配息率` 的期別 1～g（g = 1）= 八提前出場觀察日推得的 Non-Call（DACN 共用 `doc.guaranteed_periods`；FCN D 型的 `doc.autocall_terms` 已核同一件事，DACN 照跑） |
| t 範圍 | `t係為a至b` 的 a = g + 1、b = 天期（八與十五設定參數；同 FCN `doc.autocall_terms`） |
| 十四 | `到期最低保證配息率：第一個月有固定配息` 推得的 g = 配息表 g（`doc.min_coupon_guarantee`，新）；其他寫法沒有樣本 → 讀不到、轉人工覆核 |

### 3.6 計息條件的標的範圍（UBS DACN 專屬）

| 檢查 | 規則 |
|---|---|
| nt 定義 | 多標的時，nt 定義要寫 `所有連結標的股票收盤價皆高於或等於區間下限價`（UD1、UD2）；寫成單一標的的 `連結標的股票收盤價高於或等於區間下限價`（UD3）→ 計息看哪幾檔不明確，轉人工覆核（`doc.accrual_scope`，新；錯訊寫出兩種寫法並提示向上手確認；**暫定做法，待使用者決定**，§9） |

### 3.7 說明書內部交叉驗證與情境分析

照 UBS FCN §3.5、§3.7。DACN 差異：

| 檢查 | DACN |
|---|---|
| 期數 | 配息表列數 = 天期 = 十五 `天期：N 個月` = 十五設定參數 `每月（共N個）`（同 FCN） |
| KI | 價格表沒有下限價欄（`區間下限價` 不算）、沒有 `觸及下限事件` 定義、到期日給付直接比轉換價 → 無 KI（同 FCN 的三者一致） |
| 價格表 | 欄序 區間下限價 → 轉換價 → 提前出場價（依表頭關鍵字，不寫死）；區間下限價欄要宣告，否則被當成 KI 的下限價欄 |
| 情境設定參數 | 同 FCN（天期、面額、發行價格、初始投資金額、`每月（共N個）`、提前出場觀察日、固定與變動配息率、t 範圍）；`M個交易所營業日` 不核對 |
| 情境一～三 | 算式代入的每單位面額與配息率 = 八（同 FCN）；每段金額旁的幣別 = 承作幣別（同 FCN）；**平均年化報酬率不核對**（FCN 拿回本金情境 = 年利率；DACN 依 `n/M` 假設算出，§2） |

情境標題或算式找不到時轉人工覆核，不跳過後宣稱通過。

### 3.8 審查標準

照 UBS FCN（`issuer.ubs`）。**商品名稱樣板 `issuer.ubs.product_names.DACN`**（參考條件表 Product 是 DACN 時用；範本規格 §4.6、§9）：

- 中文：`瑞銀{ko_observation_zh}{memory_zh}提前出場區間累計配息連結{underlying_zh}股票（不保本）（無擔保）（無保證機構）結構型商品`
- 英文：`UBS {ko_observation_en} {memory_en}Callable Variable Maturity Range Accrual Equity Linked{underlying_en} Notes`
- `{ko_observation_*}`、`{memory_*}` 與比對方式（括號、空白、句尾、`瑞銀（定期觀察）` 等價）同 `issuer.ubs.product_name`。**KO 每日觀察要寫 `每日觀察`／`Daily`（同 FCN 2026-10-15 的決定）；3 份樣本都寫 `定期觀察`／`Periodic` → 判不一致（暫定，待使用者決定，§9）**。
- `{underlying_*}`：多標的填 `一籃子`／`（Laggard）`；單一標的沒有樣本 → 名稱轉人工（`single_unsupported`）。**UD3（3 檔、非記憶式）沒有 `一籃子`／`（Laggard）` → 判不一致（暫定，待使用者決定，§9）**。
- KI 字樣：DACN 有 KI 沒有樣本（§3.1 轉人工），樣板不放 `{ki_*}`。
- 投資人須知同一樣板。

### 3.9 投資人須知

照[投資人須知核對規則](iis-check-rules.md) §3 的 UBS 欄；不同的地方：

| 檢查點 | DACN |
|---|---|
| 名稱 | 名稱樣板 `issuer.ubs.product_names.DACN`（§3.8）；= 說明書 |
| 保證期數 | 收益分配事項 `本商品第一個月支付固定配息，之後每月係給付潛在配息` 推得的 g = 說明書配息表保證期數（`iis.guaranteed_periods`）；其他寫法沒有樣本 → 讀不到、轉人工覆核 |
| 受託不成立之處理 | 不核對（FCN 是 `銷售不成立之處理`，也不核對） |

投資人須知沒有配息門檻、價格與配息率（同 UBS FCN 投資人須知），不報缺漏。

## 4. 判定原則

同 UBS FCN §4：必核欄位抓不到、抓到多個不同值、或寫法不在範本規格內，一律轉人工覆核。配息門檻、保證期數、計息範圍都由明確的固定寫法推得（Issue #297 的原則），不由關鍵字有無推測。

## 5. 探勘比對結果（2026-11-13）

探勘腳本（本機 `data/tmp/dacn_wave2/scripts/`）對 3 份說明書與投資人須知逐項比對舊總表（UD1～UD3）與說明書內部一致性：

| 範圍 | 結果 |
|---|---|
| 現行 UBS FCN parser 讀 DACN | 說明書：名稱條件不成立（辨識失敗）；配息表（公式前後相反）讀不到 → KO 觀察方式、Non-Call 讀不到；價格表的 `區間下限價` 被當成 KI 的下限價欄 → KI 型態不合法；其他（代號、ISIN、日期、天期、面額、K／KO %、年利率、記憶式、標的與期初價格、文件資訊）讀得到且和參考條件表一致。投資人須知：只有名稱條件不成立，其他欄位全部讀得到 |
| 參考條件表 | 代號、ISIN、面額、各日期、天期、K／KO %、KO 型態、記憶式、KI（`-`）、Non-Call、比價日（第 Non-Call 期與末期）、各標的代號與期初價格、年利率全部一致 |
| 型態 | 3 份同一範本版本；全部美元、KO 每日（含期末訂價日）、無 KI、3～4 檔標的、配息表保證 1 期、Non-Call 1；記憶式 2 份、非記憶式 1 份 |
| 固定寫法 | 範本規格 §2.1 五段 3 份相同（nt 定義 UD3 是單一標的寫法，§3.6）；投資人須知收益分配事項 3 份逐字相同 |
| 配息門檻 | 表頭 % 3 份都 = K %；每列區間下限價 = 期初 × %（half-up 4 位）；十五情境價格表同欄逐格相同 |
| 配息率 | 固定配息率 = 年化 ÷ 12（4 位）；變動配息率 x、y = 固定配息率那一句；十五重複處與情境算式的 X 相同 |
| 保證期數 | 配息表第 1 期固定、其後變動；十四 `第一個月`；投資人須知 `第一個月`；t 範圍起點 2；全部 = Non-Call 1 |
| 名稱 | 3 份都寫 `定期觀察`／`Periodic`（KO 都是每日）；UD3 沒有 `一籃子`／`（Laggard）`（§3.8） |
| 家族標記 | 本機 UBS FCN 說明書與投資人須知共 46 份全文都沒有 `區間下限價`、`區間累計配息`、`Range Accrual` |

## 6. 試跑預期（實作 PR 的驗收）

以私人雲端倉庫的 3 份樣本、舊總表整理的參考條件表（加 `配息門檻(%)` 欄 = `K(%)`、不加、改錯三種）在本機跑完整核對：

- 全部辨識成 `ubs-zh-dacn-pd`／`ubs-zh-dacn-iis`；沒有一份被 UBS FCN 範本認走。
- 依暫定做法：3 份說明書與投資人須知的商品名稱都判不一致（`定期觀察`）、UD3 另因沒有 `一籃子`／`（Laggard）` 判不一致、計息範圍轉人工覆核（§3.6）；其他規則除舊版參考條件表沒有評等欄的信用評等（同 FCN）外全部通過。
- 配息門檻沒有欄時和 K% 比、有欄時和欄比都通過；改錯時判不一致。
- UBS FCN 與其他上手既有測試、本機真實樣本結果不變（UBS FCN 全文沒有 `區間下限價`）。
