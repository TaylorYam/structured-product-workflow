# 核對規則：MS BEN 中文產品說明書與投資人須知

- 文件側：[MS BEN 範本規格](../templates/ms-zh-ben.md)（`ms-zh-ben-pd`）、[MS BEN 投資人須知範本規格](../templates/ms-zh-ben-iis.md)（`ms-zh-ben-iis`）
- 下單側：參考條件表，見[參考條件表格式](../order-formats/reference-sheet.md)與 [MS BEN 下單資料格式](../order-formats/ms-ben-reference.md)
- 商品：BEN（workflow ADR 0029、#372、#373、#374）；開放順序 HSBC → MS → CA，本文件是 MS（workflow #376）
- 狀態：規格；實作另開（workflow #376）。核對範圍以開發者凍結的螢光標記為準；**作業人員獨立標記先略過，2026-10-30 使用者決定**（§7）
- 標「待使用者確認（BEN-376-nn）」的是暫定的保守做法（轉人工覆核、不放行、不臆測、不覆蓋），編號對到本機疑慮記錄，全部列在 §9；使用者回覆後再更新本文件與實作。實作時每一項放在一個設定值或一個函式，方便日後改
- 本文件只寫和 [MS 核對規則](ms-check-rules.md)（FCN）不同或 BEN 特有的部分；和 [HSBC BEN 核對規則](hsbc-ben-check-rules.md) 相同的做法（沒有配息、無 KI、比價日只放期末定價日、紅利不年化、KO% 不核對、情境的交股算式、只比數值）只寫出處與差異。沒提到的（審查標準、MS 版固定警語、受託機構名稱電話地址與負責人、發行機構全名、信用評等、幣別、費率、最低金額、開始受理贖回日期、刊印日期、受託機構商品代號、商品種類、連結標的公司介紹）照 MS FCN

## 1. 範圍

- 只支援現行版範本（範本規格 §1：一般 BEN、Digital，各有 lookback）；辨識得出是 MS BEN、但寫法和現行版不同的說明書或投資人須知轉人工覆核、不能人工放行。版本依範本內容判斷，不看交易日（待使用者確認（BEN-376-05），詳見本機疑慮記錄）。
- 說明書與投資人須知都依商品家族辨識（`ms-zh-pd`／`ms-zh-ben-pd`、`ms-zh-iis`／`ms-zh-ben-iis`）；辨識結果和參考條件表 Product 不一致時轉人工覆核。
- 沒有樣本的型態：一般 BEN 單一標的或 4 檔以上、Digital 2 檔以上、非美元計價 → 轉人工覆核，錯訊寫「待樣本驗證」（待使用者確認（BEN-376-06），詳見本機疑慮記錄）。VWAP 有樣本，照 #122。
- 兩份都通過或人工放行才打 `TS`／`IIS` 的 `V` 並回填（ADR 0007）；回填多一個回顧結束日（§3.4）。
- 到期結算、回顧期初價格的計算不在本文件（比價，#374）。

## 2. 不核對的項目

- 照 MS FCN §2（總代理人、封面 7、8、11、12、第一章 §4、§8、§9、§12、§13、第五、六章等）。
- 第一章 §17～§28（BEN 的條號；FCN 的 §19～§29），§22 標題只用於範本辨識。
- §15 定義段的轉換匯率、最終實物贖回權益、畸零股說明；「籃子中表現最差的連結標的」定義只當固定句核對、不拿來判斷什麼（§3.5；待使用者確認（BEN-376-01），詳見本機疑慮記錄）。
- §14(6)～(8) 營業日說明；期末定價日到到期日的天數（只作參考）。
- 參考條件表 `KO(%)`、`UL_n_KO價`：說明書沒有 KO，照來源存、不核對（ADR 0029）。
- 情境的示意收盤價、情境說明句（含範本筆誤 `連接`）、情境四（只有文字）、本金虧損之機率段。
- 投資人須知 贖回價金之計算 2) 以後。

## 3. 核對規則

### 3.1 樣態與分流

| 檢查 | 規則 |
|---|---|
| 開放 | `[auto_check_products]` 的 `BEN` 加 `MS`（#376 實作時）；沒開放的上手照不支援樣態轉人工 |
| 樣態 | 參考條件表 KO(Freq) = `P`、KO(memo) = `N`、KI(Freq) = `-`、Non-Call = 天期；任一不符 → 照不支援樣態轉人工 |
| 範本版本 | 寫法和現行版不同 → 轉人工覆核（同不支援樣態），錯訊寫明（BEN-376-05） |
| 商品種類一致 | 範本辨識的商品家族 ≠ Product → 轉人工覆核，錯訊寫出 Product 與辨識到的範本（共用 `template.product_family`） |
| 型態一致 | 中文名稱、英文名稱、§10(a)、§15(1)(a)、§15(3) 參與率指向不同型態（一般 BEN／Digital）→ 轉人工覆核；Digital 五處全部成立才認（待使用者確認（BEN-376-03），詳見本機疑慮記錄） |
| lookback 一致 | §14(9)、§15 回顧期初價格與回顧執行價定義、§15(1) 比 `回顧執行價`、價格表沒有執行價欄、§16 重印表表頭 `回顧期初價格`：一起有或一起沒有；混雜 → 轉人工覆核 |
| MS BEN 限定 | 一般 BEN 1 檔或 4 檔以上、Digital 2 檔以上、承作幣別不是 USD → 轉人工覆核，錯訊寫明「待樣本驗證」（BEN-376-06） |

### 3.2 參考條件表欄位（共用 `rules/reference.py`、`backfill.py`）

語意同 MS FCN；MS BEN parser 只負責交出標準欄位。

| 標準欄位 | 規則 | BEN 差異 |
|---|---|---|
| 商品代號、ISIN、幣別、面額、各日期、天期、標的、期初定價 | 共用 `field.*`、`backfill.*` | 同 MS FCN；標的依順序比對（探勘全部同順序） |
| `strike_pct` | 共用 `field.strike_pct` | 非 lookback：執行價定義 X%；lookback：回顧執行價定義 X% |
| 各標的進場價、執行價 | 共用 `field.underlying_prices` | 進場價 = §15 期初價格（lookback 也是）；非 lookback 執行價 = 表上執行價欄；lookback 表上沒有執行價欄，**交出期初價格 × K%（half-up 4 位）當說明書執行價**（資料庫匯出也是這個值，#374） |
| `coupon_pa_pct` | 共用 `field.coupon_pa_pct` | 交出紅利（§15(1) `紅利配息率：X%`）；和 `Coupon p.a. (%)` 數值相等，**不年化**；MS FCN 的「範本沒有年利率、改比月配息率」不適用 |
| `participation_pct` | 共用參與率規則（#375 新增的 `doc.participation`，參考條件表那一側） | 說明書明寫 §15(3)，讀出值和參考條件表「參與率(%)」比（§3.3） |
| `lookback_end_date` | 新回填規則（§3.4） | 只有 MS BEN |
| `ko_pct`、KO 價 | 不適用 | 說明書沒有 KO；表上值不看（ADR 0029）；MS FCN 的「KO 視為 100%」不套用 |
| `ki_type`、`ki_pct`、下限價 | 共用 | 無 KI：KI(Freq) `-`、KI(%) `-`、`UL_n_下限價` `-` 或空白 |
| Non-Call | 共用 `field.*`＋`field.non_call_product` | = 天期（`PRODUCT_RULES` 的 BEN `maturity_only`） |
| 比價日 | 共用 `backfill.compare_dates` | 只有 `比價日_{天期}` = §14(5) 期末定價日，其他 `-` |

### 3.3 紅利與參與率

| 檢查 | 規則 |
|---|---|
| 紅利主來源 | §15(1) `紅利配息率：X%`（價格表之後那一行）；讀不到或有多個不同值 → 轉人工覆核 |
| 紅利其他出處 | §16 假設 `▪ 紅利配息率：X%`；一般 BEN 情境二 `x(100%+X%)`；Digital 情境一、二 `(100%+X%)`；投資人須知收益分配事項 `紅利配息率：X%`：每處數值 = 主來源，每處一筆結果，**只比數值** |
| 參與率主來源 | §15(3) `參與率：X%`；讀不到 → 轉人工覆核 |
| 參與率其他出處 | §16 假設 `▪ 參與率：X%`；投資人須知收益分配事項 `參與率：X%`：數值 = 主來源 |
| 參與率與型態 | 一般 BEN 公式 → 100、Digital 公式 → 0；§15(3) 和公式型態不符 → 轉人工覆核（型態一致，§3.1） |
| 參與率與參考條件表 | 數值 = 「參與率(%)」，不同 → 不一致；參考條件表沒有這欄或空白 → 轉人工覆核（同 HSBC BEN） |
| 最低保證贖回率 | §15(2)、§16 假設、投資人須知：固定句 `本商品不適用。本商品不保本。本商品於到期的本金贖回可能等於零。`（忽略空白）；不當成 0%、不當成參與率 |

### 3.4 回顧結束日（lookback，新）

| 檢查 | 規則 |
|---|---|
| 起點 | §14(9) `回顧觀察期間：自交易日（包含）起至…（包含）。` 固定寫法；不同 → 不一致 |
| 日期先後 | 交易日 < 回顧結束日 < 期末定價日；不成立 → 不一致（資料庫也擋，`product_terms`） |
| 共同交易日 | 回顧結束日是所有標的市場都開市的日子（交易所假日表；ADR 0029 共同交易日定義）；不是 → 不一致；假日表沒涵蓋 → 轉人工覆核 |
| 和參考條件表比、回填 | 照 [MS BEN 下單資料格式](../order-formats/ms-ben-reference.md) §5：表上空白 → 通過後回填資料庫 `lookback_end_date`（`check_source.write_back` 經 `product_terms.backfill`，原值記 `workflow.backfill_log`）；相同 → 一致；不同 → 不一致、不覆蓋、不能人工放行；已有回顧期初價格 → 只比對不回填；說明書沒有 §14(9) 但表上有值 → 不一致 |

以上整節是保守做法（待使用者確認（BEN-376-07），詳見本機疑慮記錄）。投資人須知沒有回顧結束日，不核對。

### 3.5 說明書內部交叉驗證

| 檢查 | 規則 |
|---|---|
| 沒有 KO | §10 開頭 `主要給付項目為到期贖回金額`、第一章沒有自動提前出場條（28 條）、全文沒有 `自動提前出場`：三者都成立才判沒有 KO；任一不成立 → 讀不到、轉人工覆核（明確句，#297） |
| 沒有定期配息 | §10 開頭句、§15 沒有配息條款、投資人須知收益分配事項開頭句（§3.7）；不同 → 不一致 |
| 無 KI | 全文沒有 `觸及`、價格表沒有下限價欄、§15(1)(b) 直接比執行價（lookback：回顧執行價）：三者都成立才判無 KI；任一不成立 → 讀不到 |
| 到期公式 | §15(1) 開頭句、(a)、(b) 是該型態、該 lookback 與否的固定寫法（範本規格 §2.1；忽略空白、去掉頁首頁尾）；§10(a) = §15(1)(a)；不同 → 不一致 |
| 定義句 | 非 lookback 執行價定義；lookback 回顧期初價格、回顧執行價定義；一般 BEN 最差表現定義（lookback 版仍寫期初價格，照抄、不判錯；BEN-376-01）：固定寫法，不同 → 不一致 |
| Digital 一籃子寫法 | §15(1) 開頭與投資人須知收益分配事項的 `籃子中表現最差的連結標的` 當固定句，不判錯（待使用者確認（BEN-376-04），詳見本機疑慮記錄） |
| 百分比 | 非 lookback：§15 價格表表頭 `（期初價格的X%）` = 執行價定義 K%（共用 `doc.price_header_pct`）；lookback：§16 重印表表頭 `（回顧期初價格的X%）` = 回顧執行價定義 K% |
| 價格 | 非 lookback：共用 `derive.prices`（執行價 = 期初價格 × K%，half-up 4 位）；價格表列數 = 標的數；沒有 KO 價欄、沒有下限價欄 |
| 標的代碼 | §11 標的表彭博代碼依序 = §15 價格表（同 MS FCN `doc.underlying_tickers`，條號改 §15） |
| 名稱、ISIN、幣別、受託機構商品代號、商品種類 | 同 MS FCN（§1 = 封面 4、§5 = 封面 9、封面 2 = 封面 1（空白判不一致）、封面 6 依標的數） |
| 期數 | 名稱 `N 個月` = §14(1) = §16 假設年期；MS FCN 的日期表期數、`j 係為…` 不適用 |
| FCN 專屬規則 | 月配息率、日期表、KO 觀察方式、記憶式、`doc.ko_column`、D／P 型日期規則不適用 |

### 3.6 審查標準

照 MS FCN（`issuer.ms`：MS 版固定警語 3 次、投資人須知 1 次、風險等級、發行機構全名、受託機構名稱電話地址與負責人、審查通過日期、費率、受託對象、發行價格 100%）。風險等級的期望值同 FCN：參考條件表「風險等級」。

只有**商品名稱樣板**不同（依 Product 選樣板，見[審查標準](review-standard.md) §2.6；設定 `[issuer.ms.product_names.BEN]`，同 HSBC BEN）。樣板依範本辨識出的型態選：

- 一般 BEN 中文：`英商摩根士丹利發行{天期}個月期{幣別中文}計價連結{underlying_zh}紅利表現結構型商品(無保證機構)(無擔保)(不保本)(下稱「本商品」)`；英文：`Morgan Stanley & Co. International Plc issuance of {天期} Months {幣別代碼} Bonus Enhanced Notes linked to {underlying_en} (non-guaranteed)(unsecured)(non-principal protected)`。
- Digital 中文：`英商摩根士丹利發行{天期}個月期{幣別中文}計價連結{underlying_zh}結構型商品(無保證機構)(無擔保)(不保本)(下稱「本商品」)`；英文：`… {幣別代碼} Equity Linked Notes linked to {underlying_en} (non-guaranteed)(unsecured)(non-principal protected)`。
- `{underlying_zh}`／`{underlying_en}` 同 MS FCN（1 檔／多檔兩組字串）；天期 1 個月英文用單數 `Month`（#343）；lookback 不改名稱；比對方式同 MS FCN（中文忽略空白、括號全半形不計；英文忽略所有空白）。

### 3.7 投資人須知

照 [MS 投資人須知範本規格](../templates/ms-zh-iis.md) 與[投資人須知核對規則](iis-check-rules.md) 的 MS 欄；不同的地方：

| 檢查點 | BEN |
|---|---|
| 名稱 | = 說明書封面名稱（BEN 樣板，依型態） |
| 年利率；月配息率 | 不適用 |
| 沒有定期配息 | 收益分配事項開頭 `於到期日，視期末定價日時籃子中表現最差的連結標的之收盤價而定。`（投資人須知範本規格 §3） |
| 紅利、最低保證贖回率、參與率 | = 說明書 §15(1)～(3)（§3.3） |
| 到期公式 | 贖回價金之計算 1) = 說明書 §15(1)（lookback 與否一致） |
| 商品簡介編號 | 開始受理贖回日期是 `11)`（FCN `12)`）；依標籤定位 |
| KO、KI、觀察日、記憶式 | 不適用；`贖回價金之計算：` 段沒有觸及下限事件與自動提前出場事件 |
| 回顧結束日 | 投資人須知沒寫，不核對 |

### 3.8 情境分析（§16；照 FCN 重算核對）

共用 `scenario.reprint`（§16 重印表逐格 = §15 價格表；lookback 重印表的回顧期初價格欄 = §15 期初價格、回顧執行價欄 = 期初價格 × K%）照用。共用 `scenario.params` 交總投資金額、年期；情境年化報酬率不等於年利率，不交給共用規則，改由下表核對。

| 檢查 | 規則 |
|---|---|
| 情境種類 | 三個計算情境＋情境四文字，以標題判斷（範本規格 §5）。一般 BEN：一 `較佳情況 A`（≥ 執行價、漲幅 > 紅利）、二 `較佳情況 B`（≥ 執行價、漲幅 < 紅利）、三 `最差情況`（< 執行價）；Digital：一 `較佳情況`（> 執行價）、二 `較佳情況`（= 執行價）、三 `最差情況` |
| 基本假設 | 總投資金額 = 面額；年期 = §14(1)；紅利、參與率 = §3.3 |
| 執行價與期初價格 | 情境寫的執行價（lookback：回顧執行價）= 最差表現標的在 §15（重印表）的執行價；一般 BEN 算式的 I = 該標的期初價格（lookback：回顧期初價格欄的值） |
| 一般 BEN 情境一、二 | 金額 A = 面額 × (100% + max(紅利, 參與率 × (P ÷ I − 1)))，half-up 到 2 位（容許 ±0.01）；情境一要漲幅 > 紅利、情境二要 < 紅利；報酬率 = (A − 面額) ÷ 面額；年化 = 報酬率 × 12 ÷ 天期 |
| Digital 情境一、二 | A = 面額 × (100% + 紅利)；情境一 P > K、情境二 P = K；報酬率、年化同上 |
| 交股情境（情境三） | P < K；股數 = 面額 × 期末匯率 ÷ K（4 位，容許 ±0.0001）；交割股數 = 無條件捨去取整；零股 = 股數 − 交割股數；剩餘金額 = P × 零股 ÷ 期末匯率（2 位）；到期贖回價值 = P × 交割股數 ÷ 期末匯率 + 剩餘金額（2 位）；損益 = 價值 − 面額；報酬率 = 損益 ÷ 面額，**先 half-up 到 2 位再年化**（MS 寫法，樣本 18 個交股情境都這樣）。金額容許 ±0.01 |
| 年化的寫法 | 重算值 half-up 到 2 位後和文件值比數值（容許 ±0.01） |
| 幣別字 | 情境金額旁的幣別 = 承作幣別（同 MS FCN `field.currency`） |

MS FCN 的情境規則（每期配息、總配息、獲利情境年化 = 年利率）不適用。情境標題、假設句或算式找不到 → 轉人工覆核，不跳過後宣稱通過。現行版文件真的寫錯（不是進位差）→ 判不一致，作業人員確認後人工放行（同 #314、#375）。

## 4. 判定原則

同 MS FCN §4：必核欄位抓不到、抓到多個不同值、或寫法不在範本規格內，一律轉人工覆核；沒有 KO、無 KI、沒有定期配息、參與率、lookback 與否都要由明確的句子或固定寫法判定（Issue #297），不由關鍵字有無推測。
