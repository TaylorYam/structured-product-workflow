# 核對規則：BARC DACN 中文產品說明書與投資人須知

- 文件側：[BARC DACN 範本規格](../templates/barc-zh-dacn.md)（`barc-zh-dacn-pd`）、[BARC DACN 投資人須知範本規格](../templates/barc-zh-dacn-iis.md)（`barc-zh-dacn-iis`）
- 下單側：參考條件表，見[參考條件表格式](../order-formats/reference-sheet.md)與 [BARC DACN 下單資料格式](../order-formats/barc-dacn-reference.md)
- 商品：DACN（workflow ADR 0030、#366、#367）；第二波開放順序 Barclays → BNP → UBS → MS（路線圖 #551），本文件是 Barclays（workflow #547）
- 狀態：已實作（workflow #547）；§16 一般、最差情況依假設天數的算式驗算（路線圖 #575、workflow #577）規格定案、待實作。核對範圍以開發者凍結的螢光標記為準；**作業人員獨立標記不做（路線圖 #551 指示，同 DACN／BEN 第一波）**（§7）
- 本文件只寫和 [BARC 核對規則](barc-check-rules.md)（FCN）不同或 DACN 特有的部分。沒提到的（審查標準、固定警語與次數、受託機構名稱與等價寫法、發行機構名稱、信用評等、商品種類、幣別、費率、最低金額、受理申購日、刊印日期、審查通過日期、價格推算、KO／KI／記憶式／標的的內部一致、§13(7) 自動提前出場觀察期表與比價日、名稱一致、連結標的公司介紹）照 BARC FCN。共用的 DACN 規則（配息門檻、商品種類一致、沒有樣本的型態轉人工、保證期數 = Non-Call）和第一波 DACN（[Nomura](nomura-dacn-check-rules.md)、[DBS](dbs-dacn-check-rules.md)…）相同

## 1. 範圍

- 只支援現行版範本（範本規格 §1）；辨識得出是 BARC DACN、但現行版特徵不成立 → 不支援的範本版本，轉人工覆核、不能人工放行。版本只看寫法、不看交易日（同第一波，workflow #409）。
- 依 §14 的配息率 t 公式與 nt 定義（比 `配息門檻`）辨識商品家族，不靠名稱（BARC DACN 名稱和 FCN 相同；workflow #366 決定 10）；同一家上手由專到泛，先試 DACN 範本、不符才試 FCN 範本（`issuers.py`，#436；範本規格 §8）。辨識結果和參考條件表 Product 不一致時轉人工覆核。
- 支援樣態內、但 DACN 沒有樣本的型態（非美元、單一標的、KO 不是每日記憶式、KI 每日觀察、保證期數或 Non-Call ≠ 1）→ 轉人工覆核，錯訊寫「待樣本驗證」（§3.1）。KI 每期觀察（MKI）照 workflow #386／#403 轉人工（BARC 說明書讀到 MKI 本來就轉人工）。
- 兩份都通過或人工放行才打 `TS`／`IIS` 的 `V` 並回填（ADR 0007）。

## 2. 不核對的項目

- 照 BARC FCN §2。
- **區間計息的計算**：nt、Nt、dt、Dt、實際各期配息率與配息金額（workflow #366 不在範圍內；ADR 0030 不追蹤每日計息；§16 情境依假設天數的試算另見 §3.9，要核）。§14 公式與定義只當固定寫法（辨識，範本規格 §2.1）；§14 配息觀察期表的 `預定交易日日數(Nt)` 欄不核對。
- §9(3) dt、Dt 的定義與中斷日說明（只核對兩處 `相關配息率為X%` 的 X）。
- 情境分析：一般情況、最差情況 `(n/N)` 寫的 n、N 本身（假設值；算式用文件寫的 n、N 驗算，§3.9）；三個情境的平均年化報酬率（一般情況依假設算出、不是年利率，有利、最差情況照 FCN；路線圖 #575 年化一律不核）；最差情況的交付股數、畸零股數、剩餘金額與每單位最終實物贖回權益等值本身（取決於假設最終價格，同 FCN 不核；總報酬率算式裡的等值要等於該段寫的等值，§3.9）。
- 投資人須知配息率 t 寫法和說明書 §14 字不同（各自當固定寫法，不互相比對文字）。

## 3. 核對規則

### 3.1 樣態與分流

| 檢查 | 規則 |
|---|---|
| 開放 | `[auto_check_products]` 的 `DACN` 加 `BARC`；沒開放的上手照不支援樣態轉人工 |
| 範本版本 | 寫法和現行版不同 → 不支援的範本版本（`template.detect`，原因 `template_unsupported`），錯訊列出缺的特徵；不看交易日 |
| 商品種類一致 | 辨識到的範本商品家族 ≠ Product → 轉人工覆核（共用 `template.product_family`）；Product 空白視為 FCN |
| 沒有樣本的型態 | 說明書讀出的型態不是「美元計價、多標的、KO 每日＋記憶式、KI 無或到期觀察、配息公式保證 1 期、Non-Call 1」→ 轉人工覆核（`doc.template_variant`），錯訊寫出哪一項「待樣本驗證」 |

### 3.2 參考條件表欄位（共用 `rules/reference.py`、`backfill.py`）

| 標準欄位 | 規則 | DACN 差異 |
|---|---|---|
| 商品代號、ISIN、幣別、面額、各日期、天期、K／KO／KI %、KO／KI 型態、記憶式、標的、各標的價格、比價日 | 共用 `field.*`、`backfill.*` | 同 BARC FCN |
| `coupon_pa_pct` | 範本沒有年利率（`absent`，共用 `field.coupon_pa_pct` 判不適用） | 表上年利率改由 §3.3 的月配息率推算核對 |
| `coupon_barrier_pct` | 共用 `field.coupon_barrier_pct`（§3.4） | 第一次用在 BARC |
| Non-Call | 共用 `field.first_callable_period`＋`field.non_call_product` | 同 FCN D 型；另核 = 配息公式保證期數（§3.5） |

### 3.3 月配息率（沒有年利率）

| 檢查 | 規則 |
|---|---|
| 推算 | 參考條件表 `Coupon p.a. (%)` × 天期 ÷ 12 ÷ §14 配息表期數，四捨五入到 4 位，和 §14 `配息率t=1=X%` 差 ≤ 0.0001（`derive.monthly_coupon`，同 FCN；5 份成立） |
| 公式兩個 X | §14 `配息率t=1=X%` 與 `配息率t=2到N=X%×nt/Nt` 的 X 相同（不同 → 讀不到月配息率，轉人工覆核） |
| 文件內一致 | 月配息率在 §14、§15(2) `每單位商品面額 × X%`、§9 段末 `遠低於月配息率X%` 相同（`doc.coupon_consistency`；FCN 另比 §9(1)、§17 與年利率，DACN 沒有這些出處） |
| 重複出現處 | §9(3) 兩處 `相關配息率為X%`（`doc.coupon_repeats`，同 FCN）；§16 情境試算每處 X（`100% + X%`、`× X% (四捨五入`、`× X% × (n/N)`，共用 `scenario.params`）= §14 月配息率 |
| 有利情況總報酬率 | = 月配息率 × 1 期（`doc.scenario_returns`，同 FCN）；一般、最差情況改由 §3.9 依假設天數驗算（FCN 的「月配息率 × 總期數」不適用） |

### 3.4 配息門檻（共用規則＋BARC 價格表內部核對）

| 檢查 | 規則 |
|---|---|
| 配息門檻 % | §14 定義句 `（為最初價格的Y%）` 的 Y → 共用 `field.coupon_barrier_pct`（表上有 `配息門檻(%)` 欄且有數字 → 和欄比；有欄但空白或 `-`、或沒有這欄 → 和 `K(%)` 比並註明；說明書讀不到 → 轉人工覆核） |
| 價格表欄頭 | §15 價格表 `配息門檻（為最初價格的Y%）` 欄頭 % = §14 定義句（`doc.coupon_barrier`） |
| 配息門檻價格 | §15 每列 `配息門檻` = 該列最初價格 × Y%，half-up 到 4 位後相等（`doc.coupon_barrier`，同 DBS DACN 與 `derive.prices` 的推算方式）；列數 = 標的數 |
| 情境重印表 | §16(3) 重印價格表沒有配息門檻欄：共用 `scenario.reprint` 和 §15 價格表**去掉配息門檻欄**後逐格比（期初、執行、KO、KI） |

### 3.5 保證期數與 Non-Call

| 檢查 | 規則 |
|---|---|
| 配息公式保證期數 = Non-Call | §14 `配息率t=1=X%;及(ii)配息率t=2到N=…` 的 g（= 1）= §13(7) 推得的 Non-Call（DACN 共用 `doc.guaranteed_periods`） |
| t 範圍 | §14 `「t」係自1至N`、`配息率t=2到N` 的 N = 配息表期數（讀不到或不同 → 讀不到月配息率，轉人工） |
| §13(7) 定義句 | 同 FCN Daily Memory（`doc.observation_t_range`）；§13(7) 多一行表名 `自動提前出場觀察期：`，不是定義句 |

### 3.6 說明書內部交叉驗證

照 BARC FCN §3.7、§3.8。DACN 差異：

| 檢查 | DACN |
|---|---|
| 配息表 | 從 §14 配息觀察期表讀（FCN 在 §13(6)）；日期規則（期數 = 天期、支付日遞增、末期期末日 = 最終評價日、末期支付日 = 到期日、C3、C4）同 FCN 期間型；另核每期期始日 = §13(7) 自動提前出場觀察期表同期期始日（`schedule.accrual_starts`；期末日由 C3 核對） |
| 價格表欄頭比例 | §15 與 §16 各情境表的執行／觸及生效欄頭 % = §15 定義句（`doc.price_header_pct`，同 FCN）；配息門檻欄頭另由 §3.4 核對 |
| 價格表列 | §15 價格表列靠上對齊，名稱折成三行時第三行跟著上一列（範本規格 §5）；投資人須知名稱和說明書比對（`iis.underlying_names`）照 FCN |

### 3.7 審查標準

照 BARC FCN（`issuer.barc`）。**商品名稱樣板 `issuer.barc.product_names.DACN`**（參考條件表 Product 是 DACN 時用）：BARC DACN 中英文名稱和 FCN 同一句（5 份），內容和 `issuer.barc.product_name` 相同；另外登記是因為每個家族範本都要在審查標準有自己的名稱樣板（#436 註冊表的一致性檢查）。投資人須知同一樣板。

### 3.8 投資人須知

照[投資人須知核對規則](iis-check-rules.md) §3 的 BARC 欄；不同的地方：

| 檢查點 | DACN |
|---|---|
| 月配息率 | `「配息率t」係指，(i)如t=1，為X%；及(ii)如t=2到N，為X%×nt/Nt` 的 X（兩個 X 不同 → 讀不到）；共用 `iis.monthly_coupon`（參考條件表年利率 ÷ 12，差 ≤ 0.0001） |
| 年利率 | 投資人須知沒有年利率，不交 `coupon_pa_pct`（不核對） |
| 價格表 | 照 BARC FCN；另核 `配息門檻` 欄頭 % = 說明書配息門檻、各列價格 = 最初價格 × %（half-up 4 位）（`iis.coupon_barrier`） |
| 配息率 t、nt、Nt 定義 | 固定寫法（辨識，投資人須知範本規格 §1.1） |

### 3.9 情境依假設天數的算式（§16(3) (ii) 一般情況、(iii) 最差情況；路線圖 #575、workflow #577）

用文件自己寫的 `(n/N)` 驗算，n、N 本身不核對。g = 配息公式保證期數（§3.5）、天期 = §14 配息表期數。

| 檢查 | 規則 |
|---|---|
| 第 1～g 期配息 | `第1 個配息支付日：`（g > 1 寫 `第1 到g 個`）下一行 `每單位配息金額 = 面額 × X% (四捨五入至小數點後第2 位)` 的 `= A`：期別 = 1～g；面額 = §6 面額；A = 面額 × 月配息率（§14），依寫的進位方式與位數 |
| 第 g+1 期起配息 | `第g+1 到N 個配息支付日：` 下一行 `每單位配息金額 = 面額 × X% × (n/N) (四捨五入至小數點後第2 位)` 的 `= B`：期別 = g+1～天期；面額 = §6 面額；B = 面額 × 月配息率 × n ÷ N，依寫的進位方式與位數（共用 `dacn.accrual_coupon_issues`）；N 是 0 → 算不出，轉人工覆核（各上手 DACN 一致） |
| 每單位累積配息金額 | `= A × 期數 + B × 期數 = 累積`：算式裡兩段的金額 = A、B，期數 = g、天期 − g；累積 = A × g + B × (天期 − g)（已進位的每期配息 × 期數加總，共用 `dacn.coupon_total_issues`）。最差情況樣本第二段寫成不帶期數的 `0.00 美元`：沒寫期數時不核期數，加總照天期 − g 算。A、B 驗算通過時用預期值、沒通過時用文件寫的值：每期配息算錯、累積照錯的配息加總時只報每期配息 |
| 一般情況最終現金交割金額 | `每單位最終現金交割金額 = 每單位商品面額 × 100% = 面額 × 100% = 金額`：算式的面額與金額 = §6 面額 |
| 總報酬率 | `= [(加數 + 加數) / 面額] - 1 = r%`：兩個加數一個 = 每單位累積配息金額、另一個 = 一般情況的每單位最終現金交割金額或最差情況的每單位最終實物贖回權益等值（照文件寫的值；順序不拘，一般情況樣本把交割金額寫在前、最差情況把累積寫在前）；除數 = 面額；r = 加總 ÷ 面額 − 1，依寫的位數四捨五入（half-up） |
| 年化 | 不核對（§2） |

算式找不到、出現多次或寫法不在範本規格內 → 轉人工覆核，不跳過後宣稱通過。路線圖 #575 前（workflow #547）這些依假設不核；§5 探勘 5 份都可穩定重算，沒有 SG DACN 那種進位或寫法前後不一致，所以改核。

## 4. 判定原則

同 BARC FCN §4：必核欄位抓不到、抓到多個不同值、或寫法不在範本規格內，一律轉人工覆核。配息門檻、保證期數、月配息率都由明確的固定寫法推得（Issue #297 的原則），不由關鍵字有無推測。

| 參考條件表 | BK01～BK04：代號、ISIN、幣別、面額、各日期、天期、K／KO／KI %、KO／KI 型態、記憶式、Non-Call、比價日、各標的代號與價格全部一致；年利率 ÷ 12 和月配息率差 ≤ 0.0001 |

## 6. 試跑預期（實作 PR 的驗收）

以私人雲端倉庫的 5 份樣本、舊總表整理的參考條件表（加 `配息門檻(%)` 欄 = `K(%)`、不加、改錯三種；BK05 用說明書反推的列）在本機跑完整核對：

- 全部辨識成 `barc-zh-dacn-pd`／`barc-zh-dacn-iis`；沒有一份被 BARC FCN 範本認走。
- 說明書與投資人須知除 BK01 名稱（同 FCN 舊格式）與舊版參考條件表沒有評等欄的信用評等（同 FCN）外全部通過；配息門檻沒有欄時和 K% 比、有欄時和欄比都通過；改錯時判不一致。
- BARC FCN、FCN_Express 與其他上手既有測試、本機真實樣本結果不變（BARC FCN 全文沒有 `配息門檻`；靠上對齊只用在 BARC DACN 價格表）。
