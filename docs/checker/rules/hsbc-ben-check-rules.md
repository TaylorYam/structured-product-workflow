# 核對規則：HSBC BEN 中文產品說明書與投資人須知

- 文件側：[HSBC BEN 範本規格](../templates/hsbc-zh-ben.md)（`hsbc-zh-ben-pd`）、[HSBC BEN 投資人須知範本規格](../templates/hsbc-zh-ben-iis.md)（`hsbc-zh-ben-iis`）
- 下單側：參考條件表，見[參考條件表格式](../order-formats/reference-sheet.md)與 [HSBC BEN 下單資料格式](../order-formats/hsbc-ben-reference.md)
- 商品：BEN（workflow ADR 0029、#372、#373）；開放順序 HSBC → MS → CA，本文件是 HSBC（workflow #375）
- 狀態：規格；實作另開（workflow #375）。核對範圍以開發者凍結的螢光標記為準；**作業人員獨立標記先略過，2026-10-30 使用者決定**（§7）
- 標「待使用者確認」的是暫定的保守做法（轉人工覆核、不放行、不臆測），詳見本機疑慮記錄；使用者回覆後再更新本文件與實作
- 本文件只寫和 [HSBC 核對規則](hsbc-check-rules.md)（FCN）不同或 BEN 特有的部分；和 [HSBC Super Bull 核對規則](hsbc-super-bull-check-rules.md) 相同的做法（沒有配息、無 KI、名稱前綴、標的不看順序、情境的交股算式、只比數值）只寫出處與差異。沒提到的（審查標準、固定警語、受託機構名稱與負責人、發行機構名稱、信用評等、幣別、費率、最低金額、受理申購日、刊印日期、價格推算、連結標的公司介紹、開始受理贖回日寫法）照 HSBC FCN

## 1. 範圍

- 只支援現行版範本（範本規格 §1：Maxi、Digital 兩型，含 Word 排版）；辨識得出是 HSBC BEN、但寫法和現行版不同的說明書或投資人須知轉人工覆核、不能人工放行。版本依範本內容判斷，不看交易日（同 #314；待使用者確認，詳見本機疑慮記錄）。
- 說明書與投資人須知都依商品家族辨識（`hsbc-zh-pd`／`hsbc-zh-sb-pd`／`hsbc-zh-ben-pd`、`hsbc-zh-iis`／`hsbc-zh-sb-iis`／`hsbc-zh-ben-iis`）；辨識結果和參考條件表 Product 不一致時轉人工覆核。
- 沒有樣本的型態：Maxi 單一標的、Maxi 4 檔以上標的、Digital 2 檔以上標的、非美元計價 → 轉人工覆核，錯訊寫「待樣本驗證」（待使用者確認，詳見本機疑慮記錄）。VWAP 有樣本，照 #122。
- 兩份都通過或人工放行才打 `TS`／`IIS` 的 `V` 並回填（ADR 0007）。

## 2. 不核對的項目

- 照 HSBC FCN §2（保證機構、`UL_n_Memo`、連結標的中文名稱與交易所、警語全文以外的段落、第五章等）。
- §11 的定義段（最差表現、期末股價、收盤價、連結標的股數、零股、期末匯率；Maxi 寫成第 24 項、Digital 寫第 25 項的「變更條件」參照）：只有文字。K% 與 Maxi 紅利的定義句除外（§3.3、§3.5）。
- §15(4) 評價日定義、§15(7)～(12)（只用來確認沒有自動提前贖回決定日，§3.5）。
- 最後評價日到到期日的天數（只作參考）。
- 參考條件表 `KO(%)`、`UL_n_KO價`：說明書沒有 KO，照來源存、不核對（ADR 0029）。
- 起單建檔的 `Observation Frequency (m)`（不在參考條件表）。
- 情境的示意股價與條件句（`期末股價為美元 P…`、`以下情境分析之零股數僅供示意…`）、§18 重印表的幣別與交易所欄、本金虧損之機率段、Digital §18 的 `*假設天期將因不同可供選擇之商品天期而異。`。
- 第三章與投資人須知第五的通用風險段（含 `自動提前到期` 字樣的再投資風險段）：不拿來判斷有沒有 KO。
- 投資人須知 第三 贖回價金之計算（只參照說明書）。

## 3. 核對規則

### 3.1 樣態與分流

| 檢查 | 規則 |
|---|---|
| 開放 | `[auto_check_products]` 的 `BEN` 加 `HSBC`（#375 實作時）；沒開放的上手照不支援樣態轉人工 |
| 樣態 | 參考條件表 KO(Freq) = `P`、KO(memo) = `N`、KI(Freq) = `-`、Non-Call = 天期（ADR 0029 起單匯入一律這樣存）；任一不符 → 照不支援樣態轉人工 |
| 範本版本 | 寫法和現行版不同 → 轉人工覆核（同不支援樣態），錯訊寫明 |
| 商品種類一致 | 範本辨識的商品家族 ≠ Product → 轉人工覆核，錯訊寫出 Product 與辨識到的範本（共用 `template.product_family`） |
| 型態一致 | 中文名稱、英文名稱、§11 開頭、§11(1) 到期公式指向不同型態（Maxi／Digital）→ 轉人工覆核 |
| HSBC 限定 | Maxi 只有 1 檔或 4 檔以上標的、Digital 2 檔以上標的、承作幣別不是 USD → 轉人工覆核，錯訊寫明「待樣本驗證」（範本規格 §4.1；待使用者確認，詳見本機疑慮記錄） |

### 3.2 參考條件表欄位（共用 `rules/reference.py`、`backfill.py`）

語意同 HSBC FCN；HSBC BEN parser 只負責交出標準欄位。

| 標準欄位 | 規則 | BEN 差異 |
|---|---|---|
| 商品代號、ISIN、幣別、面額、各日期、天期、K%、各標的進場價與執行價、期初定價 | 共用 `field.*`、`backfill.*` | 同 HSBC FCN；K% 取 §11 定義句；VWAP 照 #122 |
| 標的 | 共用 `field.underlyings` | **以彭博代號配對、不看順序**（比照 #314 HSBC Super Bull；探勘 13 份順序不同、代號相同）；數量要相同；`any_order_products` 的 `BEN` 加 `HSBC` |
| `coupon_pa_pct` | 共用 `field.coupon_pa_pct` | 交出紅利（Maxi §11 `紅利配息率為X%`、Digital §11(2) `紅利配息率：X% %`）；和 `Coupon p.a. (%)` 數值相等，**不年化** |
| `participation_pct` | 新規則（§3.4） | 參考條件表「參與率(%)」第一次被核對 |
| `ko_pct`、KO 價 | 不適用 | 說明書沒有 KO；表上值不看（ADR 0029） |
| `ki_type`、`ki_pct`、下限價 | 共用 | 無 KI：KI(Freq) `-`、KI(%) `-`、`UL_n_下限價` `-` 或空白 |
| Non-Call | 共用 `field.*`＋`field.non_call_product` | = 天期（`PRODUCT_RULES` 的 BEN `maturity_only`） |
| 比價日 | 共用 `backfill.compare_dates` | 只有 `比價日_{天期}` = §15(5) 最後評價日，其他 `-`（下單資料格式 §4） |

### 3.3 紅利

| 檢查 | 規則 |
|---|---|
| 主來源 | Maxi：§11 定義段 `紅利配息率為X%`；Digital：§11(2) `紅利配息率：X% %`；讀不到或有多個不同值 → 轉人工覆核 |
| 其他出處 | §18 假設 `紅利配息率為X%`（Digital `X%%`）；Maxi 情境一、二算式 `最大值 [X%，…]`；Digital 情境一 `(100% + X%%)`：每處數值 = 主來源，每處一筆結果。**只比數值**，不管小數位數與多出的 `%`（待使用者確認，詳見本機疑慮記錄） |
| Digital 配息金額 | §11(2) ≥ 執行價 `以現金給付每單位面額 × 紅利配息率`、< 執行價 `則無紅利配息。`：固定寫法（忽略空白），不同 → 不一致 |

### 3.4 參與率（新）

HSBC 說明書不寫參與率（§17(2) `本商品不適用`），由 §11(1) 到期公式的固定寫法推得（範本規格 §4.3；待使用者確認，詳見本機疑慮記錄）：

| 公式 | 推得 |
|---|---|
| Maxi：`每單位面額x {100% + 最大值 [紅利配息率，(最差表現連結標的期末股價 /最差表現連結標的期初股價-1)]}` | 100 |
| Digital：`以現金給付每單位面額×100%`（加 §11(2) 配息金額） | 0 |
| 其他寫法 | 讀不到 → 轉人工覆核（同範本版本不符） |

- 推得的值和參考條件表「參與率(%)」比，數值不同 → 不一致。
- 參考條件表沒有「參與率(%)」欄或該列空白 → 轉人工覆核（舊的 Excel 參考條件表可能沒有這欄；資料庫匯出的 BEN 一定有值，ADR 0029）。
- §17(2) `本商品不適用` 照固定寫法核對（§3.5），**不當成參與率 0**。

### 3.5 說明書內部交叉驗證

| 檢查 | 規則 |
|---|---|
| 沒有 KO | §11 開頭是該型態的固定句（Maxi `本商品主要給付項目為商品到期贖回金額`；Digital `本商品主要給付項目為配息金額與到期贖回金額，該金額視期末股價而定`）、§11 沒有提前贖回表、§15 沒有 `自動提前贖回決定日`：三者都成立才判沒有 KO；任一不成立 → 讀不到、轉人工覆核（明確句，#297）。「自動提前」通用風險段不看（§2） |
| 沒有定期配息 | Maxi：§16 `本商品不適用`；Digital：§16 `請見上述第一章第11 項之說明,本商品於到期時連同到期贖回金額及應付之紅利配息一次給付，並無因配息致投資標的價值而相對降低之情事。`（固定寫法，待使用者確認，詳見本機疑慮記錄）；兩型 §17(1) 最低保證配息率 `本商品不適用`。沒有或不同 → 不一致 |
| 無 KI | 全文沒有 `觸及`、§12(1) 沒有觸及不保本價格欄、§11(1) < 執行價交股句直接比執行價：三者都成立才判無 KI；任一不成立 → 讀不到 |
| 到期公式 | §11(1) ≥ 執行價（§3.4 兩種之一）與 < 執行價交股句 `…以實物給付最差表現連結標的之股份數(簡稱為「連結標的股數」)及以現金支付零股部分`、§17(2) 參與率 `本商品不適用`：固定寫法（忽略空白、去掉頁首頁尾），不同 → 不一致 |
| 百分比 | §12(1) 表頭 `執行價(即期初股價的X%)` = §11 定義句 K%（共用 `doc.price_header_pct`） |
| 價格 | 共用 `derive.prices`：執行價 = 期初股價 × K%（half-up 4 位）；價格表列數 = 標的數；沒有 KO 價欄、沒有觸及不保本價格欄 |
| Digital 標的表殘留註記 | §12(1) 表後的方括號殘留 `註3：[…]` → 不一致，作業人員確認後人工放行（待使用者確認，詳見本機疑慮記錄） |
| `(最終版)` | 封面標題沒有 `(最終版)`（Word 排版）→ 不一致，作業人員確認後人工放行（待使用者確認，詳見本機疑慮記錄） |
| 名稱、ISIN、幣別、期數 | 同 HSBC FCN（`doc.name_consistency`：§1 名稱 = 封面，中英文都比；期數 = 名稱 `N 個月` = §15(1) = §18 假設天期） |
| FCN、Super Bull 專屬規則 | 配息表、配息期數、月配息率、記憶式、`doc.redemption_pct`、提前出場表、出場紅利、提前贖回表月數不適用 |

### 3.6 審查標準

照 HSBC FCN（`issuer.hsbc`：固定警語 HSBC 版本 3 次、投資人須知 2 次、風險等級、發行機構名稱、受託機構名稱與負責人、審查通過日期、費率、受託對象、發行價格 100%）。風險等級的期望值同 FCN：參考條件表「風險等級」（流程自算，BEN 用同一個公式）。

只有**商品名稱樣板**不同（依 Product 選樣板，見[審查標準](review-standard.md) §2.2；設定 `[issuer.hsbc.product_names.BEN]`，同 Super Bull）。BEN 有兩種型態，樣板依範本辨識出的型態選：

- Maxi 中文：`香港上海滙豐銀行{天期}個月{幣別中文}計價紅利表現股權連結（無保證機構無擔保）（不保本）結構型商品（以下簡稱「本商品」）`；英文：`Bonus Enhanced Notes (Non Guaranteed, Unsecured)`，前面的 `Maxi ` 不核對（比照 #314 的 `ignore_prefix_en = true`；樣本都有 `Maxi`）。
- Digital 中文：`香港上海滙豐銀行{天期}個月{幣別中文}計價紅利配息股權連結（無保證機構無擔保）（不保本）結構型商品（以下簡稱「本商品」）`；英文：`Reverse Convertible with Digital Coupon Notes (Non Guaranteed, Unsecured)`。
- 投資人須知沒有「（以下簡稱「本商品」）」，同 FCN。只有天期、幣別兩個佔位符；比對方式（英文忽略所有空白、中文括號全半形不計）同 HSBC FCN。

### 3.7 情境分析（§18；照 FCN 重算核對）

共用 `scenario.reprint`（§18 重印表逐格與表頭 % = §12(1)，依代號對；交易所欄內容不比，Digital 沒有交易所欄）照用。共用 `scenario.params` 交天期、每單位面額、期初投資金額；情境年化報酬率不等於年利率，不交給共用規則，改由下表核對。

| 檢查 | 規則 |
|---|---|
| 情境種類 | 剛好三個，以標題判斷（範本規格 §5）。Maxi：一（≥ 執行價、漲幅 > 紅利）、二（≥ 執行價、漲幅 < 紅利）、三（< 執行價）；Digital：一（≥ 執行價）、二（< 執行價）、三（期末股價 0） |
| 基本假設 | 天期 = §15(1)；面額、期初投資金額 = 面額 × 發行價格；期末匯率 = 1（Maxi 寫 `1 美元 = 美元 1.00`、Digital 寫 `1 美元 = 美元 1`，比數值）；紅利 = §3.3 |
| Maxi 情境一、二 | 算式 `最大值 [x%，(P/I-1)]` 的 x = 紅利、I = 最差表現標的的期初股價（以 §12(1) 中文名稱對到列）、P ≥ 執行價；金額 A = 面額 × (100% + max(x%, P ÷ I − 1))，half-up 到 2 位（容許 ±0.01）；情境一要 P ÷ I − 1 > x%、情境二要 < x%；損益 = A − 面額；年化 = 損益 ÷ 面額 × 12 ÷ 天期 |
| Digital 情境一 | `(100% + x%%)` 的 x = 紅利；A = 面額 × (100% + x%)（容許 ±0.01）；損益、年化同上 |
| 交股情境（Maxi 三、Digital 二、三） | P < K（K = 最差表現標的執行價）；股數 = 面額 × 期末匯率 ÷ K（4 位，容許 ±0.0001）；交割股數 = 股數無條件捨去取整；零股數 = 股數 − 交割股數（4 位）；剩餘金額 = P × 零股數 ÷ 期末匯率，half-up 到 2 位；到期贖回價值 = P × 交割股數 ÷ 期末匯率 + 剩餘金額（2 位）；損益 = 價值 − 面額；年化 = 損益 ÷ 面額 × 12 ÷ 天期。金額容許 ±0.01。Digital 情境三 P = 0、價值 0 |
| 年化的寫法 | 文件寫「四捨五入至百分位後第二位」但整數不補 0；Digital 情境二寫成算式（`=美元 -5,000.00 / 美元 10,000 / 6 × 12`），取最後的 % 值：重算值 half-up 到 2 位後和文件值**比數值**（容許 ±0.01，同 #314） |
| 幣別字 | 情境金額與 `以X支付` 的 X = 承作幣別（同 HSBC FCN §3.5 金額旁的幣別） |

情境標題、假設句或算式找不到 → 轉人工覆核，不跳過後宣稱通過。現行版文件真的寫錯（不是進位差）→ 判不一致，作業人員確認後人工放行（同 #314）。

### 3.8 投資人須知

照[投資人須知核對規則](iis-check-rules.md) §3 的 HSBC 欄；不同的地方：

| 檢查點 | BEN |
|---|---|
| B6 名稱 | = 說明書封面名稱（BEN 樣板，依型態；英文 `Maxi ` 不核對） |
| B16 年利率；月配息率 | 不適用 |
| 沒有定期配息 | `第二 收益分配事項：請見產品說明書第一章第11 項之說明。`（投資人須知範本規格 §3；同 Super Bull `iis.no_coupon`） |
| 標的 | 第一 10. 的代號與順序 = 說明書（投資人須知對說明書仍看順序；只有參考條件表不看，§3.2） |
| C28 刊印日期 | 照 HSBC FCN（交易日～發行日之間，不要求和說明書同一天） |
| 標題 `(最終版)` | 沒有 → 不一致、人工放行（同說明書 §3.5；待使用者確認，詳見本機疑慮記錄） |
| KO、KI、紅利、參與率、到期公式 | 投資人須知沒寫，不核對；「自動提前到期」通用段不看 |

## 4. 判定原則

同 HSBC FCN §4：必核欄位抓不到、抓到多個不同值、或寫法不在範本規格內，一律轉人工覆核；沒有 KO、無 KI、沒有定期配息、參與率都要由明確的句子或固定寫法判定（Issue #297），不由關鍵字有無推測。

## 5. 探勘比對結果（2026-10-30）

探勘腳本（本機 `data/tmp/ben_hsbc/explore_hsbc_ben.py`、`scen_hsbc_ben.py`）對 27 份說明書與投資人須知逐項比對舊總表（Product = BEN、發行機構 HSBC）與說明書內部一致性，差異全部有解釋：

| 範圍 | 結果 |
|---|---|
| 參考條件表 | 代號、ISIN、幣別、各日期、天期、Non-Call = 天期、K%、紅利 = `Coupon p.a. (%)`、比價日（只有 `比價日_{天期}`）、各標的價格、無 KI 全部一致。差異：13 份標的順序不同（代號相同，§3.2）；1 份舊總表標的交易所碼和說明書不同（下單資料格式 §6）；2 份舊總表 KO% ≠ K%（不核對，§2） |
| 內部一致性 | 價格推算、兩張價格表、表頭 %、天期各出處、名稱、ISIN、投資人須知的標的／天期／發行日／到期日全部成立 |

## 6. 試跑預期（實作 PR 的驗收）

以私人雲端倉庫的樣本（`Ben PDF/325*`）、資料庫匯出或舊總表整理的參考條件表在本機跑完整核對：

- Aspose 排版的 Maxi：全部通過並回填（ISIN、發行日、比價日），標的順序不同不影響；BEN-HS18 標的交易所碼判不一致（表上資料問題）。
- BEN-HS16、BEN-HS17（Word 排版）：說明書與投資人須知的 `(最終版)` 判不一致，其餘通過。
- Digital（BEN-HS08、BEN-HS14、BEN-HS21）：標的表殘留註記判不一致，其餘通過（參與率 0）。
- 參與率：Maxi 推得 100、Digital 推得 0，和參考條件表一致；參考條件表參與率改錯時判不一致。
- HSBC FCN、FCN_Express、Super Bull 與其他上手既有測試與本機真實樣本結果不變。
