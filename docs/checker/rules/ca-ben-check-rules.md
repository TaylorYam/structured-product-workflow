# 核對規則：CA BEN 中文產品說明書與投資人須知

- 文件側：[CA BEN 範本規格](../templates/ca-zh-ben.md)（`ca-zh-ben-pd`）、[CA BEN 投資人須知範本規格](../templates/ca-zh-ben-iis.md)（`ca-zh-ben-iis`）
- 下單側：參考條件表，見[參考條件表格式](../order-formats/reference-sheet.md)與 [CA BEN 下單資料格式](../order-formats/ca-ben-reference.md)
- 商品：BEN（workflow ADR 0029、#372、#373）；開放順序 HSBC → MS → CA，本文件是 CA（workflow #377）
- 狀態：規格；實作另開（workflow #377）。核對範圍以開發者凍結的螢光標記為準；**作業人員獨立標記先略過，2026-10-30 使用者決定**（§7）
- 標「待使用者確認（BEN-377-nn）」的是暫定的保守做法（轉人工覆核、不放行、不臆測、不覆蓋），編號對到本機疑慮記錄，全部集中列在 §9.2；使用者回覆後再更新本文件與實作。實作時每一項放在一個設定值或一個函式，方便日後改
- 本文件只寫和 [CA 核對規則](ca-check-rules.md)（FCN）不同或 BEN 特有的部分；和 [CA Super Bull 核對規則](ca-super-bull-check-rules.md) 相同的做法（沒有配息、無 KI、情境交股算式、境外人民幣轉人工）、和 [HSBC BEN](hsbc-ben-check-rules.md)／[MS BEN](ms-ben-check-rules.md) 相同的做法（沒有 KO、比價日只放期末訂價日、紅利不年化、KO% 不核對、參與率和參考條件表比）只寫出處與差異。沒提到的（審查標準、固定警語、受託機構名稱與特例、發行機構名稱、保證機構評等、幣別代碼、費率、最低金額、受理申購日、刊印日期、價格推算、連結標的公司介紹、名稱與 ISIN 交叉驗證、開始受理贖回日寫法）照 CA FCN

## 1. 範圍

- 只支援現行版 Bonus 範本（範本規格 §1：BEN-CA04、BEN-CA05 的寫法）；辨識得出是 CA BEN、但寫法和現行版不同的說明書（KO 價欄版、早期版、2026-06 以前沒有樣本的寫法）轉人工覆核、不能人工放行。版本依範本內容判斷，不看交易日（待使用者確認（BEN-377-01、BEN-377-02），詳見本機疑慮記錄）。
- Digital（英文 `Digital Coupon Note`）只有 1 份境外人民幣樣本：辨識後轉人工覆核，不跑規則（Issue 範圍；待使用者確認（BEN-377-03），詳見本機疑慮記錄）。
- 說明書與投資人須知都依商品家族辨識（`ca-zh-pd`／`ca-zh-sb-pd`／`ca-zh-ben-pd`、`ca-zh-iis`／`ca-zh-sb-iis`／`ca-zh-ben-iis`）；辨識結果和參考條件表 Product 不一致時轉人工覆核。
- 沒有樣本的 Bonus 型態：單一標的、3 檔以上、K% ≠ 100、非美元 → 轉人工覆核，錯訊寫「待樣本驗證」（待使用者確認（BEN-377-07），詳見本機疑慮記錄）。境外人民幣照 CA Super Bull 轉人工。
- 兩份都通過或人工放行才打 `TS`／`IIS` 的 `V` 並回填（ADR 0007）。
- 到期結算不在本文件（比價，#372）。

## 2. 不核對的項目

- 照 CA FCN §2（保證機構與總代理人名稱、發行不成立門檻、期初定價和說明書的比對、`UL_n_Memo`、第三章 6.(4) 第三處受託機構名稱、連結標的中文名稱與交易所、警語 2～12 全文、第 17～25 項、第五～七章等）。
- 第 9 項 (1) 到期開頭句（`視最差表現之連結標期末訂價而定…`，範本筆誤照抄）、第 9 項 (2) 的定義段與 `投資人請注意：` 段（只用於範本版本辨識，範本規格 §1、§8）。
- 13.(7)～(9)（預定交易日、營業日、營業日慣例）；期末訂價日到到期日的天數（只作參考）。
- 第 15 項 (1)～(3)（參照第 9 項、第 18 項）。
- 參考條件表 `KO(%)`、`UL_n_KO價`：說明書沒有 KO，照來源存、不核對（ADR 0029）。
- 情境的條件句（`於期末訂價日，最差表現之連結標的收盤價高於執行價` 等）、公式標籤行（少 `-100%`，BEN-377-06）、情境三文末 `*在必要時，依期末匯率轉換為計價貨幣。`、`※ 請注意…`、`投資人請注意:` 段、本金虧損之機率段。
- 境外人民幣的第八章（替代貨幣條件；境外人民幣轉人工，不核對）。

## 3. 核對規則

### 3.1 樣態與分流

| 檢查 | 規則 |
|---|---|
| 開放 | `[auto_check_products]` 的 `BEN` 加 `CA`（#377 實作時）；沒開放的上手照不支援樣態轉人工 |
| 樣態 | 參考條件表 KO(Freq) = `P`、KO(memo) = `N`、KI(Freq) = `-`、Non-Call = 天期；任一不符 → 照不支援樣態轉人工 |
| 範本版本 | 寫法和現行版不同 → 轉人工覆核（同不支援樣態），錯訊寫明（BEN-377-01、BEN-377-02） |
| 商品種類一致 | 範本辨識的商品家族 ≠ Product → 轉人工覆核，錯訊寫出 Product 與辨識到的範本（共用 `template.product_family`） |
| 型態 | Digital → 轉人工覆核（BEN-377-03）；英文名稱和第 9 項公式指向不同型態 → 轉人工覆核（範本規格 §8） |
| CA BEN 限定 | 承作幣別 CNH → 轉人工覆核（同 CA Super Bull）；Bonus 1 檔或 3 檔以上、K% ≠ 100、其他非美元 → 轉人工覆核，錯訊寫明「待樣本驗證」（BEN-377-07） |

### 3.2 參考條件表欄位（共用 `rules/reference.py`、`backfill.py`）

語意同 CA FCN §3.1；CA BEN parser 只負責交出標準欄位。

| 標準欄位 | 規則 | BEN 差異 |
|---|---|---|
| 商品代號、ISIN、幣別、面額、各日期、天期、K%、標的、各標的進場價與執行價、期初定價 | 共用 `field.*`、`backfill.*` | 同 CA FCN（交易日取期初訂價日；K% 取價格表表頭）；VWAP 照 #122 |
| `coupon_pa_pct` | 共用 `field.coupon_pa_pct` | 交出第 9 項 `紅利率：X%。`；和 `Coupon p.a. (%)` 數值相等，**不年化** |
| `participation_pct` | 共用 `doc.participation`（#375 新增，參考條件表那一側） | 交出第 9 項 `參與率：X%。`，和「參與率(%)」比（§3.3） |
| `ko_pct`、KO 價 | 不適用 | 說明書沒有 KO；表上值不看（ADR 0029） |
| `ki_type`、`ki_pct`、下限價 | 共用 | 無 KI：KI(Freq) `-`、KI(%) `-`、`UL_n_下限價` `-` 或空白 |
| Non-Call | 共用 `field.*`＋`field.non_call_product` | = 天期（`PRODUCT_RULES` 的 BEN `maturity_only`） |
| 比價日 | 共用 `backfill.compare_dates` | 只有 `比價日_{天期}` = 13.(4) 期末訂價日，其他 `-` |

### 3.3 紅利與參與率

| 檢查 | 規則 |
|---|---|
| 紅利主來源 | 第 9 項公式下 `紅利率：X%。`；讀不到或有多個不同值 → 轉人工覆核 |
| 紅利其他出處 | 16.(3) 基本假設 `紅利率：X%`；情境一、二 `最大值（X%，`；投資人須知 二、2. `紅利率：X%。`：每處數值 = 主來源，每處一筆結果，**只比數值** |
| 參與率主來源 | 第 9 項公式下 `參與率：X%。`；讀不到 → 轉人工覆核 |
| 參與率其他出處 | 15.(5) `參與率：X%`（寫法 `100.00%。`、`100%`、`100%。` 都收）；情境一、二 `最大值（…，X% x（`；投資人須知 二、2. `參與率：X%。`：數值 = 主來源 |
| 參與率與參考條件表 | 數值 = 「參與率(%)」，不同 → 不一致；參考條件表沒有這欄或空白 → 轉人工覆核（同 HSBC、MS BEN） |
| 最低保證配息率 | 15.(4) 固定句 `最低保證配息率：不適用，本商品持有期間並無配息金額。`（忽略空白）；不當成 0% |

### 3.4 說明書內部交叉驗證

| 檢查 | 規則 |
|---|---|
| 沒有 KO | 第 9 項 (1) 開頭 `本商品主要給付項目為「到期贖回金額」，持有期間並無配息金額。`、13. 沒有自動提前出場觀察日條、全文沒有 `提前出場`：三者都成立才判沒有 KO；任一不成立 → 不支援的範本版本（範本規格 §8 條件 4；明確句，#297） |
| 沒有配息 | 第 9 項 (1) 開頭句、13.(6) `配息日：本商品持有期間並無配息金額。`、15.(4) 固定句：三處都要有；沒有或不同 → 不一致 |
| 無 KI | 全文沒有 `界限事件`、價格表沒有下限價欄、到期（1）直接比執行價：三者都成立才判無 KI；任一不成立 → 讀不到 |
| 到期公式 | 到期（1）交股句、（2）領回句、Bonus 公式：固定寫法（範本規格 §2；忽略空白、去掉頁首頁尾、相容字換成一般字）；公式括號照樣本原樣，不另核對括號（BEN-377-06）；不同 → 不一致 |
| 價格 | 共用 `derive.prices`：執行價 = 期初訂價 × K%（half-up 4 位）；價格表列數 = 第 10 項標的數；**只有兩欄**（有 KO 價欄 → 不支援的範本版本） |
| 表頭 % | 第 9 項價格表表頭 `(期初訂價之X% )` = K(%)（共用 `doc.price_header_pct`） |
| 名稱、ISIN、幣別、期數 | 同 CA FCN §3.5（`doc.name_consistency`、`doc.isin_consistency`、`doc.currency_consistency`；期數 = 名稱 `N 個月`／`N-Month` = 13.(1) = 基本假設天期） |
| FCN 專屬規則 | 配息表、月配息率、最低保證配息率月數、`doc.redemption_pct`、KO 觀察方式、記憶式、`doc.ko_column`、第一期整期配息句不適用 |

### 3.5 審查標準

照 CA FCN（`issuer.ca`：固定警語 CA 版本 3 次、投資人須知 1 次、風險等級寫法、發行機構名稱、商品種類 `股權連結結構型商品`、受託機構名稱與特例、審查通過日期、費率、發行價格 100%）。風險等級的期望值同 FCN：參考條件表「風險等級」。

只有**商品名稱樣板**不同（依 Product 選樣板，見[審查標準](review-standard.md) §2.15；設定 `[issuer.ca.product_names.BEN]`，同 HSBC、MS BEN）：

- 中文：`Crédit Agricole CIB Financial Solutions {tenor} 個月{ccy_zh}計價紅利結構型商品(無擔保) (不保本)`
- 英文：`Crédit Agricole CIB Financial Solutions {ccy} {tenor}-Month Bonus Note (Unsecured)(Non-principal protected)`
- 只有天期、幣別兩個佔位符；比對方式（截到 `(ISIN：` 之前、忽略空白、括號統一）同 CA FCN。Digital 轉人工，不設樣板（BEN-377-03）。

### 3.6 投資人須知

照[投資人須知核對規則](iis-check-rules.md) §3 的 CA 欄；不同的地方：

| 檢查點 | BEN |
|---|---|
| B6 名稱 | = 說明書名稱、= BEN 名稱樣板；不同 → 不一致，作業人員確認後人工放行（樣本 2 份名稱寫錯；待使用者確認（BEN-377-04），詳見本機疑慮記錄） |
| B16 年利率；月配息率 | 不適用；改核對紅利、參與率 = 說明書（§3.3） |
| 沒有配息 | 二、1.(15)、二、2. 開頭（投資人須知範本規格 §3） |
| 沒有 KO、無 KI | 二、2. 開頭只有到期贖回金額、沒有界限事件、(1) 直接比執行價 |
| 到期公式 | 二、2. 公式 = 說明書第 9 項（§3.4） |
| 剩餘金額幣別字 | `以X支付剩餘金額` 的 X = 承作幣別（同 CA FCN） |
| 商品簡介編號 | 開始受理贖回日是 (19)；依標籤定位 |
| KO 觀察方式、第一個可提前出場期、記憶式 | 不適用 |

### 3.7 情境分析（16.(3)；照 FCN 重算核對）

共用 `scenario.reprint`（情境價格表逐格與表頭 % = 第 9 項價格表）照用。共用 `scenario.params` 只交天期、每單位面額、初始投資金額；情境年化報酬率不等於年利率，不交給共用規則，改由下表核對。

| 檢查 | 規則 |
|---|---|
| 情境種類 | 剛好三個：較佳情況、一般情況、較差情況（以標題判斷，範本規格 §5） |
| 基本假設 | 天期 = 13.(1)；面額、初始投資金額 = 面額；`紅利率：X%` = 紅利（§3.3） |
| 情境一、二 | 假設收盤價 P ≥ 執行價 K（K = 價格表最差那一檔的執行價）；算式代入的面額、紅利、參與率、P、I（= 該標的期初訂價）= 前面各值；漲幅 r = 參與率 × (P ÷ I − 1)，代入行的 r 和重算值比（文件位數）；情境一要 r > 紅利、情境二要 r < 紅利；金額 A = 面額 × (100% + max(紅利, r))，half-up 到 2 位（容許 ±0.01）；報酬率行重寫的金額 = A（BEN-377-05）；報酬率 = A ÷ 面額 − 1；年化 = 報酬率 × 12 ÷ 天期（文件位數，容許 ±0.01） |
| 情境三 | 假設收盤價 P < 執行價 K；股數 = 面額 ÷ K **無條件去位到 3 位**；整數股數 = 股數取整；畸零股數 = 股數 − 整數股數；剩餘金額 = 畸零股數 × P，half-up 到 2 位（容許 ±0.01）；報酬率算式重寫的整數股數、P、剩餘金額、面額 = 前面各值；報酬率 = (整數股數 × P + 剩餘金額) ÷ 面額 − 1（2 位，容許 ±0.01）；年化 = **未四捨五入的**報酬率 × 12 ÷ 天期（2 位，容許 ±0.01）（同 CA Super Bull） |
| 幣別字 | 情境金額與 `以X支付剩餘金額` = 承作幣別（同 CA FCN） |

CA FCN 的情境規則（每期配息、總配息、獲利情境年化 = 年利率）不適用。情境標題、假設句或算式找不到 → 轉人工覆核，不跳過後宣稱通過。現行版文件真的寫錯（不是進位差）→ 判不一致，作業人員確認後人工放行（同 #312、#375、#376；BEN-377-05）。

## 4. 判定原則

同 CA FCN §4：必核欄位抓不到、抓到多個不同值、或寫法不在範本規格內，一律轉人工覆核；沒有 KO、無 KI、沒有配息、參與率都要由明確的句子或固定寫法判定（Issue #297），不由關鍵字有無推測。

## 5. 探勘比對結果（2026-10-30）

| 範圍 | 結果 |
|---|---|
| 參考條件表 | 代號、ISIN、幣別、面額、各日期、天期、Non-Call = 天期、K%、各標的價格、紅利 = `Coupon p.a. (%)`（Digital 是紅利水準 − 100）、比價日（只有 `比價日_{天期}`）、無 KI 全部一致 |

| 舊版樣本 | 雲端倉庫、`runtime/` 與 checker `data/` 的 CA PDF 都掃過，沒有 2026-06 以前的 CA BEN（BEN-377-02） |
| 範本辨識（現行程式） | 5 份說明書與 5 份投資人須知全部判為範本未知（沒有被 CA FCN、Super Bull 範本誤判） |

## 6. 試跑預期（實作 PR 的驗收）

以私人雲端倉庫的樣本（`Ben PDF/086*`）、資料庫匯出或舊總表整理的參考條件表在本機跑完整核對：

- BEN-CA04：全部通過並回填（ISIN、發行日、比價日）。
- BEN-CA05：說明書通過；投資人須知中文名稱判不一致（BEN-377-04），人工放行後回填。
- BEN-CA02、BEN-CA03：說明書判不支援的範本版本、轉人工（不能人工放行）；投資人須知照說明書一起停（BEN-377-01）。
- BEN-CA01：Digital（境外人民幣）轉人工覆核（BEN-377-03）。
- 參與率：Bonus 100，和參考條件表一致；參考條件表參與率改錯時判不一致。
