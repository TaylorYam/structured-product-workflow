# 核對規則：BNP Super Bull 中文產品說明書與投資人須知

- 文件側：[BNP Super Bull 範本規格](../templates/bnp-zh-super-bull.md)（`bnp-zh-sb-pd`）、[BNP Super Bull 投資人須知範本規格](../templates/bnp-zh-super-bull-iis.md)（`bnp-zh-sb-iis`）
- 下單側：參考條件表，見[參考條件表格式](../order-formats/reference-sheet.md)與 [BNP Super Bull 下單資料格式](../order-formats/bnp-super-bull-reference.md)
- 商品：Super Bull（workflow ADR 0028、#309）；開放順序 BNP → CA → HSBC，本文件是 BNP（workflow #311）
- 狀態：已實作（workflow #311）：`rules/bnp_super_bull.py`、`rules/bnp_super_bull_iis.py`。核對範圍以開發者凍結的螢光建議清單為準，作業人員獨立標記略過（2026-10-28 使用者決定，§7）
- 本文件只寫和 [BNP 核對規則](bnp-check-rules.md)（FCN）不同或 Super Bull 特有的部分；沒提到的（審查標準、固定警語、保證機構、受託機構、評等、費率、最低金額、發行不成立門檻、價格推算、分割轉人工、連結標的公司介紹、基本公開說明書日期、頁首總頁數）照 BNP FCN

## 1. 範圍

- 只支援現行版範本（2026-06 起交易，樣本 S01～S27）；舊版辨識出是 Super Bull 就轉人工覆核（範本規格 §1、§8，#309 決策 13）。
- 說明書與投資人須知都依商品家族辨識（`bnp-zh-pd`／`bnp-zh-sb-pd`、`bnp-zh-iis`／`bnp-zh-sb-iis`）；辨識結果和參考條件表 Product 不一致時轉人工覆核。
- 兩份都通過或人工放行才打 `TS`／`IIS` 的 `V` 並回填（ADR 0007）。

## 2. 不核對的項目

- 照 BNP FCN §2（總代理人、保證機構地址、警語 (2)～(9) 全文、連結標的中文名稱與交易所、第一章 §4、§8～§10、§12 內容、§13、§19、§21～§27 等）。
- §14(8) 以後的營業日、營業日慣例、預定交易日等定義；自動提前贖回日的日期本身（只檢查晚於同列評價日）。
- §18 情境四末句「除本商品之配息金額外，到期時潛在收益可能不存在」（FCN 範本殘留，2026-10-28 決定不核對）；情境五（只有文字）；情境三、四的年化報酬率（同 BNP FCN）。
- 起單建檔的 `Observation Frequency (m)`（不在參考條件表）。
- 評價日到自動提前贖回日、期末評價日到到期日的天數（只作參考）。

## 3. 核對規則

### 3.1 樣態與分流（Super Bull 共用，所有上手）

| 檢查 | 規則 |
|---|---|
| 開放 | `[auto_check_products]` 的 `"Super Bull"` 已加 `BNP`（#311）；沒開放的上手照不支援樣態轉人工 |
| 樣態 | 參考條件表 KO(Freq) = `P`、KO(memo) = `N`、KI(Freq) = `-`；任一不符 → 照不支援樣態轉人工（兩份都停、不回填、不能人工放行），錯訊寫出哪一欄。起單建檔的 `KO Type` 不是 `Period End` 或 `Barrier Type` 不是 `NONE` 匯出後就是這三欄不符（從 workflow #310 移來） |
| 範本版本 | 舊版 → 轉人工覆核（同不支援樣態），錯訊寫明舊版 |
| 商品種類一致 | 範本辨識的商品家族 ≠ Product → 轉人工覆核，錯訊寫出 Product 與辨識到的範本 |
| BNP 限定 | KO(%) ≠ K(%)、承作幣別不是 USD、只有 1 檔標的 → 轉人工覆核（現行版沒有樣本；範本規格 §4.3） |

### 3.2 參考條件表欄位（共用 `rules/reference.py`、`backfill.py`）

語意同 BNP FCN §3.1；BNP Super Bull parser 只負責交出標準欄位。

| 標準欄位 | 規則 | Super Bull 差異 |
|---|---|---|
| 商品代號、ISIN、幣別、面額、各日期、天期、K%、KO%、標的、各標的價格、期初定價 | 共用 `field.*`、`backfill.*` | 同 FCN；VWAP 照 #122 |
| `coupon_pa_pct` | 共用 `field.coupon_pa_pct` | 交出出場紅利（§16 的 X）；和 `Coupon p.a. (%)` 數值相等，**不年化** |
| `ki_type`、`ki_pct` | 共用 | 無 KI：KI(Freq) `-`、KI(%) `-` |
| Non-Call | 共用 `field.*`＋`field.non_call_product` | 第 1 個評價日的月數；Super Bull 至少 1（`PRODUCT_RULES`） |
| 比價日 | 共用 `backfill.compare_dates` | 照 [BNP Super Bull 下單資料格式](../order-formats/bnp-super-bull-reference.md) §4：`比價日_m` = 評價日、`比價日_{天期}` = 期末評價日 |

### 3.3 出場紅利（BNP Super Bull 專屬）

| 檢查 | 規則 |
|---|---|
| 主來源 | §16 `自動提前贖回金額 = 商品面額 × [100% + X%]`：剛好一處；讀不到或寫法不在範本規格內 → 轉人工覆核 |
| 其他出處 | §18 情境一 `[100% + X%]`、第二章 §4 `之{100% + X%}`、投資人須知收益分配事項 `{100% + X%}`：每處 = §16 的 X（數值相等），每處一筆結果 |
| 各評價日紅利 | 只有一個 X（範本沒有各評價日不同的紅利）；讀到不同的值 → 轉人工覆核（#309 決策） |

### 3.4 日期表與比價日（BNP Super Bull 專屬，取代共用 §6.1）

Super Bull 的日期表只列評價日，共用日期表檢查（[共用核對規則](shared-check-rules.md) §6.1：期數 = 天期、末期觀察日 = 最終評價日、末期配息日 = 到期日）不適用；parser 交出 `schedule_table` 為不適用，改核對下表。

| 檢查 | 規則 |
|---|---|
| 表的結構 | 表頭 `j`、`自動提前贖回評價日`、`自動提前贖回日`；j 從 1 連續；至少 1 列；格子都是日期（沒有 `不適用`） |
| KO 觀察方式 | §14(6) `如下表所列之日期` 與表頭一致 → P |
| 月數 | 每個評價日的月數 m（範本規格 §4.1）：晚於「發行日 + m 個月」0～7 個日曆天；1 ≤ m < 天期；各列 m 遞增且不重複 |
| 順序 | 同列評價日 < 自動提前贖回日；評價日逐列遞增；末列評價日 < 期末評價日 |
| Non-Call | = 第 1 列的 m |
| 比價日 | 由 m 與期末評價日推得（§3.2），parser 直接交出提前出場排程，不走共用日期表推導 |

### 3.5 說明書內部交叉驗證

| 檢查 | 規則 |
|---|---|
| 沒有配息 | §15 = `配息資料及其計算公式：不適用。`；投資人須知 `● 配息：不適用` |
| 非記憶式 | §16 定義句 = §20(1) 定義句 = 投資人須知事件句（範本規格 §3）；同 BNP FCN `doc.ko_memory` |
| 無 KI | §17 沒有觸及生效事件、到期條款兩款（範本規格 §2）、§11 沒有下限價格列，三者都成立才判無 KI；任一不成立 → 讀不到 |
| 到期公式 | §17 (1) `商品面額 × [100% + 100% × (…收盤價格 ÷ …執行價格 - 1)]`、`參與率：100%。`、`最低保證配息率：無。`：固定寫法，不同 → 不一致 |
| 名稱與期數 | 封面標題 = 封面 2 = 第一章 §1（同 FCN）；名稱 `N 個月期` = §14(1) 天期 |
| 其他 | 受託機構商品代號、幣別一致、基本公開說明書日期、頁首總頁數：同 BNP FCN §3.5 |

### 3.6 審查標準

照 BNP FCN（`issuer.bnp`：固定警語、風險等級寫法、發行機構、保證機構三處、商品種類 `股權連結結構型商品`、最低金額倍數、發行不成立門檻、費率）。風險等級的期望值同 FCN：參考條件表「風險等級」（流程自算，Super Bull 用同一個公式）。

只有**商品名稱樣板**不同（依 Product 選樣板，見[審查標準](review-standard.md) §2.7）：

- 中文：`法國巴黎銀行{tenor}個月期{ccy_zh}計價自動提前贖回連結{underlying_zh}股票/交易所買賣基金結構型商品(不保本)(無擔保)`（沒有 `固定配息`；`自動提前贖回` 固定寫出）
- 英文：`{tenor} Months {ccy} Super Bull Early Redeemable Note linked to {underlying_en} issued by BNP Paribas Issuance B.V. (unsecured)`
- `{underlying_*}`、比對方式（中文忽略空白、括號全半形不計；英文忽略所有空白）同 FCN。

### 3.7 情境分析（§18(3)，BNP Super Bull 專屬；#309 決策：照 FCN 重算核對）

共用 `scenario.reprint`（§18 重印表 = §11）、`scenario.strike`（情境二～四的執行價 = §11 表現最差那一檔）照用。共用 `scenario.params` 只交面額、投資本金、發行價格三處；情境年化報酬率不等於年利率，不交給共用規則，改由下表核對。

| 檢查 | 規則 |
|---|---|
| 情境種類 | 剛好五個：自動提前贖回情況、較佳情況、較差情況、最差情況、極端情況（以標題判斷） |
| 情境一 | 假設句 `假設於第1 個自動提前贖回評價日`；`[100% + X%]` = §16（§3.3）；`= A` 的 A = 面額 × (100% + X%)；總報酬率 = X%（文件位數）；年化報酬率 = X × 12 ÷ 第 1 個評價日的月數，half-up 到文件位數 |
| 情境二 | 金額 = 面額 × 假設收盤價 ÷ 執行價，half-up 到 2 位，容許 ±0.01；總報酬率 = 金額 ÷ 面額 − 1（文件位數）；年化報酬率 = 總報酬率 × 12 ÷ 天期，half-up 到文件位數；假設收盤價須 ≥ 執行價 |
| 情境三、四 | 股數 = 面額 ÷ 執行價（4 位）、無條件捨去至整數位；剩餘金額 = 假設收盤價 × 畸零股數（2 位，容許 ±0.01）；總報酬率 = (股數 × 收盤價 + 剩餘金額) ÷ 面額 − 1；假設收盤價須 < 執行價；年化報酬率不核對 |
| 情境四末句 | 不核對（§2） |

金額容許 ±0.01 進位差（舊版樣本有一份差 0.01；#311）。情境標題、假設句或算式找不到 → 轉人工覆核，不跳過後宣稱通過。現行版文件真的寫錯（不是進位差）→ 判不一致，作業人員確認後人工放行。

情境三、四的股數、剩餘金額與總報酬率在探勘時沒有逐份驗算，實作時以 S01～S27 驗證；不符合本表的地方列給使用者確認後再定。

### 3.8 投資人須知

照[投資人須知核對規則](iis-check-rules.md) §3 的 BNP 欄；不同的地方：

| 檢查點 | Super Bull |
|---|---|
| B6 名稱 | = 說明書名稱（Super Bull 樣板） |
| B16 年利率；月配息率 | 不適用；改核對出場紅利 `{100% + X%}` = 說明書 §16（§3.3） |
| B19a KI | 不適用（沒有下限價格列） |
| D31 KO 觀察方式 | `每N 個月一次`／`每月一次` → P |
| D33 第一個可提前出場期 | 不寫（同 BNP FCN P 型） |
| D35 KI 型態 | 無 KI：到期贖回金額段沒有觸及生效事件、兩款寫法（投資人須知範本規格 §2） |
| 評價日間隔（Super Bull 新增） | `每N 個月一次` 的 N = 說明書日期表的每個間隔（發行日 → 第 1 個評價日、相鄰評價日）；不符 → 轉人工覆核（#309 決策） |
| 沒有配息（Super Bull 新增） | `● 配息：不適用` |

## 4. 判定原則

同 BNP FCN §4：必核欄位抓不到、抓到多個不同值、或寫法不在範本規格內，一律轉人工覆核；無 KI、非記憶式、沒有配息都要由明確的句子判定（Issue #297）。

## 5. 探勘比對結果（2026-10-28）

探勘腳本（本機 `data/tmp/superball_bnp/explore.py`）對 57 份說明書與投資人須知逐項比對參考條件表（1,895 項）與說明書內部一致性：

| 範圍 | 結果 |
|---|---|
| 現行版 S01～S27，參考條件表 | 只有 6 份的 1 檔標的交易所碼和說明書不同：使用者確認以起單建檔為準，說明書寫錯（2026-10-28），判不一致是預期結果 |
| 現行版 S01～S27，內部一致性 | 全部成立：價格推算、各檔 K%／KO% 相同、§11 = §18 重印、紅利三處、情境一與情境二的金額與年化、日期表順序與月數、受理申購日、刊印日期、名稱、無配息、參與率、投資人須知各欄與評價日間隔 |
| 舊版 S28～S57 | 不支援（轉人工）。探勘另發現表上到期日、比價日、拆股還原與文件內情境面額幣別等差異，留給 workflow 回補舊總表時處理；其中 1 份說明書評價日與投資人須知、情境說法矛盾，使用者決定略過 |

Non-Call、出場紅利 = `Coupon p.a. (%)`、KO(Freq) `P`、KO(memo) `N`、KI(Freq) `-`：57 份全部一致。
