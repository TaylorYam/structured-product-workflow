# 核對規則：BNP DACN 中文產品說明書與投資人須知

- 文件側：[BNP DACN 範本規格](../templates/bnp-zh-dacn.md)（`bnp-zh-dacn-pd`）、[BNP DACN 投資人須知範本規格](../templates/bnp-zh-dacn-iis.md)（`bnp-zh-dacn-iis`）
- 下單側：參考條件表，見[參考條件表格式](../order-formats/reference-sheet.md)與 [BNP DACN 下單資料格式](../order-formats/bnp-dacn-reference.md)
- 商品：DACN（workflow ADR 0030、#366、#367）；第二波開放順序 Barclays → BNP → UBS → MS（路線圖 #551），本文件是 BNP（workflow #548）
- 狀態：已實作（workflow #548）。核對範圍以開發者凍結的螢光標記為準；**作業人員獨立標記不做（路線圖 #551 指示，同 DACN／BEN 第一波）**（§7）
- 本文件只寫和 [BNP 核對規則](bnp-check-rules.md)（FCN）不同或 DACN 特有的部分。沒提到的（審查標準、固定警語與次數、保證機構三種寫法、受託機構、發行機構名稱、信用評等、商品種類、幣別、費率、最低金額、受理申購日、刊印日期、審查通過日期、價格推算與分割轉人工、KO／KI／記憶式的內部一致、D 型日期表與比價日、名稱一致、基本公開說明書日期、頁首總頁數、連結標的說明）照 BNP FCN。共用的 DACN 規則（配息門檻、商品種類一致、沒有樣本的型態轉人工、保證期數 = Non-Call）和第一波 DACN、[Barclays DACN](barc-dacn-check-rules.md) 相同

## 1. 範圍

- 只支援現行版範本（範本規格 §1）；辨識得出是 BNP DACN、但現行版特徵不成立 → 不支援的範本版本，轉人工覆核、不能人工放行。版本只看寫法、不看交易日（同第一波，workflow #409）。
- 依 §15 的 `×(nj/Nj)` 公式與 nj 定義（比 `定界價格`）辨識商品家族（workflow #366 決定 10）；名稱另當條件（中文沒有 `固定配息`、英文有 `Daily Accrual`，範本規格 §8）。同一家上手由專到泛：DACN → Super Bull → FCN（`issuers.py`，#436）。辨識結果和參考條件表 Product 不一致時轉人工覆核。
- 支援樣態內、但 DACN 沒有樣本的型態（非美元、單一標的、KO 不是每日記憶式、無 KI、保證期數或 Non-Call ≠ 1）→ 轉人工覆核，錯訊寫「待樣本驗證」（§3.1）。KI 每期觀察（MKI）照 workflow #386／#403 轉人工（BNP FCN 支援 MKI，DACN 不支援），錯訊寫「每期觀察 KI 維持人工處理（#386）」，不寫「待樣本驗證」（BP02 就是 MKI 樣本，補樣本也不會開放）。
- 兩份都通過或人工放行才打 `TS`／`IIS` 的 `V` 並回填（ADR 0007）。

## 2. 不核對的項目

- 照 BNP FCN §2。
- **區間計息的計算**：nj、Nj、合格營業日、各期配息金額（workflow #366 不在範圍內；ADR 0030 不追蹤每日計息）。§15 公式與定義只當固定寫法（辨識，範本規格 §2.1）；§14(13) 合格營業日定義不核對。
- §15 KO 那一期的累計配息說明（`若於第1 個配息期結束日發生自動提前贖回事件…`、`應付累計配息將於…`）與最後兩句（BP03 沒有）。
- 情境分析：§18 假設 `每個配息期之合格營業日總天數=M`；自動提前贖回情況以外，第 2 期起的配息金額、`(M ÷ M)`／`(0 ÷ M)`、累積總月配息金額與總報酬率（依計息天數假設算出；FCN 這幾項核對）；較差、最差情況年化照 FCN 不核對。
- 投資人須知配息寫法和說明書 §15 字不同（各自當固定寫法，不互相比對文字）。

## 3. 核對規則

### 3.1 樣態與分流

| 檢查 | 規則 |
|---|---|
| 開放 | `[auto_check_products]` 的 `DACN` 加 `BNP`；沒開放的上手照不支援樣態轉人工 |
| 範本版本 | 寫法和現行版不同 → 不支援的範本版本（`template.detect`，原因 `template_unsupported`），錯訊列出缺的特徵；不看交易日 |
| 商品種類一致 | 辨識到的範本商品家族 ≠ Product → 轉人工覆核（共用 `template.product_family`）；Product 空白視為 FCN |
| 沒有樣本的型態 | 說明書讀出的型態不是「美元計價、多標的、KO 每日＋記憶式、KI 每日或到期觀察、配息公式保證 1 期、Non-Call 1」→ 轉人工覆核（`doc.template_variant`），錯訊寫出哪一項「待樣本驗證」；KI 每期觀察照 #386 也在這裡轉人工，錯訊寫「每期觀察 KI 維持人工處理（#386）」 |

### 3.2 參考條件表欄位（共用 `rules/reference.py`、`backfill.py`）

| 標準欄位 | 規則 | DACN 差異 |
|---|---|---|
| 商品代號、ISIN、幣別、面額、各日期、天期、K／KO／KI %、KO／KI 型態、記憶式、標的、各標的價格、比價日 | 共用 `field.*`、`backfill.*` | 同 BNP FCN |
| `coupon_pa_pct` | 共用 `field.coupon_pa_pct`（§15 `(即年利率Y%)`） | 同 FCN |
| `coupon_barrier_pct` | 共用 `field.coupon_barrier_pct`（§3.4） | 第一次用在 BNP |
| Non-Call | 共用 `field.first_callable_period`＋`field.non_call_product` | 同 FCN D 型；另核 = 配息公式保證期數（§3.5） |

### 3.3 年利率與月配息率

| 檢查 | 規則 |
|---|---|
| 年利率 | 同 FCN：§15 `(即年利率Y%)` = 參考條件表；§18 自動提前贖回情況、最佳情況 (A)(B) 每處 `年化報酬率：Y%` = 年利率（共用 `scenario.params`）。§17 沒有年利率（FCN 有） |
| 月配息率 | §15 `月配息率：X%` = 年利率 ÷ 12，四捨五入到說明書顯示的位數（`derive.monthly_coupon`，同 FCN；3 份成立） |
| 公式三個 X | §15 第 2 段 `配息金額=商品面額×X%` 與第 3 段 `配息金額=商品面額×X%×(nj/Nj)` 的 X = 第 1 段月配息率（不同 → 讀不到月配息率，轉人工覆核；取代 FCN 的 `固定配息金額 = 每單位面額 × X%`） |
| 最低配息率 | §17 `最低配息率為X%。` 的 X = 月配息率（`doc.min_coupon_rate`；FCN 是 `(年化)` 的年利率） |
| 重複出現處 | §18 `每月配息率：X%` 與每個情境算式 `× X%`、`× X% × (n ÷ M)` 的 X = 月配息率（共用 `scenario.params`；FCN 同一條規則，多了 `× (n ÷ M)` 寫法） |

### 3.4 配息門檻（共用規則＋BNP 標的表內部核對）

| 檢查 | 規則 |
|---|---|
| 配息門檻 % | §11 `定界價格(Barrier Price)` 列 `即期初價格之Y%` 的 Y（每檔都寫、須相同，不同 → 歧義轉人工）→ 共用 `field.coupon_barrier_pct`（表上有 `配息門檻(%)` 欄且有數字 → 和欄比；有欄但空白或 `-`、或沒有這欄 → 和 `K(%)` 比並註明；說明書讀不到 → 轉人工覆核） |
| 配息門檻價格 | §11 每檔定界價格 = 該檔期初價格 × Y%，half-up 到 4 位後相等（`doc.coupon_barrier`，同 Barclays、DBS DACN 的共用算法 `dacn.barrier_price`）；檔數 = 標的數 |
| 情境重印表 | §18 重印表**含定界價格列**，共用 `scenario.reprint` 和 §11 逐格比（期初、執行、自動提前贖回、下限價格、定界價格） |

### 3.5 保證期數與 Non-Call

| 檢查 | 規則 |
|---|---|
| 配息公式保證期數 = Non-Call | §15 第 2 段 `第1個配息日`（g = 1；`第1到g個` → g）= §14(8) 推得的 Non-Call（DACN 共用 `doc.guaranteed_periods`） |
| 配息日範圍 | §15 第 3 段 `第g+1到N個配息日` 的起點 = g + 1、N = 天期（不同 → 讀不到月配息率，轉人工） |

### 3.6 說明書內部交叉驗證

照 BNP FCN §3.5。DACN 差異：

| 檢查 | DACN |
|---|---|
| 期數 | 日期表列數 = 天期 = 名稱 `N 個月期` = §15 第 3 段 N = §18 最佳、較差、最差情況 `第2~N 個月`（FCN 是 `第1~N 個月`） |
| KI | §17 有無觸及生效事件與 §11 有無下限價格列一致（同 FCN）；情境數依 KI 型態（同 FCN） |
| 標的表 | §11 多定界價格列（範本規格 §5）：列標籤要宣告，否則當成下限價格列的多餘儲存格 |

### 3.7 情境分析（§18(3)）

| 情境 | 規則 |
|---|---|
| 假設 | 面額、發行價格、投資本金、`每月配息率：X%` 同 FCN；`每個配息期之合格營業日總天數=M` 不核對 |
| 自動提前贖回情況 | 同 FCN（期別 1～Non-Call、每期配息 = 面額 × 月配息率、累積、贖回金額、總報酬率、年化 = 年利率、假設句期別） |
| 最佳情況 (A)(B) | `第1 個月配息金額 = 面額 × X%` 的 `= A`：A = 面額 × 月配息率（half-up 到寫的位數，同 FCN）；`第2~N 個月` 算式的面額與 X（§3.3）；贖回金額 = 面額；年化 = 年利率。第 2 期起的配息金額、累積、總報酬率不核對（§2） |
| 較差、最差情況 | 第 1 個月配息同上；第 2 期起算式的面額與 X；股數、剩餘金額、`執行價格N` 同 FCN（股數 = 面額 ÷ 執行價、剩餘金額 = 收盤價 × 畸零股數，依文件寫的收盤價驗算）；累積、總報酬率、年化不核對（§2） |
| 極端情況 | 同 FCN 不核對 |

情境標題與期別寫法未知、或算式找不到時轉人工覆核，不跳過後宣稱通過。

### 3.8 審查標準

照 BNP FCN（`issuer.bnp`）。**商品名稱樣板 `issuer.bnp.product_names.DACN`**（參考條件表 Product 是 DACN 時用；範本規格 §9）：

- 中文：`法國巴黎銀行{tenor}個月期{ccy_zh}計價{autocall_zh}連結{underlying_zh}股票/交易所買賣基金結構型商品(不保本)(無擔保)`（FCN 樣板去掉 `固定配息`）
- 英文：`{tenor} Months {ccy} Daily Accrual {autocall_en}Note linked to {underlying_en} issued by BNP Paribas Issuance B.V. (unsecured)`
- 佔位符與比對方式同 `issuer.bnp.product_name`（3 份成立）。投資人須知同一樣板。

### 3.9 投資人須知

照[投資人須知核對規則](iis-check-rules.md) §3 的 BNP 欄；不同的地方：

| 檢查點 | DACN |
|---|---|
| 月配息率 | `其中C為X%` 的 X（同 FCN；共用 `iis.monthly_coupon`） |
| 保證期數 | `第1個配息日之配息金額` 與 `第2~N個配息日` 推得的 g = 說明書 §15 保證期數（`iis.guaranteed_periods`）；N = 天期 |
| 標的表 | 照 FCN；另核 `定界價格` 列的 % = 說明書配息門檻、每檔價格 = 說明書 §11 同檔（`iis.coupon_barrier`）；列標籤和價格黏在一起、跨頁的版面照範本規格 §3 拆開 |
| 配息、nj、Nj 定義 | 固定寫法（辨識，投資人須知範本規格 §1.1） |

## 4. 判定原則

同 BNP FCN §4：必核欄位抓不到、抓到多個不同值、或寫法不在範本規格內，一律轉人工覆核。配息門檻、保證期數、月配息率都由明確的固定寫法推得（Issue #297 的原則），不由關鍵字有無推測。

標記外、刻意不核對的段落見 §2。每條新規則實作時要有合成反例，特別是「正式條款正確、但其他出處錯」：§11 某檔定界價格 % 和其他檔不同；某檔定界價格不是期初 × %；§18 重印表定界價格列和 §11 不同；§15 第 2 或第 3 段的 X 和月配息率不同；§17 最低配息率和月配息率不同；§18 某處 `× X% × (n ÷ M)` 的 X 不同；保證期數和 Non-Call 不同（`第1到2個配息日`）；§15 第 3 段 N ≠ 天期；§15 nj 定義改成不比定界價格（→ 範本未知）；§15 其他固定字改掉（→ 不支援的範本版本）；§11 沒有定界價格列（→ 不支援的範本版本）；參考條件表配息門檻 ≠ 說明書；配息門檻欄存在但空白（→ 和 K% 比）；表上沒有配息門檻欄；Product 是 FCN 或 Super Bull 但文件是 DACN（及反過來）；交易日早於 2026-06-01 但寫法相同（→ 照常核對）；非美元、單一標的、無 KI、KI 每期觀察（→ 轉人工）；投資人須知 C、g、定界價格 % 或價格和說明書不同；投資人須知標的表列標籤和價格黏在一起、跨頁。
